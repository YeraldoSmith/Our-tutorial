# Our Tutorial · Программирование с нуля

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · **Русский**

Курс программирования **с абсолютного нуля** на нескольких языках, где практика идёт вместе с чтением, и кроссплатформенная программа для обучения.

- 📚 **9 курсов**: Первые шаги, Python, C, C++, Java, Rust, Go, JavaScript/TypeScript, ассемблер (x86-64)
- 🌏 **Уроки на 4 языках**: упрощённый и традиционный китайский, английский, русский; интерфейс программы также на японском, корейском, испанском, французском и немецком
- ✍️ **Задания в каждом уроке**: выбор ответа, «что выведет программа» и задачи на программирование с **автоматической проверкой**
- 💬 **Понятные ошибки**: к английским сообщениям компиляторов добавляется объяснение простыми словами на вашем языке
- 🧪 **Проверка памяти C/C++**: включите её в «Инструменты → Настройки…», и выход за границы массива, использование освобождённой памяти, утечки и подобные ошибки ловятся сразу, с номером строки (на основе AddressSanitizer; с MinGW в Windows недоступна)
- 🖥️ **Настоящая программа** (не веб-страница) для Windows, macOS и Linux: читать, писать, запускать и решать — в одном окне
- 🆕 **Современное содержание**: Python 3.14 и uv, C23, C++23, Java 25 (LTS), Rust 2024, Go 1.2x, запуск TypeScript прямо в Node.js…

## Два способа учиться

### 1. С программой (рекомендуется)

1. Откройте страницу [Releases](https://github.com/YeraldoSmith/Our-tutorial/releases) и скачайте файл для своей системы:
   - Windows: `app-windows-x64.zip` — распакуйте и запустите `OurTutorial.exe`
   - macOS (Apple silicon): `app-macos-arm64.zip` — распакуйте и перетащите `OurTutorial.app` в «Программы». Если macOS не может проверить разработчика, откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть»
   - Linux: `app-linux-x64.tar.gz` — распакуйте и запустите `OurTutorial/OurTutorial`
2. Выберите язык интерфейса и начните с урока 1 курса «Первые шаги».
3. В программу **встроен Python**, поэтому курс Python работает без установки чего-либо. Для других языков откройте «Инструменты → Проверить инструменты разработки» и следуйте подсказкам; пока можно пользоваться «запуском онлайн».

**Запуск из исходников** (Python 3.11+):

```bash
git clone https://github.com/YeraldoSmith/Our-tutorial.git
cd Our-tutorial
pip install -r app/requirements.txt
python app/run.py
```

`git pull` обновляет уроки в программе; в скачанной версии есть «Инструменты → Обновить материалы курса».

### 2. Читать прямо на GitHub

Каждый урок — это папка с файлом на каждом языке: `zh-CN.md`, `zh-TW.md`, `en.md`, `ru.md`. Эталонные решения и тесты лежат там же в `exercises.toml`.
