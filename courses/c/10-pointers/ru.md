Указатели — самая характерная часть C и та, которой новички боятся больше всего. На самом деле в основе одна идея: **адрес**. Не спешите, запускайте и меняйте каждый пример.

## 10.1 Память и адреса

Представьте память как очень-очень длинную улицу, где у каждого дома (каждого **байта**) есть номер — его **адрес**. Каждая переменная живёт по какому-то адресу; `int` занимает 4 дома подряд, `double` — 8.

```c
#include <stdio.h>

int main(void) {
    int age = 20;
    double price = 9.5;
    printf("age = %d, адрес %p\n", age, (void *)&age);
    printf("price = %.1f, адрес %p\n", price, (void *)&price);
    printf("age занимает %zu байта, price — %zu\n", sizeof age, sizeof price);
    return 0;
}
```

- `&age` читается как «адрес age»; `&` — **операция взятия адреса**. Вы давно пользуетесь ею в `scanf("%d", &age)`.
- `%p` выводит адрес в шестнадцатеричном виде; по правилам его сначала приводят к `(void *)` (про `void *` — в разделе 10.8).
- Адреса, скорее всего, меняются от запуска к запуску — операционная система нарочно перемешивает их ради безопасности. Конкретные числа не важны.

## 10.2 Переменные-указатели

**Указатель** — это просто «переменная, в которой хранится адрес».

```c
#include <stdio.h>

int main(void) {
    int x = 10;
    int *p = &x;                  // p — «указатель на int», в нём адрес x

    printf("x = %d\n", x);
    printf("адрес в p: %p\n", (void *)p);
    printf("*p = %d\n", *p);      // *p: int, найденный по этому адресу, то есть x

    *p = 25;                      // меняем x через указатель
    printf("x = %d\n", x);        // 25

    int y = 7;
    p = &y;                       // указатель можно перенаправить на другую переменную
    *p += 1;
    printf("y = %d\n", y);        // 8
    return 0;
}
```

```text
       x                    p
    ┌──────┐          ┌──────────┐
    │  25  │ ◀─────── │ адрес x  │
    └──────┘          └──────────┘
```

| Запись | Смысл |
|--------|-------|
| `int *p;` | определить указатель `p`, который может хранить адрес переменной `int` |
| `&x` | адрес `x` |
| `*p` | **разыменование**: переменная, на которую указывает `p`, — для чтения и записи |

У `*` два применения, не путайте их: **в определении** `int *p` говорит «p — указатель»; **в выражении** `*p` означает «то, на что указывает p».

> [!TIP]
> `int *p` и `int* p` — одно и то же, но лучше первый вариант. В `int* a, b;` указатель только `a`, а `b` — обычный `int`! Два указателя пишут так: `int *a, *b;`.

Тип указателя должен соответствовать переменной, на которую он указывает: адрес `int` хранят в `int *`, адрес `double` — в `double *`.

## 10.3 Указатели как параметры функций

`swap` из урока 7 не сработал, потому что функция получила копии. Теперь передадим **адреса**:

```c
#include <stdio.h>

void swap(int *a, int *b) {        // параметры — два адреса
    int t = *a;
    *a = *b;
    *b = t;
}

void min_max(const int arr[], int n, int *min, int *max) {   // «возвращаем» два результата через указатели
    *min = arr[0];
    *max = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] < *min) {
            *min = arr[i];
        }
        if (arr[i] > *max) {
            *max = arr[i];
        }
    }
}

int main(void) {
    int p = 1, q = 2;
    swap(&p, &q);                       // передаём адреса
    printf("p = %d, q = %d\n", p, q);   // p = 2, q = 1: получилось!

    int data[] = {4, -2, 9, 0};
    int lo = 0, hi = 0;
    min_max(data, 4, &lo, &hi);
    printf("минимум %d, максимум %d\n", lo, hi);
    return 0;
}
```

C по-прежнему передаёт по значению — просто на этот раз копируется **адрес**. Копия указывает туда же, куда и оригинал, поэтому изменение `*a` меняет `p` из `main`.

Теперь понятен и `scanf("%d", &x)`: `scanf` должна записать прочитанное число в `x`, поэтому ей нужен адрес `x`.

## 10.4 `NULL` и «дикие» указатели

**Неинициализированный указатель** хранит мусорный адрес и называется **диким**. Чтение или запись через него — это запись в случайное место: программа может упасть, а может незаметно испортить другие данные:

```c norun
int *p;          // не инициализирован: дикий указатель
*p = 5;          // неопределённое поведение!
```

Правила простые:

- инициализируйте указатели сразу при определении: либо адресом переменной (`&x`), либо **`NULL`** — особым «пустым адресом», означающим «никуда не указывает»;
- если не уверены, что указатель действителен, проверяйте `if (p != NULL)` перед использованием;
- чтение или запись через `NULL` сразу роняет программу (`Segmentation fault`). С включённой проверкой памяти (урок 8) вы увидите номер строки.

Многие функции возвращают `NULL`, чтобы сказать «не найдено» или «не получилось»:

```c
#include <stdio.h>

int *find(int arr[], int n, int target) {   // нашли — возвращаем адрес элемента, нет — NULL
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) {
            return &arr[i];
        }
    }
    return NULL;
}

int main(void) {
    int data[] = {3, 8, 5};
    int *p = find(data, 3, 8);
    if (p != NULL) {
        *p = 80;                     // меняем этот элемент массива прямо через указатель
    }
    if (find(data, 3, 42) == NULL) {
        printf("42 не найдено\n");
    }
    printf("%d %d %d\n", data[0], data[1], data[2]);   // 3 80 5
    return 0;
}
```

> [!WARNING]
> Функция **не должна возвращать адрес своей локальной переменной**: локальная переменная исчезает, когда функция заканчивается, и адрес становится «висячим указателем». `find` выше возвращает адрес элемента массива вызывающего — это нормально. Заметив такую ошибку, GCC предупреждает: `function returns address of local variable`.

## 10.5 Указатели и массивы

Массивы и указатели очень тесно связаны:

```c
#include <stdio.h>

int main(void) {
    int a[5] = {10, 20, 30, 40, 50};
    int *p = a;                       // имя массива превращается в адрес первого элемента, &a[0]

    printf("%d %d\n", *p, *(p + 1));  // 10 20: p + 1 указывает на следующий элемент
    printf("%d %d\n", a[3], *(a + 3));// a[i] — это *(a + i)

    for (int *q = a; q < a + 5; q++) {   // обходим массив указателем
        printf("%d ", *q);
    }
    printf("\n");

    int *r = &a[4];
    printf("между r и p %td элемента\n", r - p);                     // 4
    printf("sizeof a = %zu, sizeof p = %zu\n", sizeof a, sizeof p);  // 20 и 8
    return 0;
}
```

- **В большинстве выражений имя массива превращается в адрес его первого элемента.** Поэтому в `int *p = a;` не нужен `&`, как и в `scanf("%s", name)`.
- **Арифметика указателей**: `p + 1` не прибавляет к адресу 1, а **сдвигается на один элемент** (для `int *` — на 4 байта). Разность двух указателей внутри одного массива — число элементов между ними (выводится через `%td`).
- `a[i]` — просто сокращение для `*(a + i)`.
- Параметры функции `int a[]` и `int *a` — **в точности одно и то же**. Вот почему в уроке 8 `sizeof a` внутри функции давал 8: там `a` на самом деле указатель.

Но массив — не указатель: массив — это целый блок памяти с данными, `sizeof a` — размер всего массива, а `a = p;` и `a++` запрещены; указатель — всего лишь переменная с адресом (обычно 8 байт), и его можно в любой момент перенаправить.

## 10.6 Указатели и строки

Строковые функции повсюду используют указатели. `strchr` и `strstr` возвращают указатель на найденное место:

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

int main(void) {
    char text[] = "name=Ada;lang=C";
    char *eq = strchr(text, '=');              // указывает на первый '='
    if (eq != NULL) {
        printf("индекс '=': %td\n", eq - text);   // разность указателей: 4
        printf("после него: %s\n", eq + 1);        // строка, начинающаяся со следующего символа
    }

    const char *greeting = "hello";            // указывает на строковый литерал: только чтение
    printf("первая буква %s — %c\n", greeting, greeting[0]);

    // strtol: переводит строку в целое и через end сообщает, где остановилась
    const char *input = "123abc";
    char *end;
    long value = strtol(input, &end, 10);      // 10 — десятичная система
    printf("прочитано %ld, осталось \"%s\"\n", value, end);
    if (end == input) {
        printf("ни одной цифры\n");
    } else if (*end != '\0') {
        printf("после числа есть другие символы\n");
    }
    return 0;
}
```

- `strtol(строка, &end, основание)` аккуратнее `atoi`: `end` указывает на первый непреобразованный символ. `end == input` — цифр не было вовсе; `*end == '\0'` — вся строка оказалась числом. Для дробных есть `strtod`.
- **Строковые литералы менять нельзя.** `"hello"` лежит в памяти только для чтения, поэтому этот код упадёт:

```c norun
char *s = "hello";
s[0] = 'J';          // ошибка сегментации!
```

| Запись | Смысл |
|--------|-------|
| `char s[] = "hello";` | **массив**: литерал **копируется** в него, менять можно сколько угодно |
| `const char *s = "hello";` | **указатель** на литерал только для чтения. С `const` случайное `s[0] = 'J'` станет ошибкой компиляции |

## 10.7 `const` и указатели

`const` в параметре функции — это обещание:

- `const int *p` (или `const int a[]` из урока 8): **через `p` нельзя менять** данные. Читать можно, запись — ошибка компиляции `assignment of read-only location`.
- `int *const p`: **сам** `p` нельзя перенаправить, но данные через него менять можно. Встречается реже.

Правило: если функция только читает данные по указателю, делайте параметр `const`. Вызывающий сразу видит, что его данные не изменятся, а компилятор проверит это за вас.

## 10.8 `void *`, указатели на функции и `qsort`

### Указатели на функции

У функций тоже есть адреса, а переменная, хранящая такой адрес, — **указатель на функцию**:

```c
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int mul(int a, int b) {
    return a * b;
}

int main(void) {
    int (*op)(int, int) = add;     // op указывает на «функцию от двух int, возвращающую int»
    printf("%d\n", op(3, 4));      // 7
    op = mul;                      // переключаемся на другую функцию
    printf("%d\n", op(3, 4));      // 12
    return 0;
}
```

Запись выглядит странно: в `int (*op)(int, int)` часть `(*op)` говорит, что `op` — указатель, а `(int, int)` и начальный `int` — на какую функцию он указывает. Имя функции само по себе (без скобок) — это её адрес.

### Сортировка с `qsort`

`qsort` из стандартной библиотеки (`<stdlib.h>`) сортирует массивы **любого типа** и гораздо быстрее пузырька. Так как она не знает, что за элементы в массиве, вы даёте ей **функцию сравнения**, которая говорит, какой из двух элементов идёт первым:

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int compare_ints(const void *a, const void *b) {
    int x = *(const int *)a;          // сначала превращаем void * в int *, потом берём значение
    int y = *(const int *)b;
    return (x > y) - (x < y);         // -1, если x < y; 0, если равны; 1, если x > y
}

int compare_words(const void *a, const void *b) {
    return strcmp((const char *)a, (const char *)b);
}

int main(void) {
    int nums[] = {42, 7, 19, -3, 7};
    int n = sizeof nums / sizeof nums[0];
    qsort(nums, n, sizeof nums[0], compare_ints);    // массив, количество, размер элемента, сравнение
    for (int i = 0; i < n; i++) {
        printf("%d ", nums[i]);
    }
    printf("\n");

    char words[][10] = {"pear", "apple", "fig", "banana"};
    qsort(words, 4, sizeof words[0], compare_words);
    for (int i = 0; i < 4; i++) {
        printf("%s ", words[i]);
    }
    printf("\n");
    return 0;
}
```

- **`void *`** — «универсальный указатель»: он может хранить адрес данных любого типа, но тип ему неизвестен, поэтому **применить к нему `*` напрямую нельзя** — сначала приведите к конкретному типу указателя, например `(const int *)a`.
- У функции сравнения всегда вид `int имя(const void *a, const void *b)`. Верните отрицательное число, если `a` должен идти раньше `b`, положительное — если позже, и 0, если они равны.
- Почему не просто `return x - y;`? Для очень больших или очень маленьких `x` и `y` вычитание может **переполниться** (урок 3) и дать неверный знак. `(x > y) - (x < y)` не переполняется никогда.
- Чтобы сортировать по убыванию, обратите сравнение, например `return compare_ints(b, a);`.

## 10.9 Частые ошибки

| Ошибка | Что будет | Как правильно |
|--------|-----------|---------------|
| `int *p; *p = 1;` (дикий указатель) | падение или испорченные данные | при определении инициализировать `&x` или `NULL` |
| чтение или запись через `NULL` | ошибка сегментации | сначала проверить `if (p != NULL)` |
| возврат адреса локальной переменной | висячий указатель | вернуть значение, принять указатель от вызывающего или `malloc` (урок 11) |
| забыт `&` или лишний `*` | предупреждение `makes pointer from integer without a cast` | чётко различать `x`, `&x`, `p` и `*p` |
| `int* a, b;` | `b` — не указатель | `int *a, *b;` |
| изменение строкового литерала | ошибка сегментации | если нужно менять — `char s[] = "..."`, иначе — `const char *` |
| `sizeof` параметра-массива внутри функции | получается размер указателя (8) | передавать длину параметром |

## 10.10 Итоги

- У каждой переменной есть адрес; `&x` берёт его, `%p` выводит.
- `int *p = &x;` определяет указатель на `x`; `*p` — это сам `x`, для чтения и записи.
- Указатели в параметрах позволяют функции менять переменные вызывающего (`swap`) и «возвращать» несколько результатов.
- Инициализируйте указатели; `NULL` значит «никуда не указывает» — проверяйте перед использованием; не возвращайте адреса локальных переменных.
- Имя массива превращается в адрес первого элемента; `p + 1` сдвигается на один элемент; `a[i]` — это `*(a + i)`; параметр `int a[]` — это `int *a`.
- `strchr`/`strstr` возвращают указатели; `strtol` сообщает, где остановилась, через указатель `end`; строковые литералы только для чтения — указывайте на них через `const char *`.
- `const int *p` обещает не менять данные через `p`.
- `void *` — универсальный указатель, его нужно приводить перед использованием; имя функции — её адрес; `qsort` с функцией сравнения `int cmp(const void *a, const void *b)` сортирует любой массив.

### Задание 5: Разворот строки двумя указателями

Напишите функцию `void reverse(char *s)`, которая разворачивает строку на месте двумя указателями: один идёт от начала, другой — от конца. Прочитайте английское слово и выведите его задом наперёд.

```text
Пример ввода: pointer
Пример вывода: retniop
```

<details>
<summary>Подсказка</summary>

`char *left = s;`, `char *right = s + strlen(s) - 1;`; пока `left < right`, меняйте местами `*left` и `*right`, затем `left++` и `right--`. Не забудьте про пустую строку.
</details>

### Задание 6: Что выведет программа

```c
#include <stdio.h>

int main(void) {
    int a[] = {1, 2, 3, 4};
    int *p = a + 1;
    *p = 20;
    p++;
    *p += 10;
    printf("%d %d %d %d\n", a[0], a[1], a[2], a[3]);
    printf("%td\n", p - a);

    int x = 5;
    int *q = &x;
    *q = *q * 2;
    printf("%d\n", x);
    return 0;
}
```

<details>
<summary>Ответ и разбор</summary>

Сначала `p` указывает на `a[1]` и делает его 20; после `p++` он указывает на `a[2]`, к которому прибавляется 10 — получается 13. `p - a` равно 2. `q` указывает на `x`, так что `*q = *q * 2` — это `x = x * 2`. Вывод:

```text
1 20 13 4
2
10
```
</details>

### Задание 7: Где тут 3?

```c norun
int x = 3;
int *p = &x;
```

Какое выражение равно `3`?

- `p`
- `*p`
- `&p`
- `&x`

<details>
<summary>Ответ и разбор</summary>

`*p` — переменная, на которую указывает `p`, то есть `x`, и её значение 3. `p` и `&x` — адрес `x`, а `&p` — адрес самой переменной-указателя `p`.
</details>
