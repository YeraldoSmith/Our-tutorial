## 6.1 Цикл while

```c
#include <stdio.h>

int main(void) {
    int i = 1;
    while (i <= 5) {             // пока условие истинно — выполняем тело и снова проверяем
        printf("шаг %d\n", i);
        i++;                     // не забудьте менять i, иначе условие будет истинно вечно
    }
    printf("после цикла i = %d\n", i);
    return 0;
}
```

Как он работает: проверить условие → если истинно, выполнить код в фигурных скобках → вернуться и проверить снова… пока условие не станет ложным и цикл не закончится.

**Бесконечный цикл**: если условие всегда истинно (скажем, забыли `i++`), цикл не закончится никогда. В терминале **Ctrl+C** принудительно останавливает программу; в учебной программе нажмите «Стоп».

## 6.2 Цикл for

«Считать отсюда досюда» — самый частый цикл, и `for` записывает три его части в одну строку:

```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 5; i++) {
        printf("%d ", i);
    }
    printf("\n");

    for (int i = 10; i > 0; i -= 3) {    // обратный отсчёт с шагом 3
        printf("%d ", i);
    }
    printf("\n");
    return 0;
}
```

```text
for (инициализация; условие; действие после каждого шага) {
    тело
}
```

Это в точности то же самое, что такой `while`:

```c norun
int i = 1;            // инициализация (один раз)
while (i <= 5) {      // условие
    printf("%d ", i); // тело
    i++;              // действие после каждого шага
}
```

Переменная, объявленная в скобках `for` (`int i`), существует только внутри цикла и исчезает после него.

## 6.3 do … while: хотя бы один раз

`do … while` сначала выполняет тело и **потом** проверяет условие, поэтому тело выполняется хотя бы один раз. Идеально для «спрашивать, пока ввод не станет правильным»:

```c input="-3\n150\n42"
#include <stdio.h>

int main(void) {
    int age = 0;
    do {
        printf("Введите возраст (0–120): ");
        scanf("%d", &age);
    } while (age < 0 || age > 120);       // обратите внимание на точку с запятой в конце
    printf("\nвозраст: %d\n", age);
    return 0;
}
```

## 6.4 break и continue

- **`break`**: немедленно выйти из всего цикла;
- **`continue`**: пропустить остаток этого шага и начать следующий.

```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 10; i++) {
        if (i % 3 == 0) {
            continue;              // пропускаем кратные 3
        }
        if (i > 8) {
            break;                 // после 8 — стоп
        }
        printf("%d ", i);
    }
    printf("\n");                  // вывод: 1 2 4 5 7 8
    return 0;
}
```

Распространённый приём — «бесконечный цикл, из которого выходим через `break` по условию»:

```c input="5 12 -1 7"
#include <stdio.h>

int main(void) {
    int sum = 0, x = 0;
    while (true) {
        scanf("%d", &x);
        if (x < 0) {
            break;                 // на первом отрицательном числе останавливаемся
        }
        sum += x;
    }
    printf("сумма: %d\n", sum);    // 17
    return 0;
}
```

## 6.5 Типичные приёмы с циклами

**Сумма и подсчёт**:

```c
#include <stdio.h>

int main(void) {
    int sum = 0, count = 0;
    for (int i = 1; i <= 100; i++) {
        if (i % 7 == 0) {
            sum += i;              // накапливаем
            count++;               // считаем
        }
    }
    printf("чисел, кратных 7, от 1 до 100: %d, их сумма %d\n", count, sum);
    return 0;
}
```

**Разбор целого числа по цифрам**: `% 10` даёт последнюю цифру, `/ 10` её отбрасывает:

```c
#include <stdio.h>

int main(void) {
    int n = 2025;
    int digits = 0, digit_sum = 0, reversed = 0;
    while (n > 0) {
        int last = n % 10;         // последняя цифра
        digit_sum += last;
        reversed = reversed * 10 + last;
        n /= 10;                   // отбрасываем последнюю цифру
        digits++;
    }
    printf("цифр: %d, сумма цифр %d, наоборот %d\n", digits, digit_sum, reversed);
    return 0;
}
```

**Проверка на простоту**:

```c
#include <stdio.h>

int main(void) {
    int n = 97;
    bool prime = n >= 2;
    for (int d = 2; d * d <= n; d++) {    // достаточно проверить до √n
        if (n % d == 0) {
            prime = false;
            break;                         // одного делителя достаточно
        }
    }
    printf("%d %sпростое\n", n, prime ? "" : "не ");
    return 0;
}
```

## 6.6 Вложенные циклы

Цикл может содержать другой цикл. На каждый шаг внешнего цикла внутренний проходит целиком. Таблица умножения:

```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= i; j++) {
            printf("%dx%d=%-3d", j, i, i * j);
        }
        printf("\n");
    }
    return 0;
}
```

Рисуем узор циклами:

```c
#include <stdio.h>

int main(void) {
    int n = 4;
    for (int row = 1; row <= n; row++) {
        for (int s = 0; s < n - row; s++) {
            printf(" ");                  // сначала пробелы
        }
        for (int k = 0; k < 2 * row - 1; k++) {
            printf("*");                  // потом звёздочки
        }
        printf("\n");
    }
    return 0;
}
```

> [!TIP]
> Секрет узоров: выразите «сколько пробелов и сколько звёздочек в строке `row`» формулами через `row` (например, `n - row` и `2 * row - 1`), а потом выведите их циклами.

Обратите внимание: `break` выходит только из **того цикла, в котором он стоит**, а не из внешних.

## 6.7 Ошибки на единицу

Цикл, выполняющийся на раз больше или меньше, — самая частая ошибка вообще, **ошибка на единицу** (off-by-one error):

```c norun
for (int i = 0; i <= 10; i++) { ... }   // 11 раз (от 0 до 10)
for (int i = 0; i < 10; i++) { ... }    // 10 раз (от 0 до 9) ← самая распространённая запись в C
for (int i = 1; i <= 10; i++) { ... }   // 10 раз (от 1 до 10)
```

Если сомневаетесь, пройдите цикл на бумаге с крошечными числами (1, 2, 3) или выведите `i` через `printf` внутри цикла.

## 6.8 Итоги

- `while (условие) { ... }` сначала проверяет; `do { ... } while (условие);` выполняется хотя бы раз.
- `for (инициализация; условие; изменение) { ... }` подходит для «отсюда досюда»; переменные, объявленные в `for`, существуют только в цикле.
- `break` выходит из текущего цикла, `continue` переходит к следующему шагу; `while (true) { ... if (...) break; }` — распространённый приём.
- Типичные приёмы: накопление, подсчёт, поиск максимума, `% 10` и `/ 10` для разбора по цифрам, `d * d <= n` для проверки на простоту.
- Вложенные циклы: на каждый шаг внешнего цикла внутренний проходит целиком; для узоров сначала найдите правило для каждой строки.
- Остерегайтесь бесконечных циклов (Ctrl+C останавливает) и ошибок на единицу (`<` или `<=`?).

### Задание 6: Что выведет программа

```c
#include <stdio.h>

int main(void) {
    int i = 0;
    while (i < 10) {
        i += 3;
        if (i == 6) {
            continue;
        }
        printf("%d ", i);
    }
    printf("\n");
    for (int j = 5; j > 0; j--) {
        if (j == 2) break;
        printf("%d", j);
    }
    printf("\n");
    return 0;
}
```

<details>
<summary>Ответ и разбор</summary>

`while`: i становится 3 (выводится), 6 (`continue` пропускает вывод), 9 (выводится), 12 (выводится, затем 12 < 10 ложно, и цикл заканчивается). Первая строка: `3 9 12 `. `for`: при j = 5, 4, 3 выводится число, при j = 2 — `break`. Вторая строка: `543`.
</details>
