## 3.1 Арифметика

```c
#include <stdio.h>

int main(void) {
    int a = 17, b = 5;
    printf("%d + %d = %d\n", a, b, a + b);
    printf("%d - %d = %d\n", a, b, a - b);
    printf("%d * %d = %d\n", a, b, a * b);
    printf("%d / %d = %d\n", a, b, a / b);      // целочисленное деление: 3, дробная часть просто отбрасывается
    printf("%d %% %d = %d\n", a, b, a % b);     // остаток: 2
    return 0;
}
```

### Целочисленное деление: самый частый «сюрприз»

В C **при делении целого на целое получается целое**: дробная часть отсекается (округление к 0), а не округляется до ближайшего:

| Выражение | Результат | Пояснение |
|-----------|-----------|-----------|
| `7 / 2` | `3` | не 3.5 |
| `-7 / 2` | `-3` | отсечение к 0 (не -4) |
| `7 % 3` | `1` | остаток |
| `-7 % 3` | `-1` | знак остатка совпадает со знаком делимого |
| `7.0 / 2` | `3.5` | если хотя бы одно число дробное, деление дробное |

Это сильно отличается от Python (там `7 / 2` — это 3.5, а `-7 // 2` — это -4).

Остаток `%` очень полезен: проверка на чётность (`n % 2 == 0`), последняя цифра (`n % 10`), циклические счётчики (`i % 7` — день недели)…

## 3.2 Преобразование типов

Чтобы получить дробный результат из двух целых, сначала **преобразуйте** одно из них в `double`:

```c
#include <stdio.h>

int main(void) {
    int total = 17, count = 5;
    double wrong = total / count;               // сначала целочисленное деление даёт 3, потом это 3.0
    double right = (double)total / count;       // сначала total становится 17.0, потом дробное деление
    printf("%.2f %.2f\n", wrong, right);        // 3.00 3.40

    double price = 9.99;
    int whole = (int)price;                     // дробное в целое: дробная часть отсекается (не округляется)
    printf("%d\n", whole);                      // 9
    return 0;
}
```

`(тип)значение` — это **приведение типа** (cast). Посмотрите на строку с `wrong`: сначала вычисляется правая часть `total / count` (целочисленное деление, результат 3), и лишь **потом** она присваивается `double` — к этому моменту дробная часть давно потеряна.

Некоторые преобразования C делает сам: когда `int` и `double` встречаются в одной операции, `int` превращается в `double`; при присваивании `double` переменной `int` дробная часть отсекается (с `-Wextra` компилятор иногда предупреждает).

## 3.3 Приоритет

Как в математике: сначала умножение и деление, потом сложение и вычитание, а скобки — в первую очередь:

```c
#include <stdio.h>

int main(void) {
    printf("%d\n", 2 + 3 * 4);       // 14
    printf("%d\n", (2 + 3) * 4);     // 20
    printf("%d\n", 10 - 4 - 3);      // 3: одинаковый уровень — слева направо
    printf("%d\n", 2 * 3 % 4);       // 2: * / % на одном уровне, слева направо: 6 % 4
    return 0;
}
```

В C десятки операторов и длинная таблица приоритетов. **Если сомневаетесь — ставьте скобки**: программу они не замедляют, а код делают понятнее.

## 3.4 Сокращённое присваивание, инкремент и декремент

```c
#include <stdio.h>

int main(void) {
    int score = 10;
    score += 5;      // score = score + 5    → 15
    score -= 3;      // score = score - 3    → 12
    score *= 2;      // score = score * 2    → 24
    score /= 5;      // score = score / 5    → 4 (целочисленное деление)
    score %= 3;      // score = score % 3    → 1
    printf("%d\n", score);

    int n = 5;
    n++;             // инкремент: n = n + 1 → 6
    n--;             // декремент: n = n - 1 → 5
    printf("%d\n", n);

    int a = 5;
    int b = a++;     // постфиксный: b получает старое значение a (5), потом a увеличивается на 1
    int c = ++a;     // префиксный: сначала a увеличивается (до 7), потом c получает новое значение
    printf("a=%d b=%d c=%d\n", a, b, c);   // a=7 b=5 c=7
    return 0;
}
```

> [!WARNING]
> Не изменяйте одну переменную больше одного раза в одном выражении, как в `i = i++ + ++i;`. В C это **неопределённое поведение**, и разные компиляторы могут дать совсем разные результаты. Пишите `++` отдельной инструкцией или только в циклах `for` (урок 6).

## 3.5 Сравнение

Сравнение даёт **истину (1)** или **ложь (0)**:

| Оператор | Смысл |
|----------|-------|
| `==` | равно (два знака равенства!) |
| `!=` | не равно |
| `<`, `>` | меньше, больше |
| `<=`, `>=` | меньше или равно, больше или равно |

```c
#include <stdio.h>

int main(void) {
    int x = 5;
    printf("%d %d %d\n", x == 5, x != 5, x > 3);    // 1 0 1
    bool adult = x >= 18;
    printf("%d\n", adult);                           // 0
    return 0;
}
```

В C **0 означает ложь, а любое ненулевое значение — истину**. Тип `bool` просто делает смысл понятнее.

### Классическая ловушка: `=` и `==`

```c norun
int x = 5;
if (x = 0) {           // хотели проверить, равен ли x нулю, а написали присваивание!
    printf("x равен 0\n");
}
```

`x = 0` — это **присваивание**: в `x` записывается 0, а значение всего выражения — 0 (ложь), поэтому `if` никогда не выполняется, а `x` испорчен. С `-Wall` компилятор предупреждает:

```text
warning: suggest parentheses around assignment used as truth value [-Wparentheses]
```

## 3.6 Логические операторы

| Оператор | Смысл | Пример |
|----------|-------|--------|
| `&&` | и (истина, только если истинны обе стороны) | `age >= 6 && age <= 12` |
| `\|\|` | или (истина, если истинна хотя бы одна сторона) | `day == 6 \|\| day == 7` |
| `!` | не (отрицание) | `!finished` |

```c
#include <stdio.h>

int main(void) {
    int age = 10, day = 6;
    printf("%d\n", age >= 6 && age <= 12);     // 1: школьный возраст
    printf("%d\n", day == 6 || day == 7);      // 1: выходной
    printf("%d\n", !(age > 18));               // 1

    int count = 0;
    if (count != 0 && 100 / count > 5) {      // короткое замыкание: при count == 0 правая часть не вычисляется
        printf("среднее больше 5\n");
    }
    printf("деления на 0 не было\n");
    return 0;
}
```

**Вычисление по короткой схеме** (short-circuit): если левая часть `&&` ложна, результат обязательно ложен, и правая часть **не вычисляется**; если левая часть `||` истинна, правая тоже не вычисляется. Пример использует это, чтобы избежать деления на 0.

> [!NOTE]
> Нельзя писать `6 <= age <= 12`, как в математике! C сначала вычислит `6 <= age` (0 или 1), а потом сравнит этот 0 или 1 с 12 — это почти всегда истина. Пишите `age >= 6 && age <= 12`.

## 3.7 Математические функции: `<math.h>`

```c
#include <stdio.h>
#include <math.h>

int main(void) {
    printf("%.4f\n", sqrt(2.0));        // квадратный корень
    printf("%.1f\n", pow(2, 10));       // 2 в степени 10: 1024.0
    printf("%.1f\n", fabs(-3.5));       // модуль (fabs для дробных; abs для целых, в <stdlib.h>)
    printf("%.1f %.1f %.1f\n", round(2.5), floor(-2.5), ceil(2.1));   // округление, вниз, вверх
    double pi = acos(-1.0);             // в стандартном C нет константы π, её можно вычислить так
    printf("%.6f\n", pi);
    printf("%.4f\n", sin(pi / 6));      // тригонометрия работает в радианах: sin(30°) = 0.5
    return 0;
}
```

> [!TIP]
> При компиляции программы с `<math.h>` через gcc в Linux добавьте в конец `-lm` (подключить математическую библиотеку): `gcc main.c -o main -lm`. Учебная программа добавляет его сама.

## 3.8 Дробные числа неточны: `0.1 + 0.2 != 0.3`

```c
#include <stdio.h>
#include <math.h>

int main(void) {
    double s = 0.1 + 0.2;
    printf("%.17f\n", s);                       // 0.30000000000000004
    printf("%d\n", s == 0.3);                   // 0: не равно!
    printf("%d\n", fabs(s - 0.3) < 1e-9);       // 1: разница ничтожна — считаем равными
    return 0;
}
```

Компьютер хранит дробные числа в двоичном виде, а 0.1 в двоичной системе — бесконечная периодическая дробь, поэтому сохраняется только приближение (как 1/3 в десятичной записи — лишь 0.333…). Поэтому:

- **не сравнивайте два дробных числа через `==`**, проверяйте, достаточно ли мала их разница;
- **не храните деньги в дробных числах**: храните копейки целым числом, например 12.50 руб. — это 1250.

## 3.9 Побитовые операторы (первое знакомство)

C умеет работать прямо с отдельными **двоичными битами** целых чисел. Это часто нужно во встраиваемых системах, сетевых протоколах и обработке изображений:

```c
#include <stdio.h>

int main(void) {
    int a = 13;   // двоичное 1101
    int b = 6;    // двоичное 0110
    printf("%d\n", a & b);    // побитовое И:   0100 = 4
    printf("%d\n", a | b);    // побитовое ИЛИ: 1111 = 15
    printf("%d\n", a ^ b);    // исключающее ИЛИ: 1011 = 11
    printf("%d\n", 1 << 5);   // сдвиг влево на 5: 100000 = 32, то есть умножение на 2⁵
    printf("%d\n", 40 >> 2);  // сдвиг вправо на 2: то есть деление на 4 → 10
    printf("%d\n", (a >> 2) & 1);   // бит номер 2 числа a (считая с 0): 1
    return 0;
}
```

Не путайте `&` (побитовое И) с `&&` (логическим И), а `|` — с `||`. Курс «Ассемблер» в этой программе подробнее рассказывает о двоичной системе.

## 3.10 Итоги

- `+ - * / %`; **целое, делённое на целое, даёт целое** (отсечение к 0); знак `%` совпадает со знаком делимого.
- Для дробного результата: `(double)a / b`; преобразование дробного в целое отсекает дробную часть.
- Приоритет: умножение и деление раньше сложения и вычитания; если сомневаетесь — скобки.
- `+=`, `-=`, `*=`…; `++`, `--` (префиксный: сначала изменить, потом использовать; постфиксный — наоборот); не изменяйте одну переменную дважды в одном выражении.
- Сравнения `== != < > <= >=` дают 1 или 0; **`=` присваивает, `==` сравнивает**; 0 — ложь, ненулевое — истина.
- Логические `&& || !` вычисляются по короткой схеме; проверка диапазона пишется как `a <= x && x <= b`.
- `<math.h>`: `sqrt`, `pow`, `fabs`, `round`, `floor`, `ceil`, тригонометрия (в Linux добавляйте `-lm`).
- У дробных чисел есть погрешность: сравнивайте через `fabs(a - b) < 1e-9`, деньги храните целыми.
- Побитовые `& | ^ ~ << >>` работают прямо с двоичными битами.

### Задание 5: Что выведет программа

```c
#include <stdio.h>

int main(void) {
    printf("%d %d %d\n", 7 / 2, -7 / 2, 7 % -3);
    printf("%.1f %d\n", 7 / 2 * 1.0, (int)3.99);
    int a = 5;
    int b = a++;
    printf("%d %d\n", a, b);
    return 0;
}
```

<details>
<summary>Ответ и разбор</summary>

Первая строка: `7 / 2` — это 3; `-7 / 2` отсекается к 0 и даёт -3; у `7 % -3` знак делимого 7, получается 1. Вторая строка: `7 / 2` сначала вычисляется как целое 3, умножение на 1.0 даёт 3.0; `(int)3.99` отсекается до 3. Третья строка: `b = a++` отдаёт b значение 5, затем a становится 6. Вывод: `3 -3 1`, `3.0 3`, `6 5`.
</details>

### Задание 6: `=` или `==`?

Что произойдёт после `int x = 5; if (x = 0) { ... }`?

- код внутри `if` выполнится, а `x` останется 5
- код внутри `if` не выполнится, а `x` станет равен 0
- программа не скомпилируется
- код внутри `if` выполнится, а `x` станет равен 0

<details>
<summary>Ответ и разбор</summary>

`x = 0` — присваивание: `x` становится 0, а значение выражения — 0 (ложь), поэтому код внутри `if` не выполняется. Для сравнения пишите `x == 0`.
</details>
