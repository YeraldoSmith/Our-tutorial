## 5.1 Инструкция if

```c input="75"
#include <stdio.h>

int main(void) {
    int score = 0;
    printf("Баллы: ");
    scanf("%d", &score);
    if (score >= 60) {
        printf("Зачёт!\n");
    }
    printf("конец программы\n");
    return 0;
}
```

- условие пишется в **круглых скобках**, они обязательны;
- если условие истинно (не 0), выполняется код в фигурных скобках; если ложно — пропускается;
- в отличие от Python, принадлежность кода к `if` определяют `{ }`, а не отступы.

## 5.2 else и else if

```c input="85"
#include <stdio.h>

int main(void) {
    int score = 0;
    scanf("%d", &score);
    if (score >= 90) {
        printf("отлично\n");
    } else if (score >= 80) {
        printf("хорошо\n");
    } else if (score >= 60) {
        printf("удовлетворительно\n");
    } else {
        printf("неудовлетворительно\n");
    }
    return 0;
}
```

Условия проверяются сверху вниз, и **выполняется только первая истинная ветка**, остальные пропускаются. Поэтому порядок важен: поставьте `score >= 60` первым — и даже 90 баллов окажутся лишь «удовлетворительно».

## 5.3 Всегда пишите фигурные скобки

Если `if` управляет одной инструкцией, C разрешает опустить фигурные скобки. Но это источник множества ошибок:

```c norun
if (balance < price)
    printf("недостаточно средств\n");
    return 1;                // выглядит как часть if, но это не так! Выполняется всегда
```

Без фигурных скобок `if` управляет только **одной следующей инструкцией**. Вторая строка с отступом в `if` не входит — программа каждый раз выполняет `return 1;`. С `-Wall` компилятор предупреждает:

```text
warning: this 'if' clause does not guard... [-Wmisleading-indentation]
```

В 2014 году знаменитая уязвимость в системах Apple («goto fail») возникла именно так: одна лишняя строка без фигурных скобок привела к тому, что проверка SSL-сертификата пропускалась. **Возьмите за правило: после `if`, `else`, `for` и `while` всегда пишите фигурные скобки.**

## 5.4 Классическая ловушка: точка с запятой после if

```c norun
if (x > 100);              // посмотрите на эту точку с запятой!
{
    printf("x большое\n"); // выполняется при любом x
}
```

Точка с запятой после `if (x > 100)` сама по себе — «пустая инструкция», и `if` управляет именно ею; фигурные скобки ниже — обычный блок, который выполняется всегда. Компилятор предупреждает `suggest braces around empty body in an 'if' statement`.

## 5.5 Вложенные и составные условия

Внутри `if` может быть другой `if`:

```c input="2024"
#include <stdio.h>

int main(void) {
    int year = 0;
    scanf("%d", &year);
    // високосный год: делится на 4, но не на 100, либо делится на 400
    if (year % 4 == 0) {
        if (year % 100 != 0 || year % 400 == 0) {
            printf("%d — високосный год\n", year);
        } else {
            printf("%d — не високосный год\n", year);
        }
    } else {
        printf("%d — не високосный год\n", year);
    }
    return 0;
}
```

Глубокую вложенность трудно читать. Часто условия можно объединить в одно с помощью логических операторов:

```c norun
bool leap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
```

## 5.6 switch: выбор одного из многих

Когда нужно выбрать один из многих вариантов по **значению одного целого числа (или символа)**, `switch` понятнее длинной цепочки `else if`:

```c input="3"
#include <stdio.h>

int main(void) {
    int day = 0;
    scanf("%d", &day);
    switch (day) {
        case 1:
            printf("понедельник\n");
            break;
        case 2:
            printf("вторник\n");
            break;
        case 3:
            printf("среда\n");
            break;
        case 6:
        case 7:                        // у 6 и 7 общий код
            printf("выходной!\n");
            break;
        default:                       // выполняется, если ничего выше не подошло
            printf("другой день\n");
            break;
    }
    return 0;
}
```

- значение в `switch (выражение)` должно быть **целым числом или символом** (не дробным и не строкой);
- после каждого `case` стоит константа; выполнение начинается оттуда, где она равна значению выражения;
- **`break` выходит из `switch`**. Если его забыть, программа **продолжит выполнять код следующего `case`** — это **проваливание** (fall through);
- после `case 6:` выше ничего нет — это намеренное проваливание, чтобы 6 и 7 выполняли один и тот же код.

> [!WARNING]
> Забытый `break` — самая частая ошибка в `switch`. С `-Wextra` компилятор предупреждает `this statement may fall through`. Если проваливание задумано, в C23 можно написать `[[fallthrough]];`, чтобы это было видно.

```c
#include <stdio.h>

int main(void) {
    char op = '*';
    int a = 6, b = 7;
    switch (op) {
        case '+': printf("%d\n", a + b); break;
        case '-': printf("%d\n", a - b); break;
        case '*': printf("%d\n", a * b); break;
        case '/':
            if (b != 0) {
                printf("%d\n", a / b);
            } else {
                printf("на 0 делить нельзя\n");
            }
            break;
        default:  printf("неизвестный оператор %c\n", op); break;
    }
    return 0;
}
```

## 5.7 Тернарный оператор `? :`

`условие ? значение1 : значение2` даёт значение1, если условие истинно, иначе значение2. Удобно для коротких выборов «одно из двух»:

```c
#include <stdio.h>

int main(void) {
    int a = 7, b = 12;
    int bigger = (a > b) ? a : b;
    printf("большее: %d\n", bigger);

    int n = 3;
    printf("%d — %s число\n", n, (n % 2 == 0) ? "чётное" : "нечётное");
    int stock = 0;
    printf("%s\n", stock > 0 ? "есть в наличии" : "нет в наличии");
    return 0;
}
```

Не вкладывайте тернарные операторы друг в друга слишком глубоко — в этот момент `if` уже понятнее.

## 5.8 Итоги

- `if (условие) { ... } else if (условие) { ... } else { ... }`: проверка сверху вниз, выполняется только первая истинная ветка.
- **Всегда пишите фигурные скобки**: без них `if` управляет лишь одной инструкцией; отступы для C ничего не значат.
- Точка с запятой после `if (...);` отключает условие.
- `switch` выбирает вариант по целому числу или символу; заканчивайте каждый `case` словом `break`, иначе будет проваливание; `default` обрабатывает всё остальное.
- `условие ? a : b` — короткий выбор одного из двух.

### Задание 5: Что выведет программа

```c
#include <stdio.h>

int main(void) {
    int x = 5;
    if (x > 10)
        printf("A\n");
        printf("B\n");
    if (x > 3) printf("C\n"); else printf("D\n");
    switch (x) {
        case 5: printf("E\n");
        case 6: printf("F\n"); break;
        default: printf("G\n");
    }
    return 0;
}
```

<details>
<summary>Ответ и разбор</summary>

У первого `if` нет фигурных скобок, и он управляет только `printf("A\n")`; `x > 10` ложно, поэтому A не выводится, но B от `if` не зависит и выводится. `x > 3` истинно — выводится C. `switch` начинает с `case 5`, выводит E, `break` нет — проваливается в `case 6`, выводит F и выходит по `break`. Итого четыре строки: B, C, E, F.
</details>
