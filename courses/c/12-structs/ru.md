## 12.1 Структуры: связанные данные вместе

У точки есть координаты x и y; у ученика — имя, возраст и оценка. Если хранить их в отдельных переменных, их легко перепутать. **Структура** (structure) объединяет несколько связанных значений в новый тип:

```c
#include <stdio.h>

struct point {               // определяем новый тип: struct point
    int x;                   // у него два «поля»: x и y
    int y;
};                           // обратите внимание на точку с запятой!

int main(void) {
    struct point a = {3, 4};               // инициализация по порядку
    struct point b = {.y = 10, .x = -2};   // по именам полей: порядок любой, пропущенные поля равны 0
    a.x = a.x + 1;                         // к полям обращаются через .
    printf("a = (%d, %d)\n", a.x, a.y);
    printf("b = (%d, %d)\n", b.x, b.y);
    printf("struct point занимает %zu байт\n", sizeof(struct point));
    return 0;
}
```

- `struct point { ... };` только **определяет тип** (это как чертёж) и не создаёт переменных; `struct point a;` создаёт переменную.
- После `}`, закрывающей определение, **обязательна точка с запятой**. Если её забыть, GCC выдаст загадочную ошибку: `expected ';', identifier or '(' before 'int'`.
- Каждое поле ведёт себя как обычная переменная: `a.x` можно присваивать, использовать в вычислениях и передавать в `scanf` (`scanf("%d", &a.x)`).

> [!NOTE]
> Иногда структура больше, чем сумма её полей. Например, `struct { char c; int n; }` обычно занимает 8 байт, а не 5: компилятор вставляет между полями байты «выравнивания», чтобы `int` начинался с адреса, кратного 4, — так процессор читает быстрее.

## 12.2 `typedef`: короткое имя

Писать каждый раз `struct point` утомительно. `typedef` даёт типу другое имя:

```c
#include <stdio.h>
#include <string.h>

typedef struct {
    char name[32];
    int age;
    double score;
} Student;                         // дальше пишем просто Student

int main(void) {
    Student s = {"Ada", 20, 95.5};
    Student t;
    strcpy(t.name, "Linus");       // полю-массиву char присваивают через strcpy (урок 9)
    t.age = 21;
    t.score = 88.0;
    printf("%-8s %3d %6.1f\n", s.name, s.age, s.score);
    printf("%-8s %3d %6.1f\n", t.name, t.age, t.score);
    return 0;
}
```

Имена собственных типов принято начинать с заглавной буквы (`Student`, `Point`), чтобы отличать их от имён переменных.

## 12.3 Присваивание, сравнение и передача структур

```c
#include <stdio.h>
#include <math.h>

typedef struct {
    double x;
    double y;
} Point;

double distance(Point a, Point b) {             // по значению: функция получает копии
    double dx = a.x - b.x, dy = a.y - b.y;
    return sqrt(dx * dx + dy * dy);
}

Point midpoint(Point a, Point b) {              // структуру можно вернуть из функции
    Point m = {(a.x + b.x) / 2, (a.y + b.y) / 2};
    return m;
}

void move(Point *p, double dx, double dy) {     // по указателю: меняем структуру вызывающего
    p->x += dx;                                 // p->x — это (*p).x
    p->y += dy;
}

int main(void) {
    Point a = {0, 0}, b = {3, 4};
    printf("расстояние %.1f\n", distance(a, b));
    Point m = midpoint(a, b);
    printf("середина (%.1f, %.1f)\n", m.x, m.y);

    Point c = b;                    // структуры можно копировать целиком через =
    move(&c, 1, 1);
    printf("b = (%.1f, %.1f), c = (%.1f, %.1f)\n", b.x, b.y, c.x, c.y);
    return 0;
}
```

- **Присваивание `c = b` копирует все поля** — даже массивы внутри структуры. В этом отличие от массивов, которые присваивать нельзя вовсе.
- **Структуры нельзя сравнивать через `==`**: сравнивайте поля по одному, лучше в отдельной функции.
- Структура передаётся в функцию **по значению**: функция получает копию. Чтобы функция могла её изменить, передавайте указатель.
- К полю через указатель обращаются с помощью **`->`**: `p->x` — это `(*p).x`. Заметьте: `*p.x` — ошибка: `.` связывает сильнее `*`, так что это `*(p.x)`.
- Если структура большая (скажем, с полем-массивом из 1000 элементов), передача по значению каждый раз копирует большой кусок памяти. Поэтому даже когда функция ничего не меняет, часто пишут `const Student *s`: передаётся только адрес, а `const` обещает ничего не менять.

## 12.4 Массивы структур

Массив структур похож на таблицу: каждый элемент — строка, каждое поле — столбец. С помощью `qsort` (урок 10) его можно отсортировать по любому правилу:

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    char name[32];
    int score;
} Student;

int by_score_desc(const void *a, const void *b) {
    const Student *x = a;                  // void * можно сразу присвоить указателю другого типа
    const Student *y = b;
    if (x->score != y->score) {
        return (x->score < y->score) - (x->score > y->score);   // высокие оценки — первыми
    }
    return strcmp(x->name, y->name);       // при равных оценках — по имени
}

int main(void) {
    Student cls[] = {
        {"Mia", 88},
        {"Leo", 95},
        {"Ava", 88},
        {"Noah", 72},
    };
    int n = sizeof cls / sizeof cls[0];
    qsort(cls, n, sizeof cls[0], by_score_desc);
    for (int i = 0; i < n; i++) {
        printf("%d. %-5s %d\n", i + 1, cls[i].name, cls[i].score);
    }
    return 0;
}
```

`cls[i].name`: сначала берём элемент `i` (это `Student`), потом его поле `name`.

## 12.5 Перечисления: `enum`

Когда переменная может принимать лишь несколько фиксированных значений (день недели, сигнал светофора, состояние персонажа в игре), **перечисление** даёт каждому значению имя — это гораздо понятнее, чем 0, 1, 2:

```c
#include <stdio.h>

typedef enum {
    RED,             // 0
    YELLOW,          // 1
    GREEN,           // 2
} Light;

const char *light_name(Light l) {
    switch (l) {
        case RED:
            return "красный";
        case YELLOW:
            return "жёлтый";
        case GREEN:
            return "зелёный";
    }
    return "?";
}

Light next(Light l) {
    switch (l) {
        case RED:
            return GREEN;
        case GREEN:
            return YELLOW;
        case YELLOW:
            return RED;
    }
    return RED;
}

int main(void) {
    Light l = RED;
    for (int i = 0; i < 5; i++) {
        printf("%s ", light_name(l));
        l = next(l);
    }
    printf("\n");
    return 0;
}
```

- Значения перечисления — просто целые константы; по умолчанию они начинаются с 0 и растут на 1, но их можно задать и самому, например `enum { LOW = 1, HIGH = 10 };`. Их имена обычно пишут заглавными буквами.
- Если `switch` по перечислению пропускает какое-то значение, GCC предупреждает: `enumeration value 'GREEN' not handled in switch` — ещё одно преимущество перечислений.

## 12.6 Связные списки

Элементы массива лежат в памяти подряд, поэтому вставка в начало означает сдвиг всех остальных. **Связный список** устроен иначе: каждый элемент (**узел**) выделяется отдельно через `malloc`, и, кроме данных, в каждом узле хранится **указатель на следующий узел**:

```text
 head
  │
  ▼
┌────┬───┐    ┌────┬───┐    ┌────┬───┐
│ 40 │ ●─┼──▶ │ 30 │ ●─┼──▶ │ 20 │ ●─┼──▶ NULL
└────┴───┘    └────┴───┘    └────┴───┘
 value next
```

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *next;          // указывает на следующий узел; у последнего узла next равен NULL
} Node;

// Вставляет новый узел в начало списка и возвращает новую голову
Node *push_front(Node *head, int value) {
    Node *n = malloc(sizeof *n);
    if (n == NULL) {
        return head;            // для простоты: если malloc не удался, ничего не вставляем
    }
    n->value = value;
    n->next = head;             // новый узел указывает на прежний первый
    return n;                   // и становится новой головой
}

void print_list(const Node *head) {
    for (const Node *p = head; p != NULL; p = p->next) {   // идём по next от узла к узлу
        printf("%d -> ", p->value);
    }
    printf("NULL\n");
}

void free_list(Node *head) {
    while (head != NULL) {
        Node *next = head->next;    // сначала запоминаем следующий узел, потом освобождаем текущий
        free(head);
        head = next;
    }
}

int main(void) {
    Node *list = NULL;              // пустой список
    for (int i = 1; i <= 4; i++) {
        list = push_front(list, i * 10);
    }
    print_list(list);               // 40 -> 30 -> 20 -> 10 -> NULL
    free_list(list);
    return 0;
}
```

- Когда структура ссылается на свой же тип (`struct Node *next`), после `typedef struct` нужно дать структуре имя — `struct Node`: внутри списка полей псевдонима `Node` ещё не существует.
- Стандартный обход списка: `for (p = head; p != NULL; p = p->next)`.
- Освобождая список, **сохраняйте `next` до вызова `free`**: после `free(head)` читать `head->next` уже нельзя.
- У списков и массивов свои сильные стороны: список быстро вставляет и удаляет в начале, но чтобы найти i-й элемент, нужно считать с начала; массив мгновенно даёт любой индекс, но вставка в середину требует сдвига элементов.

## 12.7 Частые ошибки

| Ошибка | Что говорит компилятор | Как правильно |
|--------|------------------------|---------------|
| нет точки с запятой после определения структуры | `expected ';', identifier or '(' before ...` | `struct point { ... };` |
| голое имя типа без `typedef` | `unknown type name 'point'` | писать `struct point` или использовать `typedef` |
| `.` у указателя | `'p' is a pointer; did you mean to use '->'?` | `p->x` |
| `->` у переменной-структуры | `invalid type argument of '->'` | `a.x` |
| сравнение структур через `==` | `invalid operands to binary ==` | сравнивать поле за полем |
| опечатка в имени поля | `has no member named ...` | свериться с определением структуры |
| чтение `->next` после освобождения узла | использование после освобождения (сообщит проверка памяти) | сохранить `next` до `free` |

## 12.8 Итоги

- `struct имя { поля... };` определяет тип-структуру; `переменная.поле` — обращение к полю; инициализация по порядку или через `.поле = значение`.
- `typedef struct { ... } Name;` даёт короткое имя; для ссылки на себя: `typedef struct Node { ...; struct Node *next; } Node;`.
- Структуры копируются целиком через `=`, передаются и возвращаются по значению; сравнивать их через `==` нельзя.
- С указателем на структуру используйте `->`: `p->x` — это `(*p).x`; большие структуры передавайте как `const T *`.
- Массив структур + `qsort` сортирует по любому правилу.
- `enum` даёт имена набору целых констант; используйте его вместе со `switch`.
- Связный список: каждый узел — от `malloc`, узлы связаны указателями `next`, последний указывает на `NULL`; перед освобождением сохраняйте `next`.

### Задание 4: Удаление из связного списка

В первой строке — `n` (0 ≤ n ≤ 1000), во второй — `n` целых; постройте из них связный список в том же порядке (новые узлы добавляются в **конец**). В третьей строке — целое `x`. Удалите все узлы со значением `x` и выведите оставшиеся значения через пробел или `empty`, если ничего не осталось.

```text
Пример ввода:
6
3 1 3 4 3 5
3
Пример вывода: 1 4 5
```

<details>
<summary>Подсказка</summary>

При построении держите указатель `tail` на последний узел и присоединяйте новые узлы к `tail->next`. Для удаления удобнее всего «указатель на указатель»: `Node **pp = &head;`; если `(*pp)->value == x`, сохраните `Node *dead = *pp;`, сделайте `*pp = dead->next;` и `free(dead)`; иначе `pp = &(*pp)->next;`. Не забудьте в конце освободить весь список.
</details>

<!-- exercise: struct-predict -->
### Задание 5: Что выведет программа

```c
#include <stdio.h>

typedef struct {
    int a[3];
    int n;
} Box;

void set_n(Box b) {
    b.n = 99;
}

void set_n_ptr(Box *b) {
    b->n = 99;
}

int main(void) {
    Box x = {{1, 2, 3}, 3};
    Box y = x;
    y.a[0] = 100;
    set_n(x);
    printf("%d %d %d\n", x.a[0], y.a[0], x.n);
    set_n_ptr(&y);
    printf("%d\n", y.n);
    return 0;
}
```

<details>
<summary>Ответ и разбор</summary>

`Box y = x;` копирует все поля (включая массив), поэтому изменение `y.a[0]` не затрагивает `x.a[0]`. `set_n` получает копию, так что `x.n` по-прежнему 3. `set_n_ptr` меняет `y.n` через указатель. Вывод:

```text
1 100 3
99
```
</details>

<!-- exercise: arrow -->
### Задание 6: Обращение к полю

`p` — это `Point *` (указатель на структуру `Point`). Какое выражение даёт координату `x` точки, на которую он указывает?

- `p.x`
- `p->x`
- `*p.x`
- `&p->x`

<details>
<summary>Ответ и разбор</summary>

`p->x` — это `(*p).x`. В `p.x` точка применена к указателю; `*p.x` означает `*(p.x)`, потому что `.` связывает сильнее; а `&p->x` — адрес поля `x`.
</details>
