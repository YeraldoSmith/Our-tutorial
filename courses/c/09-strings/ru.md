## 9.1 Строка — это массив char, оканчивающийся `'\0'`

В C нет особого «строкового типа». Строка — это просто массив `char`, в конце которого стоит особый символ `'\0'` (символ со значением 0, **нулевой символ**), означающий «здесь строка заканчивается»:

```c
#include <stdio.h>

int main(void) {
    char a[6] = {'H', 'e', 'l', 'l', 'o', '\0'};   // записано посимвольно
    char b[] = "Hello";                            // то же самое: компилятор сам добавит '\0' в конце

    printf("%s %s\n", a, b);                       // %s выводит строку
    printf("b занимает %zu байт\n", sizeof b);     // 6: 5 букв + 1 '\0'

    for (int i = 0; b[i] != '\0'; i++) {           // идём посимвольно до '\0'
        printf("[%c]", b[i]);
    }
    printf("\n");

    b[0] = 'J';                                    // символы в массиве char можно менять
    printf("%s\n", b);                             // Jello
    b[2] = '\0';                                   // ставим '\0' в середину…
    printf("%s\n", b);                             // Je: строка здесь «закончилась»
    return 0;
}
```

```text
         b[0] b[1] b[2] b[3] b[4] b[5]
        ┌────┬────┬────┬────┬────┬────┐
"Hello" │ H  │ e  │ l  │ l  │ o  │ \0 │
        └────┴────┴────┴────┴────┴────┘
```

- `"Hello"` (двойные кавычки) — строка, `'H'` (одинарные) — один символ; это совершенно разные вещи (урок 2).
- `printf("%s", b)`, `strlen(b)` и все остальные строковые функции **читают с начала, пока не встретят `'\0'`**. Поэтому `'\0'` жизненно важен: без него функции продолжат читать за концом массива (выход за границы, урок 8).
- Значит, для строки из n символов нужен массив хотя бы из **n + 1** `char`.

## 9.2 Чтение строк

**Чтобы прочитать одно слово**, используйте `scanf("%Ns", массив)` (урок 4): чтение останавливается на пробеле или переводе строки; в качестве `N` пишите «длина массива − 1», чтобы длинный ввод не записался за конец; и **без** `&` перед именем массива.

**Чтобы прочитать целую строку** (с пробелами), используйте `fgets`:

```c input="20\nАда Лавлейс"
#include <stdio.h>
#include <string.h>

int main(void) {
    int age = 0;
    char name[50];

    printf("Возраст: ");
    scanf("%d", &age);

    int ch;                                        // выбрасываем остаток этой строки (вместе с переводом строки)
    while ((ch = getchar()) != '\n' && ch != EOF) {
    }

    printf("\nПолное имя: ");
    if (fgets(name, sizeof name, stdin) == NULL) { // читает не больше 49 байт; NULL, если прочитать нечего
        return 1;
    }
    name[strcspn(name, "\n")] = '\0';              // убираем перевод строки в конце

    printf("\n%s, возраст %d\n", name, age);
    return 0;
}
```

В этом коде три важных момента:

1. **`fgets(массив, размер, stdin)`** читает не больше «размер − 1» символов и никогда не пишет за конец. Она **читает и перевод строки `'\n'`** в конце, поэтому сразу после неё обычно пишут `name[strcspn(name, "\n")] = '\0';`, чтобы его убрать (`strcspn` возвращает позицию первого `'\n'`; если его нет, она вернёт длину строки, так что строчка безопасна в любом случае).
2. **Оставшийся перевод строки**: `scanf("%d", &age)` останавливается сразу после `20`, и перевод строки остаётся во вводе. Если ничего не делать, `fgets` тут же прочитает этот перевод строки и получит **пустую строку**. Цикл `while` читает символы по одному через `getchar()`, пока не выбросит остаток строки (вместе с переводом строки).
3. `ch` должна быть `int`, а не `char`: в конце ввода `getchar()` возвращает `EOF` (обычно -1), который не является никаким символом, и только в `int` его можно отличить от настоящих символов.

> [!WARNING]
> В старых книгах встречается `gets(name)`. Она не проверяет длину, и длинный ввод записывается за конец массива, — поэтому её **удалили из языка C**. Всегда используйте `fgets`.

## 9.3 `<string.h>`: строковые функции

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char s[50] = "hello";
    printf("длина %zu, размер массива %zu\n", strlen(s), sizeof s);   // 5 и 50

    char t[50];
    strcpy(t, s);                          // копирование: t = s не работает (массивы нельзя присваивать)
    strcat(t, ", world");                  // склейка: дописываем в конец t
    printf("%s\n", t);                     // hello, world

    if (strcmp(s, "hello") == 0) {         // сравнение содержимого: 0 значит «равны»
        printf("в s записано hello\n");
    }
    if (strcmp("apple", "banana") < 0) {   // отрицательное: первая идёт раньше по алфавиту
        printf("apple идёт раньше banana\n");
    }
    if (strstr(t, "world") != NULL) {      // поиск подстроки: NULL, если не найдена
        printf("в t есть world\n");
    }
    if (strchr(t, ',') != NULL) {          // поиск символа
        printf("в t есть запятая\n");
    }
    return 0;
}
```

| Функция | Что делает |
|---------|------------|
| `strlen(s)` | длина строки, **без** `'\0'` |
| `strcpy(d, s)` | копирует `s` в `d` (`d` должен быть достаточно большим!) |
| `strcat(d, s)` | дописывает `s` в конец `d` (`d` должен быть достаточно большим!) |
| `strcmp(a, b)` | сравнение: 0, если равны; отрицательное, если `a` идёт раньше, положительное — если позже |
| `strncmp(a, b, n)` | сравнивает только первые `n` символов, например проверка начала: `strncmp(s, "http", 4) == 0` |
| `strchr(s, c)` / `strstr(s, t)` | ищет символ `c` / подстроку `t`; `NULL`, если не нашлось (результат на самом деле указатель — урок 10) |
| `snprintf(d, size, формат, ...)` | как `printf`, но «печатает» в строку `d`, записывая не больше `size - 1` символов |

### `strcpy` и `strcat` опасны

Они **не знают, насколько велик целевой массив**, и просто пишут дальше. Если места не хватает, запись уходит за конец — отсюда берутся дыры в безопасности типа «переполнение буфера». Часть таких ошибок GCC замечает:

```text
warning: '__builtin_memcpy' writing 8 bytes into a region of size 4 overflows the destination
```

Для склейки и форматирования строк безопаснее `snprintf`: она записывает не больше `size - 1` символов плюс `'\0'`, а если результат не помещается, **обрезает** его, никогда не выходя за границы:

```c
#include <stdio.h>

int main(void) {
    char first[] = "Grace", last[] = "Hopper";
    char full[50];
    snprintf(full, sizeof full, "%s %s", first, last);   // места достаточно
    printf("[%s]\n", full);

    char tiny[8];
    snprintf(tiny, sizeof tiny, "%s %s", first, last);   // помещается только 7 символов
    printf("[%s]\n", tiny);                              // [Grace H]: безопасно обрезано
    return 0;
}
```

(При компиляции GCC предупредит, что у второго `snprintf` `output may be truncated`, — он указывает, что результат будет обрезан, а это мы и показываем.)

## 9.4 Сравнение строк: не через `==`

```c norun
char answer[10] = "yes";
if (answer == "yes") { ... }          // неправильно!
```

```text
warning: comparison with string literal results in unspecified behavior [-Waddress]
```

`answer == "yes"` сравнивает, **где две строки лежат в памяти**, а не их содержимое, и почти всегда даёт «не равны». Содержимое **всегда сравнивайте через `strcmp`**:

```c norun
if (strcmp(answer, "yes") == 0) { ... }   // правильно
```

Аналогично копируйте через `strcpy` (или `snprintf`), а не через `=`; и помните, что для равных строк `strcmp` возвращает **0**, поэтому не пишите `if (strcmp(a, b))` — это значит «не равны».

## 9.5 Посимвольная обработка: `<ctype.h>`

В `<ctype.h>` есть функции для проверки и преобразования отдельных символов:

```c
#include <stdio.h>
#include <ctype.h>

int main(void) {
    char s[] = "Hello, World 2026!";
    int letters = 0, digits = 0, spaces = 0, others = 0;

    for (int i = 0; s[i] != '\0'; i++) {
        unsigned char c = (unsigned char)s[i];   // функциям ctype нужны значения из диапазона unsigned char
        if (isalpha(c)) {
            letters++;
        } else if (isdigit(c)) {
            digits++;
        } else if (isspace(c)) {
            spaces++;
        } else {
            others++;
        }
        s[i] = (char)toupper(c);                 // в верхний регистр; не буквы не меняются
    }
    printf("%s\n", s);
    printf("букв %d, цифр %d, пробельных %d, прочих %d\n", letters, digits, spaces, others);
    return 0;
}
```

| Функция | Проверяет / делает |
|---------|--------------------|
| `isalpha(c)` | английская буква? |
| `isdigit(c)` | цифра `0`–`9`? |
| `isalnum(c)` | буква или цифра? |
| `isspace(c)` | пробельный символ (пробел, `\t`, `\n`…)? |
| `isupper(c)` / `islower(c)` | заглавная / строчная буква? |
| `toupper(c)` / `tolower(c)` | перевод в верхний / нижний регистр (не буквы возвращаются без изменений) |

> [!NOTE]
> Зачем сначала приводить к `unsigned char`? На многих платформах `char` знаковый, и байты нелатинских символов (например, русских букв) становятся **отрицательными числами**, а передавать отрицательное число в `isalpha` и подобные функции — неопределённое поведение. Приведение делает вызов безопасным.

Символы — это маленькие целые числа (урок 2), поэтому с ними можно считать. Коды цифр `'0'`–`'9'` идут подряд, так что `c - '0'` — значение цифры; латинские буквы тоже идут подряд, так что `'a' + 2` — это `'c'`:

```c
#include <stdio.h>

int main(void) {
    char number[] = "9527";
    int sum = 0;
    for (int i = 0; number[i] != '\0'; i++) {
        sum += number[i] - '0';          // '9' - '0' = 9
    }
    printf("сумма цифр: %d\n", sum);     // 23

    for (char c = 'a'; c <= 'e'; c++) {
        printf("%c", c - 'a' + 'A');     // «ручной» перевод строчных в заглавные
    }
    printf("\n");
    return 0;
}
```

## 9.6 Строки в числа и обратно

- **Строка → число**: `sscanf`, которая работает как `scanf`, но читает из строки. Её результат говорит, сколько значений удалось прочитать.
- **Число → строка**: `snprintf`.

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char text[] = "42 3.5";
    int n = 0;
    double x = 0;
    if (sscanf(text, "%d %lf", &n, &x) == 2) {        // успех, только если прочитаны оба значения
        printf("%d %.1f\n", n * 2, x * 2);
    }
    if (sscanf("abc", "%d", &n) != 1) {
        printf("\"abc\" — не целое число\n");
    }

    char date[20];
    snprintf(date, sizeof date, "%d-%02d-%02d", 2026, 3, 7);
    printf("%s, длина %zu\n", date, strlen(date));     // 2026-03-07, длина 10
    return 0;
}
```

Вам может встретиться `atoi("42")`. Она проста, но для `"abc"` молча возвращает 0, и узнать об ошибке нельзя; более аккуратной `strtol` нужны указатели, так что она подождёт до урока 10.

## 9.7 Русский текст и UTF-8

`strlen` считает **байты**, а не «буквы». В **UTF-8**, стандартной сегодня кодировке, латинские буквы занимают 1 байт, русские — 2, китайские иероглифы обычно 3, эмодзи — 4:

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char s[] = "Код C";
    printf("strlen = %zu\n", strlen(s));               // 8 = 2 + 2 + 2 + 1 + 1

    int chars = 0;
    for (int i = 0; s[i] != '\0'; i++) {
        if (((unsigned char)s[i] & 0xC0) != 0x80) {   // не «байт продолжения» — значит, начался новый символ
            chars++;
        }
    }
    printf("символов = %d\n", chars);                   // 5
    return 0;
}
```

Правило UTF-8: после первого байта символа его «байты продолжения» всегда начинаются с битов `10` (`0x80`–`0xBF`). `& 0xC0` оставляет два старших бита (битовые операции, урок 3), и каждый байт, у которого результат не равен `0x80`, начинает новый символ.

Поэтому с русским текстом нужна осторожность: разворот строки по байтам разрывает буквы на части, в `char s[4]` помещается только одна русская буква и `'\0'`, а функции вроде `toupper` работают только с латинскими буквами.

## 9.8 Массивы строк

Несколько строк можно хранить в **двумерном массиве char** — по строке в каждом ряду:

```c
#include <stdio.h>
#include <string.h>

#define COUNT 4
#define LEN 20

int main(void) {
    char names[COUNT][LEN] = {"Carol", "alice", "Bob", "Dave"};

    // сортировка пузырьком (урок 8): сравниваем через strcmp, меняем через strcpy
    for (int pass = 0; pass < COUNT - 1; pass++) {
        for (int i = 0; i < COUNT - 1 - pass; i++) {
            if (strcmp(names[i], names[i + 1]) > 0) {
                char t[LEN];
                strcpy(t, names[i]);
                strcpy(names[i], names[i + 1]);
                strcpy(names[i + 1], t);
            }
        }
    }
    for (int i = 0; i < COUNT; i++) {
        printf("%s\n", names[i]);
    }
    return 0;
}
```

`alice` оказалась последней! `strcmp` сравнивает символы по их **кодам**, а все заглавные латинские буквы (`A`–`Z` — это 65–90) идут раньше строчных (`a`–`z` — 97–122). Чтобы не учитывать регистр, переведите обе строки в нижний регистр перед сравнением.

## 9.9 Частые ошибки

| Ошибка | Что будет | Как правильно |
|--------|-----------|---------------|
| `char s[5] = "Hello";` — нет места для `'\0'` | у строки нет конца, функции читают за границей | длина хотя бы n + 1 или `char s[] = "Hello";` |
| `s = "abc";` | ошибка компиляции: массивы нельзя присваивать | `strcpy(s, "abc");` или `snprintf` |
| `if (s == "abc")` | сравниваются адреса; почти всегда ложь | `if (strcmp(s, "abc") == 0)` |
| `scanf("%s", s);` без ширины | длинный ввод пишет за границу | `scanf("%49s", s);` |
| забыли убрать `'\n'` после `fgets` | лишний перевод строки при сравнении и выводе | `s[strcspn(s, "\n")] = '\0';` |
| `fgets` сразу после `scanf("%d")` | читается пустая строка | сначала выбросить остаток строки циклом с `getchar` |
| `strcpy` / `strcat` в слишком маленький массив | переполнение буфера | рассчитать размер или взять `snprintf` |

## 9.10 Итоги

- Строка в C — массив `char`, оканчивающийся `'\0'`; `"..."` добавляет `'\0'` сам; для n символов нужно место под n + 1.
- Слово: `scanf("%49s", s)`; целая строка: `fgets(s, sizeof s, stdin)`, затем убрать `'\n'`; при смешивании `scanf` и `fgets` сначала выбросите оставшийся перевод строки.
- `<string.h>`: `strlen`, `strcpy`, `strcat`, `strcmp` (0, если равны), `strncmp`, `strchr`, `strstr`; `strcpy`/`strcat` не проверяют размер, для склейки и форматирования лучше `snprintf`.
- Сравнивайте содержимое через `strcmp`, а не `==`; копируйте через `strcpy`, а не `=`.
- `<ctype.h>`: `isalpha`, `isdigit`, `isspace`, `toupper`… — аргумент сначала приводите к `unsigned char`; `c - '0'` даёт значение цифры.
- Строки ↔ числа: `sscanf` (проверяйте результат) и `snprintf`.
- В UTF-8 русская буква занимает 2 байта; `strlen` считает байты.
- Массивы строк: `char names[N][LEN]`.

### Задание 6: Что выведет программа

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char s[10] = "abc";
    printf("%zu %zu\n", strlen(s), sizeof s);
    s[1] = '\0';
    printf("%s %zu\n", s, strlen(s));
    printf("%d\n", strcmp("cat", "car") > 0);
    return 0;
}
```

<details>
<summary>Ответ и разбор</summary>

`strlen` равна 3 (без `'\0'`), а `sizeof` — весь массив, 10. После того как `s[1]` стал `'\0'`, строка там и заканчивается: остаётся `a` длины 1. У `"cat"` и `"car"` первые два символа совпадают, а третий, `t`, больше `r`, поэтому `strcmp` возвращает положительное число, `> 0` истинно и выводится 1. Вывод:

```text
3 10
a 1
1
```
</details>

### Задание 7: Сравнение строк

Как проверить, что строки в массивах `a` и `b` совпадают по содержимому?

- `if (a == b)`
- `if (strcmp(a, b) == 0)`
- `if (strcmp(a, b))`
- `if (strlen(a) == strlen(b))`

<details>
<summary>Ответ и разбор</summary>

`strcmp` возвращает 0, когда строки одинаковы. `a == b` сравнивает адреса; `if (strcmp(a, b))` — ровно наоборот, «различаются»; а одинаковая длина ещё не значит одинаковое содержимое.
</details>
