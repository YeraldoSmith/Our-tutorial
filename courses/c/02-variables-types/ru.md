## 2.1 Объявление переменных: сначала тип

В Python `age = 12` создаёт переменную. В C переменную **нужно сначала объявить**, указав её **тип**:

```c
#include <stdio.h>

int main(void) {
    int age = 12;              // объявляем целую переменную age с начальным значением 12
    double height = 1.52;      // дробное число (двойной точности)
    char grade = 'A';          // один символ, в одинарных кавычках

    printf("возраст: %d\n", age);
    printf("рост: %f м\n", height);
    printf("оценка: %c\n", grade);

    age = age + 1;             // присваивание: меняем значение (тип менять нельзя)
    printf("в следующем году: %d\n", age);
    return 0;
}
```

Зачем указывать тип? C должен уже **во время компиляции** знать, сколько памяти нужно каждой переменной и какими инструкциями с ней считать. После объявления тип переменной **изменить нельзя**: нельзя сначала хранить в ней число, а потом строку (это **статическая типизация**).

Можно объявить сразу несколько переменных одного типа: `int a = 1, b = 2, c;`.

## 2.2 Базовые типы

| Тип | Смысл | Обычный размер | Пример |
|-----|-------|----------------|--------|
| `int` | целое число | 4 байта, примерно ±2,1 млрд | `int count = 42;` |
| `long long` | большое целое | 8 байт, примерно ±9,2 × 10¹⁸ | `long long big = 9000000000LL;` |
| `double` | дробное число (двойная точность) | 8 байт, около 15–16 значащих цифр | `double pi = 3.14159;` |
| `float` | дробное число (одинарная точность) | 4 байта, около 6–7 значащих цифр | `float f = 2.5f;` |
| `char` | один символ (на деле маленькое целое в 1 байт) | 1 байт | `char c = 'x';` |
| `bool` | истина / ложь | 1 байт | `bool ok = true;` |

> [!NOTE]
> `bool`, `true` и `false` — ключевые слова стандарта **C23**, ими можно пользоваться сразу. В старых стандартах (C99–C17) сначала нужно `#include <stdbool.h>`. Этот курс использует C23 (ключ `-std=c2x`); если старый компилятор ругается, добавьте эту строку.

`sizeof` сообщает, сколько байт занимает тип или переменная:

```c
#include <stdio.h>
#include <limits.h>
#include <float.h>

int main(void) {
    printf("char:      %zu байт\n", sizeof(char));
    printf("int:       %zu байта, диапазон от %d до %d\n", sizeof(int), INT_MIN, INT_MAX);
    printf("long long: %zu байт, максимум %lld\n", sizeof(long long), LLONG_MAX);
    printf("float:     %zu байта, около %d значащих цифр\n", sizeof(float), FLT_DIG);
    printf("double:    %zu байт, около %d значащих цифр\n", sizeof(double), DBL_DIG);
    printf("bool:      %zu байт\n", sizeof(bool));
    return 0;
}
```

В `<limits.h>` и `<float.h>` определены пределы каждого типа. Результат `sizeof` выводится через `%zu`.

> [!TIP]
> **Какой тип выбрать?** Для целых чисел обычно `int`; для значений, которые могут превысить 2,1 млрд (большие суммы в копейках, отметки времени), — `long long`; для дробных — `double` (точности `float` мало, если только не нужно экономить память).

## 2.3 Спецификаторы формата printf

Первый аргумент `printf` — **строка формата**; `%d`, `%f` и т. п. в ней — «заполнители», которые по порядку заменяются следующими аргументами:

| Спецификатор | Для | Пример → вывод |
|--------------|-----|----------------|
| `%d` | `int` | `printf("%d", 42)` → `42` |
| `%lld` | `long long` | `printf("%lld", 9000000000LL)` → `9000000000` |
| `%f` | `double` (по умолчанию 6 знаков) | `printf("%f", 3.14)` → `3.140000` |
| `%.2f` | 2 знака после точки | `printf("%.2f", 3.14159)` → `3.14` |
| `%e` | экспоненциальная запись | `printf("%e", 12345.678)` → `1.234568e+04` |
| `%c` | `char` | `printf("%c", 'A')` → `A` |
| `%s` | строка | `printf("%s", "hi")` → `hi` |
| `%x` | шестнадцатеричное целое | `printf("%x", 255)` → `ff` |
| `%zu` | результат `sizeof` | `printf("%zu", sizeof(int))` → `4` |
| `%%` | сам знак процента | |

Можно управлять и **шириной** с **выравниванием** — идеально для аккуратных таблиц:

```c
#include <stdio.h>

int main(void) {
    printf("[%5d]\n", 42);       // ширина 5, выравнивание вправо: [   42]
    printf("[%-5d]\n", 42);      // выравнивание влево:            [42   ]
    printf("[%05d]\n", 42);      // дополнение нулями:             [00042]
    printf("[%8.3f]\n", 3.14159);// ширина 8, 3 знака:             [   3.142]
    printf("[%-6s|%6s]\n", "ab", "cd");

    printf("%-8s%6s%8s\n", "item", "qty", "price");
    printf("%-8s%6d%8.2f\n", "apple", 3, 4.5);
    printf("%-8s%6d%8.2f\n", "banana", 12, 0.75);
    return 0;
}
```

> [!NOTE]
> `printf` считает ширину в **байтах**, а русская буква в UTF-8 занимает 2 байта, поэтому столбцы с кириллицей ровно не выстроятся. Для выровненных таблиц используйте латинские заголовки или считайте отступы сами.

> [!WARNING]
> **Спецификатор должен соответствовать типу.** `printf("%d", 3.14)` читает `double` как `int` и печатает бессмысленное число (это «неопределённое поведение»). К счастью, с `-Wall` компилятор предупреждает: `format '%d' expects argument of type 'int', but argument 2 has type 'double'`. **Всегда исправляйте предупреждения.**

## 2.4 Символы — это маленькие целые числа

В компьютере нет «букв», только числа. `char` на самом деле хранит целое от 0 до 127 (или от −128 до 127), а **таблица ASCII** ставит каждому числу в соответствие символ: `'A'` — 65, `'a'` — 97, `'0'` — 48.

```c
#include <stdio.h>

int main(void) {
    char c = 'A';
    printf("код символа %c равен %d\n", c, c);  // одно значение: %c — символ, %d — число
    printf("%c\n", c + 2);                       // 'A' + 2 = 67 = 'C'
    printf("%c\n", 'a' - 'A' + 'G');             // заглавную в строчную: g
    char digit = '7';
    printf("число для символа '7': %d\n", digit - '0');   // '7' - '0' = 55 - 48 = 7
    return 0;
}
```

> [!NOTE]
> `char` вмещает ровно один байт, поэтому в него помещаются только английские буквы, цифры и распространённые знаки. Русские буквы занимают в UTF-8 по 2 байта и в один `char` не помещаются; такой текст хранят в **строках** (урок 9).

## 2.5 Константы

Значение, которое никогда не меняется, — **константа**. Записать её можно несколькими способами:

```c
#include <stdio.h>

#define MAX_STUDENTS 40              // макрос препроцессора: перед компиляцией каждое MAX_STUDENTS заменяется на 40

int main(void) {
    const double PI = 3.14159265;    // const: эту переменную потом нельзя изменить
    double r = 2.0;
    printf("площадь: %.2f\n", PI * r * r);
    printf("не больше %d учеников\n", MAX_STUDENTS);
    // PI = 3;                       // если раскомментировать, будет ошибка: assignment of read-only variable 'PI'
    return 0;
}
```

- `const`: обычная переменная, но только для чтения. В современном C это предпочтительный способ: у неё есть тип, который компилятор может проверить.
- `#define`: простая текстовая замена, которую делает **препроцессор** (шаг «препроцессор» из урока 1); типа нет; имена по традиции пишут заглавными.
- В C23 появился и `constexpr` — «константы, вычислимые во время компиляции», например `constexpr int SIZE = 10;`.

У **литералов** свои правила: `10` — это `int`, `10LL` — `long long`, `3.14` — `double`, `3.14f` — `float`, `'x'` — символ, а `"x"` — строка (это не одно и то же!). Целые можно записывать в шестнадцатеричном виде `0xFF` или двоичном `0b1010` (C23), а длинные числа разделять апострофами: `1'000'000` (C23).

## 2.6 Правила именования

- только буквы, цифры и подчёркивания, и **не с цифры**: `score2` ✓, `2score` ✗;
- регистр важен: `count` и `Count` — разные переменные;
- ключевые слова использовать нельзя: `int`, `return`, `if`, `while`…;
- соглашение: переменные и функции — строчными с подчёркиваниями (`total_score`), константы-макросы — заглавными (`MAX_SIZE`);
- пишите имена латиницей в английской раскладке: русская «с» в имени выглядит как латинская «c», но это другой символ (урок 1).

## 2.7 Неинициализированные переменные: мусорные значения

В Python нельзя пользоваться переменной, которой ничего не присвоили. C позволяет объявить переменную **без начального значения**, но тогда в ней лежит **то, что осталось в этой памяти** — «мусорное значение»:

```c norun
#include <stdio.h>

int main(void) {
    int x;                  // начального значения нет
    printf("%d\n", x);      // может быть 0, а может 32765; при каждом запуске может быть разным
    return 0;
}
```

```text
warning: 'x' is used uninitialized [-Wuninitialized]
```

Это одна из самых частых ошибок в программах на C. **Возьмите за правило: всегда задавайте начальное значение при объявлении.**

## 2.8 Переполнение: у целых чисел есть пределы

У каждого целого типа есть диапазон. Что будет за его пределами?

```c
#include <stdio.h>
#include <limits.h>

int main(void) {
    unsigned char small = 255;          // unsigned: без знака, только 0–255
    small = small + 1;
    printf("255 + 1 = %d\n", small);    // 0: беззнаковое переполнение «заворачивается» к 0

    long long big = INT_MAX;            // в типе побольше переполнения нет
    big = big + 1;
    printf("INT_MAX + 1 = %lld\n", big);
    return 0;
}
```

- **беззнаковые** целые при переполнении «заворачиваются», как счётчик пробега в машине, — это поведение строго определено;
- переполнение **знакового** целого (обычного `int`) — это **неопределённое поведение** (undefined behavior): стандарт C не говорит, что произойдёт, и программа может выдать странные числа или ещё более странные ошибки. **Избегайте его**: оценивайте, насколько большими будут данные, и при необходимости берите `long long`.

В 1996 году европейская ракета «Ариан-5» взорвалась через 40 секунд после старта из-за переполнения при переводе 64-битного числа с плавающей точкой в 16-битное целое.

## 2.9 Целые фиксированного размера: `<stdint.h>`

Размер `int` на разных платформах может отличаться (почти на всех компьютерах 4 байта, но на некоторых микроконтроллерах — 2). Когда нужен **точный размер** (форматы файлов, сетевые данные, регистры устройств), используйте `<stdint.h>`:

```c
#include <stdio.h>
#include <stdint.h>
#include <inttypes.h>

int main(void) {
    int8_t   a = -100;          // ровно 8 бит (1 байт), со знаком
    uint8_t  b = 200;           // ровно 8 бит, без знака: 0–255
    int32_t  c = 2000000000;    // ровно 32 бита
    uint64_t d = 18000000000000000000u;   // ровно 64 бита, без знака
    printf("%d %d %" PRId32 " %" PRIu64 "\n", a, b, c, d);
    printf("%zu %zu %zu %zu\n", sizeof a, sizeof b, sizeof c, sizeof d);
    return 0;
}
```

`PRId32` и `PRIu64` — спецификаторы формата из `<inttypes.h>`, правильные на любой платформе.

## 2.10 Итоги

- Переменные в C должны сначала **получить тип**: `int`, `long long`, `double`, `float`, `char`, `bool`; потом тип не меняется.
- `sizeof` даёт число байт (выводится через `%zu`); в `<limits.h>` и `<float.h>` — диапазоны.
- Спецификаторы `printf`: `%d`, `%lld`, `%f`, `%.2f`, `%c`, `%s`, `%x`, `%zu`; `%5d`, `%-5d`, `%05d` управляют шириной и выравниванием; **спецификатор должен соответствовать типу**.
- `char` — маленькое целое (ASCII): `'A'` — 65, `'7' - '0'` — 7.
- Константы: `const` (предпочтительно), `#define`, `constexpr` из C23.
- **Инициализируйте при объявлении**, иначе получите мусор; знаковое переполнение — неопределённое поведение; когда нужен точный размер, используйте `<stdint.h>`.

### Задание 5: Что выведет программа

```c
#include <stdio.h>

int main(void) {
    int a = 7;
    double b = 2.5;
    printf("%d %.1f|%5.2f|%-4d|\n", a, b, b * 2, a);
    printf("%c%c\n", 'a' + 1, 'A' + 25);
    return 0;
}
```

<details>
<summary>Ответ и разбор</summary>

Первая строка: `%d` выводит `7`; `%.1f` — `2.5`; `%5.2f` выводит `5.00` — это всего 4 символа при ширине 5, поэтому спереди добавляется пробел; `%-4d` выравнивает `7` влево в 4 позициях, добавляя 3 пробела после. Итого: `7 2.5| 5.00|7   |`. Вторая строка: `'a' + 1` — это `b`, `'A' + 25` — `Z`, выводится `bZ`.
</details>

### Задание 6: Переменная без начального значения

Что выведет `printf("%d", x);` сразу после `int x;`?

- всегда 0
- непредсказуемое «мусорное значение», которое может каждый раз быть разным
- компилятор откажется компилировать
- программа обязательно упадёт

<details>
<summary>Ответ и разбор</summary>

</details>
