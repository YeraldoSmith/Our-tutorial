# 4. Ввод: scanf

> 🎯 **Цели урока**: читать с помощью `scanf` введённые пользователем целые и дробные числа, символы и слова; понять, зачем перед переменными нужен `&`; запомнить, что «`scanf` читает `double` через `%lf`»; проверять **возвращаемое значение** `scanf`, чтобы справляться с опечатками; решить проблему «оставшегося перевода строки» при чтении символов; читать до конца ввода.
>
> ⏱ **Время**: 50 минут　|　📋 **Что нужно знать**: уроки 2–3 этого курса

## 4.1 Первый scanf

`printf` отвечает за вывод, `scanf` — за ввод. Спецификаторы формата у них почти одинаковые:

```c input="12"
#include <stdio.h>

int main(void) {
    int age = 0;
    printf("Сколько вам лет? ");
    scanf("%d", &age);                 // прочитать целое число и записать в age
    printf("В следующем году вам будет %d!\n", age + 1);
    return 0;
}
```

После запуска программа остановится и будет ждать. Введите `12` и нажмите Enter — и она продолжит работу.

### Зачем `&`?

`&age` читается как «**адрес** переменной age». Каждая переменная живёт где-то в памяти, и у этого места есть номер — адрес. `scanf` должен знать, **куда записать** прочитанное число, поэтому ему сообщают адрес.

```c
#include <stdio.h>

int main(void) {
    int age = 12;
    printf("значение age: %d\n", age);
    printf("адрес age: %p\n", (void *)&age);     // %p выводит адрес (при каждом запуске может отличаться)
    return 0;
}
```

`printf` нужно только значение, поэтому `&` не нужен; `scanf` должен изменить переменную, поэтому `&` обязателен. В уроке 10 об указателях это станет совершенно ясно. **Забытый `&` — одна из самых частых ошибок новичков, и программа обычно падает.**

## 4.2 Читаем несколько значений сразу

```c input="3 4"
#include <stdio.h>

int main(void) {
    int a = 0, b = 0;
    printf("Введите два целых числа: ");
    scanf("%d %d", &a, &b);
    printf("%d + %d = %d\n", a, b, a + b);
    return 0;
}
```

`%d` сам пропускает пробелы, табуляции и переводы строк перед числом, поэтому ввод `3 4`, `3    4` или `3` и `4` на двух строках даёт одинаковый результат.

## 4.3 Спецификаторы формата scanf

| Тип | в `scanf` | в `printf` |
|-----|-----------|-----------|
| `int` | `%d` | `%d` |
| `long long` | `%lld` | `%lld` |
| `double` | **`%lf`** | `%f` |
| `float` | `%f` | `%f` |
| `char` | `%c` (или `" %c"`, см. 4.5) | `%c` |
| одно слово (строка) | `%s` (**без `&`**) | `%s` |

> [!WARNING]
> **`scanf` должен читать `double` через `%lf`** — `%f` прочитает неверное значение, — а `printf` выводит `double` через `%f`. Эта асимметрия — частый источник ошибок в C.

```c input="1.75 60"
#include <stdio.h>

int main(void) {
    double height = 0, weight = 0;
    printf("Рост (м) и вес (кг): ");
    scanf("%lf %lf", &height, &weight);
    printf("ИМТ = %.1f\n", weight / (height * height));
    return 0;
}
```

## 4.4 Проверяем возвращаемое значение: что, если пользователь ошибся?

Если программа ждёт целое число, а пользователь вводит `abc`, что будет? `scanf` **не сможет его прочитать**, и переменная сохранит прежнее значение. К счастью, у `scanf` есть **возвращаемое значение**: сколько значений удалось прочитать.

```c input="abc"
#include <stdio.h>

int main(void) {
    int n = 0;
    printf("Введите целое число: ");
    if (scanf("%d", &n) != 1) {          // ожидаем прочитать 1 значение
        printf("\nЭто не целое число!\n");
    } else {
        printf("Вы ввели %d\n", n);
    }
    return 0;
}
```

(`if … else` подробно — в следующем уроке.) Настоящие программы, получив ввод, который не могут обработать, часто завершаются через `return 1;`, ненулевым кодом завершения сообщая системе «что-то пошло не так» (урок 1).

| `scanf` возвращает | Смысл |
|--------------------|-------|
| столько, сколько просили | полный успех |
| меньше, чем просили | прочитана только часть (остальное не подошло под формат) |
| `EOF` (обычно -1) | ввод закончился (больше читать нечего) |

> [!TIP]
> **Серьёзные программы всегда проверяют, что вернул `scanf`.** С `-Wall` компилятор иногда предупреждает, что результат scanf игнорируется. Чтобы не усложнять, дальнейшие задания курса часто считают, что ввод всегда правильный.

## 4.5 Чтение символов: осторожно, лишний перевод строки

```c input="5\nY"
#include <stdio.h>

int main(void) {
    int count = 0;
    char answer = 0;
    printf("Сколько штук? ");
    scanf("%d", &count);
    printf("Уверены? (Y/N) ");
    scanf(" %c", &answer);             // обратите внимание на пробел перед %c!
    printf("\nколичество %d, ответ %c\n", count, answer);
    return 0;
}
```

Введя `5`, пользователь нажал Enter, и порождённый им перевод строки `\n` **так и остался во вводе**. `%d` пропускает пробельные символы, а `%c` — **нет**: он добросовестно прочитает этот перевод строки. Пробел перед ним, `" %c"`, означает «сначала пропусти все пробельные символы, потом прочитай один символ», — и проблема решена.

## 4.6 Чтение слова

```c input="Tom"
#include <stdio.h>

int main(void) {
    char name[50];                     // «массив char», вмещающий до 49 символов (подробно в уроке 9)
    printf("Ваше имя латиницей: ");
    scanf("%49s", name);               // имя массива уже является адресом, поэтому без &
    printf("Hello, %s!\n", name);
    return 0;
}
```

- `%s` читает **до ближайшего пробельного символа (пробела, перевода строки)**, то есть одно слово; чтобы прочитать целую строку, используют `fgets` (урок 9).
- 49 в `%49s` означает «не больше 49 символов» — остаётся место для `\0`, которым заканчивается строка. **Всегда пишите это ограничение**: иначе слишком длинный ввод испортит память — источник многих уязвимостей.

## 4.7 Читаем до конца ввода

В задачах часто не говорят, сколько будет чисел, а пишут лишь «читать до конца ввода». Используем возвращаемое значение `scanf`:

```c input="3 8 1 9 4"
#include <stdio.h>

int main(void) {
    int x = 0, count = 0;
    long long sum = 0;
    while (scanf("%d", &x) == 1) {       // продолжаем, пока удаётся прочитать очередное целое
        sum += x;
        count++;
    }
    printf("всего %d чисел, сумма %lld\n", count, sum);
    return 0;
}
```

Циклы `while` подробно разберём в следующем уроке, а пока запомните этот приём. При вводе вручную в терминале нажмите **Ctrl+D** (macOS / Linux) или **Ctrl+Z, затем Enter** (Windows), чтобы сообщить «ввод закончен».

## 4.8 Частые ошибки

```c norun
int age = 0;
scanf("%d", age);          // забыли &
```

```text
warning: format '%d' expects argument of type 'int *', but argument 2 has type 'int' [-Wformat=]
```

При запуске программа скорее всего упадёт (`Segmentation fault`). `int *` означает «указатель на int (адрес)» — компилятор подсказывает, что здесь нужен адрес.

```c norun
double h = 0;
scanf("%f", &h);           // для double нужен %lf
```

```text
warning: format '%f' expects argument of type 'float *', but argument 2 has type 'double *' [-Wformat=]
```

> [!NOTE]
> При компиляции в Microsoft Visual Studio можно увидеть `'scanf': This function or variable may be unsafe. Consider using scanf_s instead` (ошибка C4996). Это собственное правило Microsoft, а не требование стандарта C. Добавьте первой строкой файла `#define _CRT_SECURE_NO_WARNINGS` или пользуйтесь GCC / Clang.

## 4.9 Итоги

- `scanf("%d", &x)` читает целое число в `x`; **`&` означает «адрес»**, и раз `scanf` меняет переменную, он обязателен (кроме массивов `char`).
- Спецификаторы `scanf`: `%d`, `%lld`, **`%lf` (double)**, `%c`, `%s`; `%d`, `%lf` и `%s` сами пропускают пробельные символы.
- `scanf` возвращает число прочитанных значений, а в конце ввода — `EOF`; проверяйте ввод через `if (scanf(...) != 1)`.
- Символ читайте через `" %c"` (с пробелом впереди), чтобы пропустить оставшийся перевод строки; слово — через `%49s` с ограничением длины.
- `while (scanf("%d", &x) == 1)` читает до конца ввода.

### Задание 5: Что выведет программа

Пусть на вход этой программе подаётся `12 abc`:

```c
#include <stdio.h>

int main(void) {
    int a = 0, b = 0;
    int n = scanf("%d %d", &a, &b);
    printf("%d %d %d\n", n, a, b);
    return 0;
}
```

<details>
<summary>Ответ и разбор</summary>

`12` читается в `a`; `abc` — не целое число, чтение `b` не удаётся, и `b` остаётся 0. `scanf` возвращает число прочитанных значений — 1. Вывод: `1 12 0`.
</details>

<!-- exercise: why-amp -->
### Задание 6: Зачем `&`?

Почему в `scanf("%d", &age);` пишут `&age`, а не `age`?

- `&` означает «это целое число»
- `scanf` должен записать прочитанное значение в переменную, поэтому ему нужен её адрес в памяти, а `&age` — это и есть адрес
- `&` — просто привычка, без него тоже работает
- `&` прибавляет 1 к введённому числу

<details>
<summary>Ответ и разбор</summary>

`&` — оператор взятия адреса. Получив только `age`, `scanf` получит лишь значение (скажем, 0) и не узнает, куда записать результат, и программа часто падает.
</details>
