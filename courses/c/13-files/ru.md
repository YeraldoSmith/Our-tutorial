# 13. Файлы

> 🎯 **Цели урока**: открывать файлы через `fopen` и закрывать через `fclose`, различать режимы `"r"`, `"w"`, `"a"` и другие; читать и писать текстовые файлы с помощью `fprintf`, `fputs`, `fgetc`, `fgets` и `fscanf`; понять, что `stdin`, `stdout` и `stderr` — тоже «файлы», и писать функции, работающие с любым `FILE *`; обрабатывать ошибки вроде «файл не открывается» (`perror`, `strerror(errno)`); читать форматированные данные, например CSV; читать и писать двоичные файлы через `fwrite` и `fread`; принимать аргументы командной строки `argc` и `argv`.
>
> ⏱ **Время**: 90 минут　|　📋 **Что нужно знать**: уроки 1–12 этого курса

Пока программа работает, её переменные живут в памяти и исчезают, как только она завершится. Чтобы **сохранить** данные — сохранения игры, ведомость оценок, настройки, — их записывают в **файл**.

## 13.1 Открыть, записать, закрыть, прочитать

```c
#include <stdio.h>

int main(void) {
    FILE *f = fopen("hello.txt", "w");       // открываем файл для записи; если его нет — создаём
    if (f == NULL) {                         // NULL, если открыть не удалось
        perror("hello.txt");                 // выводим причину
        return 1;
    }
    fprintf(f, "Привет, файл!\n");           // как printf, но с дополнительным первым аргументом
    fprintf(f, "1 + 1 = %d\n", 1 + 1);
    fclose(f);                               // закрываем: так данные точно попадут в файл

    f = fopen("hello.txt", "r");             // открываем снова, теперь для чтения
    if (f == NULL) {
        perror("hello.txt");
        return 1;
    }
    char line[100];
    while (fgets(line, sizeof line, f) != NULL) {   // читаем построчно; в конце — NULL
        printf("прочитано: %s", line);
    }
    fclose(f);
    return 0;
}
```

- **`FILE *`** — «указатель на файл» из стандартной библиотеки, он обозначает открытый файл. Его возвращает `fopen`, и он нужен всем последующим функциям чтения и записи.
- **Всегда проверяйте, не вернула ли `fopen` значение `NULL`**: отсутствующий файл, нехватка прав или неверный путь — и открыть не получится, а чтение или запись через `NULL` роняют программу.
- **Закончив, вызывайте `fclose`.** Записанные данные сначала копятся в буфере в памяти и попадают на диск только при `fclose`; если забыть, файл может оказаться пустым или неполным.
- Имя `"hello.txt"` — **относительный путь**, относительно «текущего каталога» программы во время работы. В учебной программе к этому курсу каждый запуск происходит во временной папке.

| Режим | Что делает |
|-------|------------|
| `"r"` | чтение. Файл должен уже существовать |
| `"w"` | запись. Создаёт файл, если его нет; **если есть — стирает содержимое** |
| `"a"` | дозапись. Всё записанное идёт в конец файла |
| `"r+"` / `"w+"` / `"a+"` | и чтение, и запись (`"w+"` тоже стирает файл) |
| добавить `b`, например `"rb"`, `"wb"` | двоичный режим (раздел 13.5) |
| добавить `x`, например `"wx"` | **ошибка**, если файл уже существует, — чтобы ничего не перезаписать случайно (с C11) |

## 13.2 `stdin`, `stdout` и `stderr` — тоже файлы

Как только программа запускается, у неё уже открыты три `FILE *`:

| Имя | Что это |
|-----|---------|
| `stdin` | стандартный ввод: клавиатура или поле ввода в учебной программе |
| `stdout` | стандартный вывод: туда пишет `printf` |
| `stderr` | стандартный поток ошибок: для сообщений об ошибках |

`printf(...)` — это на самом деле `fprintf(stdout, ...)`, а `scanf(...)` — `fscanf(stdin, ...)`. Поэтому функция с параметром `FILE *` **одинаково работает и с файлами, и с вводом с клавиатуры**:

```c input="apple\nbanana\ncherry"
#include <stdio.h>

int count_lines(FILE *in) {              // работает с любым FILE *
    int lines = 0;
    int ch;
    while ((ch = fgetc(in)) != EOF) {    // fgetc: читает один символ; в конце — EOF
        if (ch == '\n') {
            lines++;
        }
    }
    return lines;
}

int main(void) {
    FILE *f = fopen("abc.txt", "w");
    if (f == NULL) {
        perror("abc.txt");
        return 1;
    }
    fputs("a\nb\nc\nd\n", f);            // fputs: записывает строку
    fclose(f);

    f = fopen("abc.txt", "r");
    if (f == NULL) {
        perror("abc.txt");
        return 1;
    }
    printf("строк в abc.txt: %d\n", count_lines(f));
    fclose(f);

    printf("строк во вводе: %d\n", count_lines(stdin));
    fprintf(stderr, "эта фраза ушла в stderr\n");
    return 0;
}
```

У вывода ошибок в `stderr` два плюса: даже если вывод перенаправлен в файл (`./main > out.txt`), ошибки всё равно видны на экране; и они не смешиваются с обычным выводом — учебная программа при проверке ответа сравнивает только `stdout`.

Основные функции чтения и записи:

| Запись | Чтение | Единица |
|--------|--------|---------|
| `fputc(c, f)` | `fgetc(f)` (в конце возвращает `EOF`) | один символ |
| `fputs(s, f)` | `fgets(buf, size, f)` (в конце возвращает `NULL`) | строка |
| `fprintf(f, формат, ...)` | `fscanf(f, формат, ...)` (возвращает, сколько значений прочитано) | форматированные данные |
| `fwrite(p, size, n, f)` | `fread(p, size, n, f)` (возвращает, сколько элементов прочитано) | блок байтов (двоичный) |

## 13.3 Обработка ошибок

Когда открыть файл не удалось, глобальная переменная **`errno`** (из `<errno.h>`) хранит номер ошибки, `strerror(errno)` (из `<string.h>`) превращает его во фразу, а `perror("префикс")` сразу выводит «префикс: пояснение» в `stderr`.

Многие программы, не найдя файл настроек, не завершаются, а берут настройки по умолчанию:

```c
#include <stdio.h>
#include <errno.h>
#include <string.h>

int main(void) {
    int volume = 50;                                  // по умолчанию
    FILE *f = fopen("settings.txt", "r");
    if (f == NULL) {
        printf("не удалось прочитать settings.txt (%s), берём настройки по умолчанию\n", strerror(errno));
    } else {
        if (fscanf(f, "%d", &volume) != 1) {          // проверяем результат fscanf
            printf("settings.txt в неверном формате, берём настройки по умолчанию\n");
            volume = 50;
        }
        fclose(f);
    }
    printf("громкость: %d\n", volume);
    return 0;
}
```

(В учебной программе появится `No such file or directory` — «нет такого файла или каталога».) Если без файла не обойтись, выведите сообщение об ошибке и завершите программу: `return EXIT_FAILURE;` (код завершения «неудача» из `<stdlib.h>`, обычно 1).

### Конец файла: не используйте `while (!feof(f))`

```c norun
while (!feof(f)) {                  // неправильно!
    fgets(line, sizeof line, f);
    printf("%s", line);             // последняя строка обработается дважды
}
```

`feof(f)` становится истинным только **после того, как чтение уже не удалось**, поэтому цикл делает лишний оборот и ещё раз обрабатывает остатки предыдущего чтения. Правильно — **сразу проверять результат функции чтения**: `while (fgets(...) != NULL)`, `while (fscanf(...) == 1)`, `while ((ch = fgetc(f)) != EOF)`.

## 13.4 Чтение форматированных данных: CSV

**CSV** (значения, разделённые запятыми) — самый распространённый формат таблиц, его открывает и Excel:

```text
name,score
Ada,95
Linus,88
Grace,91
```

Надёжнее всего читать так: целую строку — через `fgets`, а данные из неё — через `sscanf`. Тогда одна испорченная строка не помешает следующим:

```c
#include <stdio.h>

int main(void) {
    FILE *f = fopen("scores.csv", "w");
    if (f == NULL) {
        perror("scores.csv");
        return 1;
    }
    fputs("name,score\nAda,95\nLinus,88\nGrace,91\n", f);
    fclose(f);

    f = fopen("scores.csv", "r");
    if (f == NULL) {
        perror("scores.csv");
        return 1;
    }
    char line[200];
    if (fgets(line, sizeof line, f) == NULL) {         // пропускаем первую строку (заголовок)
        fclose(f);
        return 0;
    }
    char name[32];
    int score = 0, count = 0;
    long total = 0;
    while (fgets(line, sizeof line, f) != NULL) {
        if (sscanf(line, "%31[^,],%d", name, &score) == 2) {   // %[^,]: читать до запятой
            printf("%-6s %d\n", name, score);
            total += score;
            count++;
        }
    }
    fclose(f);
    if (count > 0) {
        printf("среднее %.2f\n", (double)total / count);
    }
    return 0;
}
```

`%31[^,]` — это **набор сканирования**: `[^,]` значит «любой символ, кроме запятой», так что чтение идёт до запятой (не больше 31 символа), и пробелы в именах не мешают. Аналогично `%[^\n]` читает до конца строки.

## 13.5 Двоичные файлы

`fwrite` записывает байты из памяти в файл **как есть**, а `fread` так же читает их обратно. Сохранение массива структур занимает одну строку:

```c
#include <stdio.h>

typedef struct {
    char name[16];
    int level;
    double hp;
} Player;

int main(void) {
    Player team[3] = {{"Ada", 12, 98.5}, {"Bob", 7, 40.0}, {"Cy", 20, 150.25}};
    FILE *f = fopen("save.dat", "wb");
    if (f == NULL) {
        perror("save.dat");
        return 1;
    }
    size_t written = fwrite(team, sizeof team[0], 3, f);    // 3 элемента по sizeof team[0] байт
    fclose(f);
    printf("записано сохранений: %zu, по %zu байта\n", written, sizeof team[0]);

    Player loaded[3];
    f = fopen("save.dat", "rb");
    if (f == NULL) {
        perror("save.dat");
        return 1;
    }
    size_t got = fread(loaded, sizeof loaded[0], 3, f);    // возвращает, сколько элементов прочитано
    fclose(f);
    for (size_t i = 0; i < got; i++) {
        printf("%-4s Lv.%-3d HP %.2f\n", loaded[i].name, loaded[i].level, loaded[i].hp);
    }
    return 0;
}
```

**Текст или двоичный формат?**

- Двоичные файлы маленькие и быстро читаются и пишутся, но человеку их не прочесть; к тому же размер `int`, порядок байтов и выравнивание структур (урок 12) на разных компьютерах и компиляторах могут различаться, и на другой машине файл может не прочитаться.
- Текстовые файлы (CSV, JSON…) чуть больше, зато их может прочитать человек, обработать другая программа, и они работают везде.
- Для обмена данными с людьми и программами предпочитайте текстовые форматы; двоичный годится для временных данных, которые читает только ваша программа.

## 13.6 Аргументы командной строки

Запуская программу в терминале, после её имени можно указать аргументы, например `./wordcount essay.txt -v`. `main` получает их так:

```c
#include <stdio.h>

int main(int argc, char *argv[]) {
    printf("всего аргументов: %d\n", argc);
    for (int i = 0; i < argc; i++) {
        printf("argv[%d] = %s\n", i, argv[i]);
    }
    return 0;
}
```

- `argc` (argument count) — число аргументов, а `argv` (argument vector) — массив строк.
- `argv[0]` — имя (путь) самой программы; настоящие аргументы начинаются с `argv[1]`. При запуске `./wordcount essay.txt -v` значение `argc` равно 3.
- Учебная программа запускает ваш код без аргументов, поэтому `argc` будет 1. Попробуйте добавить аргументы, компилируя и запуская в терминале.

Многие утилиты командной строки начинаются так:

```c norun
if (argc < 2) {
    fprintf(stderr, "использование: %s имя_файла\n", argv[0]);
    return EXIT_FAILURE;
}
FILE *f = fopen(argv[1], "r");
```

## 13.7 Частые ошибки

| Ошибка | Что будет | Как правильно |
|--------|-----------|---------------|
| не проверять результат `fopen` | падение, если файл не открылся | `if (f == NULL) { perror(...); ... }` |
| забыть `fclose` | неполные данные; слишком много открытых файлов | к каждому `fopen` — свой `fclose` |
| открыть важный файл в режиме `"w"` | его содержимое стёрто | дописывать через `"a"`; от перезаписи защищает `"wx"` |
| `while (!feof(f))` | последний элемент обрабатывается дважды | проверять результат функции чтения |
| `fopen("data.txt", 'r')` | предупреждение: в одинарных кавычках символ, а не строка | `"r"` |
| `fprintf("...", x)` без файла | предупреждение: у первого аргумента неверный тип | `fprintf(f, "...", x)` |
| файл «не находится» | относительный путь отсчитывается от текущего каталога | проверить текущий каталог или указать полный путь |

## 13.8 Итоги

- `FILE *f = fopen(имя, режим);`, проверка на `NULL`, в конце `fclose(f);`.
- Режимы: `"r"` — чтение, `"w"` — запись (со стиранием), `"a"` — дозапись; `b` — двоичный режим, `x` — защита от перезаписи.
- Текстовый ввод-вывод: `fputc`/`fgetc`, `fputs`/`fgets`, `fprintf`/`fscanf`; `stdin`/`stdout`/`stderr` — тоже `FILE *`, сообщения об ошибках — в `stderr`.
- Причину неудачи объясняют `perror` или `strerror(errno)`.
- Конец файла: проверяйте результат функции чтения, а не `while (!feof(f))`.
- CSV: `fgets` для строки плюс `sscanf` для данных; `%[^,]` читает до запятой.
- Двоичный формат: `fwrite`/`fread` копируют байты как есть — быстро, но не переносимо.
- `int main(int argc, char *argv[])` принимает аргументы командной строки; `argv[0]` — имя программы.

void show(const char *name) {

Что будет, если открыть **уже существующий файл с содержимым** в режиме `"w"`?

- новый текст допишется после старого
- старое содержимое сотрётся, и запись начнётся с начала
- `fopen` завершится ошибкой и вернёт `NULL`
- файл откроется только для чтения

<details>
<summary>Ответ и разбор</summary>

`"w"` опустошает существующий файл (его длина становится 0). Чтобы дописывать, используйте `"a"`; чтобы не перезаписать существующий файл — `"wx"`: тогда `fopen` вернёт ошибку, если файл есть.
</details>
