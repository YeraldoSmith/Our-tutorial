## 1.1 Зачем учить C?

Язык C появился в 1972 году — он старше почти любой программы, которой вы пользовались. И всё же это по-прежнему один из самых важных языков мира:

- **операционные системы**: ядра Linux, Windows и macOS написаны в основном на C;
- **встраиваемые устройства**: программы микросхем в стиральных машинах, автомобилях, роутерах и дронах — чаще всего на C;
- **фундамент других языков**: интерпретатор Python (CPython), база данных SQLite, Redis и Git написаны на C;
- **понимание компьютера**: C ставит вас лицом к лицу с **памятью**, **адресами** и **байтами**. Освоив C, вы поймёте, как программы на самом деле работают внутри компьютера, и любой другой язык дастся легче.

По сравнению с Python C более «многословен», заставляет самому следить за множеством деталей и легче допускает ошибки — но именно эти детали позволяют по-настоящему понять машину. Не волнуйтесь: будем двигаться шаг за шагом.

## 1.2 Hello, World!

```c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    printf("Привет, C!\n");
    return 0;
}
```

Нажмите «Запустить» (или скомпилируйте и запустите в терминале, см. раздел 1.3) — и появятся две строки. Разберём построчно:

| Код | Смысл |
|-----|-------|
| `#include <stdio.h>` | подключить описание (заголовочный файл) библиотеки «стандартного ввода-вывода», чтобы можно было пользоваться `printf`. `stdio` = **st**andar**d** **i**nput/**o**utput |
| `int main(void)` | определить **функцию `main`**: отсюда программа начинает работу. `int` означает, что в конце она возвращает целое число; `void` — что она не принимает аргументов |
| `{ ... }` | в фигурных скобках — тело функции, то есть выполняемые инструкции |
| `printf("...\n");` | вывести текст. `\n` означает «новая строка». **Каждая инструкция заканчивается точкой с запятой `;`** |
| `return 0;` | `main` завершается и возвращает операционной системе 0, то есть «программа завершилась нормально» |

> [!NOTE]
> В отличие от Python, в C блоки кода выделяются **фигурными скобками**, а инструкции заканчиваются **точкой с запятой**; отступы нужны только людям, компилятору они безразличны. Но всегда делайте аккуратные отступы (4 пробела), иначе код быстро станет нечитаемым.

## 1.3 Компиляция и запуск

Python **интерпретируется**: интерпретатор читает код и сразу выполняет его. C **компилируется**: сначала **компилятор** переводит исходный код в **машинный код**, который компьютер выполняет напрямую, и создаёт **исполняемый файл**, а затем вы запускаете этот файл.

В учебной программе кнопка «Запустить» сама компилирует и запускает. Чтобы сделать это в своём терминале, сохраните код как `hello.c` и выполните:

```bash
$ gcc hello.c -o hello       # компиляция: превратить hello.c в исполняемый файл hello
$ ./hello                    # запуск (macOS / Linux)
$ hello.exe                  # запуск (Windows)
```

- `gcc` — компилятор (в macOS `gcc` на самом деле Clang, пользоваться им так же);
- `-o hello` задаёт имя выходного файла; без него по умолчанию получится `a.out` (в Windows — `a.exe`);
- добавьте `-Wall -Wextra`, чтобы компилятор предупреждал о вероятных проблемах: `gcc -Wall -Wextra hello.c -o hello`. Учебная программа добавляет эти ключи по умолчанию.

### Что на самом деле делает компиляция?

За одной командой `gcc` по очереди происходят четыре вещи:

```text
hello.c ──① препроцессор──► раскрыть #include, убрать комментарии
        ──② компиляция────► перевести на язык ассемблера (hello.s)
        ──③ ассемблер─────► перевести в машинный код (hello.o, объектный файл)
        ──④ компоновка────► соединить с библиотеками (printf живёт в стандартной библиотеке C) ──► исполняемый файл hello
```

Поэтому:

- **ошибки времени компиляции** (синтаксические ошибки, опечатки в именах) обнаруживаются на шагах ② и ④, и программа вообще не создаётся;
- готовый исполняемый файл **работает сам по себе**, без исходного кода и компилятора — поэтому программы часто распространяют в виде одного `.exe`;
- скомпилированные программы работают очень быстро — важная причина того, что C до сих пор так широко используется.

> [!TIP]
> Если любопытно, `gcc -S hello.c` покажет созданный ассемблерный код (`hello.s`). Курс «Ассемблер» в этой программе объясняет, как его читать.

## 1.4 Вывод через printf

`printf` сам не переходит на новую строку; пишите `\n` там, где она нужна:

```c
#include <stdio.h>

int main(void) {
    printf("первая строка");
    printf(" всё ещё первая строка\n");
    printf("вторая строка\nтретья строка\n");
    return 0;
}
```

Сочетания, начинающиеся с обратной косой черты, как `\n`, называются **управляющими последовательностями** (escape sequences); они обозначают символы, которые неудобно набрать напрямую:

| Запись | Означает |
|--------|----------|
| `\n` | новая строка |
| `\t` | табуляция (Tab, переход к следующей позиции выравнивания) |
| `\\` | одна обратная косая черта `\` |
| `\"` | одна двойная кавычка `"` |
| `%%` | один знак процента `%` (это правило самого `printf`, ведь у `%` особая роль — см. следующий урок) |

```c
#include <stdio.h>

int main(void) {
    printf("Имя\tВозраст\n");
    printf("Петя\t12\n");
    printf("Он сказал: \"Привет\"\n");
    printf("Файл лежит в C:\\Users\\me\n");
    printf("Готово на 100%%\n");
    return 0;
}
```

## 1.5 Комментарии

Комментарии — это пояснения для людей; компилятор их игнорирует:

```c
#include <stdio.h>

/* Это многострочный комментарий:
   он может занимать много строк,
   начинается с / и * и заканчивается * и /. */

int main(void) {
    // Это однострочный комментарий: от // до конца строки
    printf("комментарии не влияют на программу\n");   // можно писать и после кода
    return 0;
}
```

## 1.6 Возвращаемое значение `main`

`return 0;` передаёт операционной системе 0, что значит «всё хорошо»; другое число (например, 1) обычно означает «что-то пошло не так». В терминале можно увидеть возвращаемое значение предыдущей программы (её **код завершения**):

```bash
$ ./hello
$ echo $?                 # macOS / Linux: покажет 0
$ echo %errorlevel%       # командная строка Windows
```

Скрипты и другие программы по коду завершения понимают, успешно ли отработала ваша программа. Начиная с C99, если `main` заканчивается без `return`, это равносильно `return 0;` — но писать его явно — хорошая привычка.

## 1.7 Самые частые ошибки компиляции

Сообщения компилятора — на английском, но подчиняются ясным закономерностям. Учебная программа объясняет причину на вашем языке под сообщением.

**Пропущенная точка с запятой**:

```c norun
#include <stdio.h>

int main(void) {
    printf("Hello\n")
    return 0;
}
```

```text
hello.c: In function 'main':
hello.c:4:22: error: expected ';' before 'return'
```

`hello.c:4:22` означает «строка 4, столбец 22». Обратите внимание: точка с запятой пропущена в конце строки 4, но компилятор часто замечает это, только прочитав следующее слово (`return` в строке 5). **Проверяйте указанную строку и строку над ней.**

**Опечатка в имени функции или пропущенный `#include`**:

```c norun
int main(void) {
    printf("Hello\n");
    return 0;
}
```

```text
hello.c:2:5: warning: implicit declaration of function 'printf' [-Wimplicit-function-declaration]
hello.c:1:1: note: include '<stdio.h>' or provide a declaration of 'printf'
```

Компилятор не знает `printf`, потому что нет `#include <stdio.h>`. GCC 13 и более ранние выдают лишь **предупреждение** (warning), и программа даже может заработать; GCC 14 и новее, а также Clang сообщают об **ошибке** (error). В любом случае исправьте — **не игнорируйте предупреждения**, они часто указывают на ошибки. Опечатка вроде `printF` или `pritnf` даст похожее сообщение (а строка `note` любезно подскажет, какой заголовок подключить).

**Буквы и знаки из другой раскладки**:

```c norun
#include <stdio.h>

int main(void) {
    рrintf("Hello\n");
    return 0;
}
```

```text
hello.c:4:5: warning: implicit declaration of function '\U00000440rintf'; did you mean 'vprintf'? [-Wimplicit-function-declaration]
```

Первая буква здесь — русская `р`, набранная в русской раскладке: она выглядит точно как латинская `p`, но `\U00000440` — это номер кириллической буквы в Unicode. То же бывает с `с`, `о`, `а`, `е`, `х`. Ещё одна частая ловушка — «ёлочки» `« »` и «умные» кавычки `“ ”`, которые вставляют текстовые редакторы: в коде C допустимы только обычные ASCII-символы `(`, `)`, `;`, `"`. Текст **внутри** строк может быть на любом языке, но сам код должен быть набран в английской раскладке.

## 1.8 Итоги

- C — высокоуровневый язык, ближе всего стоящий к железу; на нём написаны операционные системы, встраиваемые устройства и многие интерпретаторы.
- Каждая программа на C начинает работу с `int main(void) { ... }`; для `printf` нужен `#include <stdio.h>`.
- Инструкции заканчиваются `;`, блоки — в `{ }`; отступы — для людей.
- C компилируется: `gcc hello.c -o hello` компилирует, `./hello` запускает; компиляция = препроцессор → компиляция → ассемблирование → компоновка.
- `printf` не добавляет перевод строки; управляющие последовательности `\n`, `\t`, `\\`, `\"` и ещё `%%`.
- Комментарии: `// однострочный` и `/* многострочный */`. `return 0` означает нормальное завершение программы.
- При ошибке смотрите указанную строку и строку над ней; точка с запятой, `#include` и символы из другой раскладки — самые частые виновники.

### Задание 5: Что выведет программа

```c
#include <stdio.h>

int main(void) {
    printf("A");
```

</details>

### Задание 6: Что значит `return 0`

Что означает `return 0;` в `main`?

- программа печатает число 0
- программа завершилась нормально и передала операционной системе код завершения 0

<details>
<summary>Ответ и разбор</summary>

</details>
