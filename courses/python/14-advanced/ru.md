## 14.1 Полезные встроенные функции

```python
names = ["Петя", "Маша", "Коля"]
scores = [88, 95, 72]

for i, name in enumerate(names, start=1):        # номер и элемент сразу (уже видели в уроке 8)
    print(i, name)

for name, score in zip(names, scores):           # соединяем списки попарно, «как молнию»
    print(f"{name}: {score}")

print(dict(zip(names, scores)))                  # два списка — сразу в словарь

nums = [3, -1, 4, 0, 5]
print(any(n < 0 for n in nums))                  # есть ли хоть одно отрицательное? True
print(all(n >= 0 for n in nums))                 # все ли неотрицательные? False
print(sum(n for n in nums if n > 0))             # сумма положительных: 12
print(max(names, key=len), min(scores))          # самое длинное имя, самый низкий балл
print(list(reversed(nums)), sorted(nums, reverse=True))
```

| Функция | Что делает |
|---------|-----------|
| `enumerate(seq, start=0)` | даёт пары (номер, элемент) |
| `zip(a, b, ...)` | соединяет несколько последовательностей попарно, останавливаясь на самой короткой |
| `any(...)` / `all(...)` | истинно, если истинен хотя бы один / все элементы |
| `sum`, `min`, `max` | сумма, наименьший, наибольший (`min`/`max` принимают `key=`) |
| `sorted`, `reversed` | новый отсортированный список, перебор в обратном порядке |
| `map(f, seq)`, `filter(f, seq)` | применить f к каждому элементу, отобрать подходящие (обычно вместо них пишут генераторы списков) |

## 14.2 Выражения-генераторы: не создаём весь список сразу

Замените квадратные скобки генератора списка на круглые — и получится **выражение-генератор** (generator expression): оно не вычисляет все элементы сразу, а **по одному, когда они нужны**:

```python
import sys

squares_list = [n * n for n in range(1_000_000)]     # сразу создаёт миллион чисел и хранит их все
squares_gen = (n * n for n in range(1_000_000))      # лишь нечто, что «может вычислить их по запросу»

print(sys.getsizeof(squares_list), "байт")           # несколько МБ
print(sys.getsizeof(squares_gen), "байт")            # пара сотен байт
print(sum(squares_gen))                               # складывает по мере вычисления, не храня миллион чисел
```

Если выражение-генератор — единственный аргумент функции, одну пару скобок можно опустить: `sum(n * n for n in range(10))`. `any(n < 0 for n in nums)` из предыдущего раздела — тоже выражение-генератор.

> [!NOTE]
> Генератор можно перебрать **только один раз**. Потом он пуст. Если значения нужны несколько раз, используйте список.

## 14.3 `yield`: пишем свои генераторы

Любая функция, в которой есть `yield`, становится **функцией-генератором**: при вызове она не выполняется сразу, а возвращает генератор; каждый раз, когда у него просят следующее значение, функция выполняется до следующего `yield`, отдаёт значение и **замирает** там до следующего запроса.

```python
def countdown(n):
    while n > 0:
        yield n           # отдаём n и замираем здесь
        n -= 1
    print("Пуск!")

for x in countdown(3):    # цикл for сам просит у генератора следующее значение
    print(x)
```

Генераторы удобны, когда данные «производятся одно за другим»: построчное чтение большого файла, бесконечные последовательности, обработка данных порциями…

```python
def fibonacci():                     # бесконечная последовательность Фибоначчи: память не переполнится, считаем по одному
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b

for i, f in enumerate(fibonacci()):
    if i >= 10:
        break
    print(f, end=" ")
print()

def read_numbers(lines):             # «конвейер», очищающий данные по одному элементу
    for line in lines:
        line = line.strip()
        if line and not line.startswith("#"):
            yield int(line)

data = ["10", "# комментарий", "", "20", " 30 "]
print(sum(read_numbers(data)))       # 60
```

## 14.4 Звёздочки: `*args`, `**kwargs` и распаковка

```python
def average(*nums):                  # *nums собирает любое число позиционных аргументов в кортеж
    return sum(nums) / len(nums)

print(average(1, 2, 3), average(10, 20))

def profile(name, **info):           # **info собирает любое число именованных аргументов в словарь
    print(name, info)

profile("Петя", age=12, city="Москва")

scores = [90, 85, 77]
print(average(*scores))              # при вызове * «распаковывает» список в отдельные аргументы
options = {"sep": " | ", "end": "!\n"}
print("a", "b", "c", **options)      # ** распаковывает словарь в именованные аргументы

first, *rest = [1, 2, 3, 4]          # при распаковке * собирает «остальное»
print(first, rest)
*init, last = "abcd"
print(init, last)
merged = [*scores, 100, *[1, 2]]     # объединяем списки
both = {**{"a": 1}, **{"b": 2}}      # объединяем словари (можно и d1 | d2)
print(merged, both)
```

## 14.5 `match`: структурное сопоставление с образцом

В Python 3.10 появилась инструкция `match`. Это не просто сокращение нескольких `if` — она умеет разбирать данные и сопоставлять их **по структуре**:

```python
def handle(command: str) -> str:
    match command.split():
        case ["quit"]:
            return "пока"
        case ["say", *words]:                 # первое слово say, остальные собираем в words
            return " ".join(words)
        case ["move", x, y]:                  # ровно три слова
            return f"перемещение в ({int(x)}, {int(y)})"
        case ["move", *_]:
            return "move нужны две координаты"
        case []:
            return "(пустая команда)"
        case _:                               # _ подходит подо всё: как else
            return f"неизвестная команда: {command}"

for cmd in ["say привет мир", "move 3 4", "move 1", "", "quit", "jump"]:
    print(f"{cmd!r:16} → {handle(cmd)}")
```

`case` умеет также сопоставлять константы, структуру словарей и атрибуты классов и добавлять условия через `if` (`case [x, y] if x == y:`). При обработке команд или разборе данных JSON `match` делает код гораздо понятнее.

## 14.6 Декораторы: «добавляем возможности» функциям

`@dataclass` и `@property` из урока 13 — это **декораторы** (decorator): запись `@имя` над определением функции или класса, которая «оборачивает» его, добавляя дополнительное поведение.

Раз функции — это значения (урок 10), можно написать функцию, которая «принимает функцию и возвращает новую функцию»:

```python
import time
from functools import wraps

def timer(func):                             # принимает функцию
    @wraps(func)                             # сохраняет имя и документацию исходной функции
    def wrapper(*args, **kwargs):            # новая функция: принимает любые аргументы
        start = time.perf_counter()
        result = func(*args, **kwargs)       # вызываем исходную функцию
        print(f"{func.__name__} заняла {time.perf_counter() - start:.4f} с")
        return result
    return wrapper                           # возвращаем новую функцию

@timer                                       # то же самое, что slow_sum = timer(slow_sum)
def slow_sum(n):
    return sum(range(n))

print(slow_sum(1_000_000))
```

Запись `@timer` над `def` равносильна выполнению `slow_sum = timer(slow_sum)` после определения. С этого момента вызов `slow_sum` на деле вызывает `wrapper`, который добавляет замер времени вокруг исходной функции.

### Полезный встроенный декоратор: `@cache`

Рекурсивная функция Фибоначчи с ростом `n` становится поразительно медленной, потому что одни и те же значения вычисляются снова и снова. `functools.cache` **запоминает** результат каждого вызова и при тех же аргументах сразу его возвращает:

```python
from functools import cache

@cache
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print(fib(100))      # мгновенно; без @cache не досчитать и до конца Вселенной
```

Этот приём «запоминать уже вычисленные результаты» называется **мемоизацией** (memoization) и лежит в основе динамического программирования.

## 14.7 Моржовый оператор `:=`

`:=` присваивает значение переменной **посреди выражения** (похож на глаза и бивни моржа, отсюда и название):

```python
import re

text = "заказ A1234, сумма 56 рублей"
if (m := re.search(r"\d+", text)) is not None:     # сначала присваиваем m, потом проверяем
    print("найдено первое число:", m.group())

data = [3, 8, 1, 9, 4]
big = [y for x in data if (y := x * 10) > 40]       # работает и в генераторах списков
print(big)
```

Он избавляет от повторных вычислений и временных переменных — но не злоупотребляйте им, иначе код станет трудно читать.

## 14.8 Современные аннотации типов

С Python 3.9 типы контейнеров можно записывать встроенными типами, а с 3.10 `|` означает «или»:

```python
def word_lengths(words: list[str]) -> dict[str, int]:
    return {w: len(w) for w in words}

def find(names: list[str], target: str) -> int | None:     # индекс, если нашли, иначе None
    return names.index(target) if target in names else None

print(word_lengths(["hi", "hello"]))
print(find(["a", "b"], "b"), find(["a", "b"], "z"))
```

| Аннотация | Значение |
|-----------|----------|
| `list[int]` | список целых чисел |
| `dict[str, float]` | словарь со строковыми ключами и дробными значениями |
| `tuple[int, str]` | кортеж: сначала целое, потом строка |
| `int \| None` | целое число или `None` |
| `Callable[[int], str]` (из `collections.abc`) | функция, принимающая целое и возвращающая строку |

## 14.9 Итоги

- `enumerate`, `zip`, `any`, `all`, `sum/min/max(key=)`, `sorted` и `reversed` делают циклы короче.
- Выражения-генераторы `(x for x in ...)` и генераторы с `yield` «считают только по необходимости», экономят память и позволяют бесконечные последовательности; перебрать их можно только один раз.
- `*args` собирает позиционные аргументы, `**kwargs` — именованные; при вызове `*` и `**` распаковывают списки и словари; `first, *rest = ...` распаковывает.
- `match / case` сопоставляет данные по структуре; `_` подходит подо всё.
- Декоратор `@deco` равносилен `f = deco(f)`; `@cache` запоминает результаты функции.
- `:=` присваивает внутри выражения; аннотации типов пишутся как `list[int]`, `dict[str, int]`, `int | None`.

### Задание 5: Что выведет программа

```python
def gen():
    print("start")
    yield 1
    print("middle")
    yield 2

g = gen()
print("created")
print(next(g))
print(next(g))
```

<details>
<summary>Ответ и разбор</summary>

Вызов `gen()` **не запускает** тело функции, поэтому сначала печатается `created`. Первый `next(g)` выполняет код до первого `yield`: печатает `start` и отдаёт 1. Второй продолжает с места остановки: печатает `middle` и отдаёт 2. Вывод: `created`, `start`, `1`, `middle`, `2`.
</details>

### Задание 6: Что означает декоратор?

Какой строке равносильна эта запись?

```python norun
@timer
def work():
    ...
```

- `work = timer`
- `work = timer(work)`
- `timer = work(timer)`
- `work()` выполняется один раз сразу после определения

<details>
<summary>Ответ и разбор</summary>

`@timer` — то же самое, что написать после определения `work = timer(work)`: исходная `work` заменяется новой функцией, которую вернул `timer`.
</details>
