## 10.1 Зачем нужны функции?

Вы уже пользовались множеством функций: `print()`, `len()`, `input()`, `sorted()`… Каждая **упаковывает** готовый кусок работы и **даёт ему имя**, так что для использования достаточно написать имя.

У собственных функций три плюса:

1. **Без повторов**: код пишется один раз и вызывается где угодно; чтобы изменить его, меняем одно место.
2. **Понятность**: `if is_prime(n):` понять гораздо легче, чем большой цикл.
3. **Проверяемость**: каждую функцию можно проверить отдельно, и ошибку легко найти.

## 10.2 Определение и вызов

```python
def greet(name):                  # def имя_функции(параметр):
    print(f"Привет, {name}!")     # тело функции: отступ 4 пробела

greet("Петя")                     # вызов: имя_функции(аргумент)
greet("Маша")
```

- `def` — сокращение от **define** («определить»);
- `name` — **параметр**: значение, переданное при вызове, попадает в эту переменную;
- тело функции записывается **с отступом**, как у `if` и `for`;
- определение функции **не выполняет** её тело; оно выполняется только при **вызове**. Поэтому сначала определяем, потом вызываем.

## 10.3 Возвращаемое значение: `return`

Функция может «вернуть» результат туда, откуда её вызвали:

```python
def area(width, height):
    return width * height          # возвращаем результат; на этом функция заканчивается

a = area(3, 4)                     # возвращаемое значение можно сохранить в переменной
print(a)                           # 12
print(area(2, 5) + area(1, 1))     # или сразу использовать в вычислениях: 11
```

### Чем `return` отличается от `print`

Именно это новички путают чаще всего:

```python
def add_print(a, b):
    print(a + b)        # только показывает на экране

def add_return(a, b):
    return a + b        # возвращает результат

x = add_print(1, 2)     # на экране 3, но x получает None
y = add_return(1, 2)    # на экране ничего, но y получает 3
print("x =", x)
print("y =", y)
```

`print` — для **человека**; `return` — для **программы**. Функция без `return` (или с пустым `return`) возвращает `None`.

## 10.4 Способы передачи аргументов

```python
def power(base, exp=2):                 # у exp есть значение по умолчанию: если не передать, будет 2
    return base ** exp

print(power(5))                          # 25: по умолчанию
print(power(5, 3))                       # 125: аргументы по позиции
print(power(exp=3, base=2))              # 8: аргументы по имени (именованные), порядок любой

def describe(name, age, city="Москва"):
    return f"{name}, {age} лет, живёт в городе {city}"

print(describe("Петя", 12))
print(describe("Маша", 13, city="Казань"))
```

Правила: **параметры со значениями по умолчанию идут после параметров без них**. При вызове позиционные аргументы пишутся перед именованными.

## 10.5 Возвращаем несколько значений

Если перечислить несколько значений через запятую, на самом деле вернётся **кортеж**, который можно сразу распаковать (урок 8):

```python
def min_max(nums):
    return min(nums), max(nums)

lo, hi = min_max([3, 9, 1, 7])
print(lo, hi)            # 1 9

def divide(a, b):
    return a // b, a % b         # частное и остаток

q, r = divide(17, 5)
print(f"17 = 5 × {q} + {r}")
```

## 10.6 Локальные и глобальные переменные

Переменные, созданные **внутри** функции, — **локальные**: они существуют только в этой функции и исчезают, когда она заканчивается:

```python
def f():
    secret = 42           # локальная переменная
    return secret

print(f())
# print(secret)           # здесь была бы NameError: снаружи не видно переменных функции
```

Переменные, созданные **вне** функций, — **глобальные**, и функция может их **читать**. Но если внутри функции **присвоить** такому имени значение, Python решит, что вы создаёте локальную переменную с тем же именем:

```python
count = 0                 # глобальная переменная

def show():
    print("count =", count)    # только читаем: всё в порядке

show()
```

```python norun
count = 0

def increase():
    count = count + 1     # пытаемся изменить глобальную переменную…
    return count

increase()
```

```text
UnboundLocalError: cannot access local variable 'count' where it is not associated with a value
```

Можно объявить `global count`, чтобы менять глобальную переменную, но **лучше так: передавать значения внутрь через параметры, а наружу — через `return`**:

```python
def increase(count):
    return count + 1

count = 0
count = increase(count)
count = increase(count)
print(count)              # 2
```

Тогда функция зависит только от своих параметров, и её проще понять и проверить.

## 10.7 Современный стиль: аннотации типов и строки документации

В современном коде на Python обычно пишут **аннотации типов** (type hints) и **строку документации** (docstring):

```python
def bmi(weight_kg: float, height_m: float) -> float:
    """Индекс массы тела: ИМТ = вес / рост²."""
    return weight_kg / height_m ** 2

print(f"{bmi(60, 1.70):.1f}")
print(bmi.__doc__)        # строка документации хранится в __doc__; в интерактивном режиме help(bmi) покажет больше
```

- `weight_kg: float` означает «этот параметр должен быть дробным числом», а `-> float` — «функция возвращает дробное число»;
- строка в тройных кавычках — строка документации, описывающая, что делает функция.

> [!NOTE]
> Python **не проверяет** аннотации типов: с неправильным типом программа всё равно запустится. Аннотации пишут для людей и инструментов: редакторы по ним подсказывают, а инструменты вроде `mypy` и `pyright` заранее находят ошибки типов (воспользуемся одним из них в уроке 15).

## 10.8 Функции — это значения

Функции, как числа и строки, можно сохранять в переменных и передавать другим функциям:

```python
def double(x):
    return x * 2

f = double                     # без скобок: это сама функция, а не её вызов
print(f(21))                   # 42

def apply_twice(func, value):
    return func(func(value))

print(apply_twice(double, 3))  # 12
```

Маленькую функцию для одного использования можно записать одной строкой через **`lambda`**: `lambda параметры: выражение`. Чаще всего её используют, чтобы указать `sorted`, `max` и `min`, по чему сравнивать (вы видели это в уроке 9):

```python
words = ["banana", "kiwi", "apple", "fig"]
print(sorted(words, key=len))                    # сортировка по длине
print(sorted(words, key=lambda w: w[-1]))        # по последней букве

students = [("Петя", 88), ("Маша", 95), ("Коля", 72)]
print(max(students, key=lambda s: s[1]))         # у кого балл выше всех
```

## 10.9 Рекурсия: функция вызывает сама себя

Функция может **вызывать сама себя** — это **рекурсия**. Например, факториал: `n! = n × (n−1)!`, причём `0! = 1`:

```python
def factorial(n: int) -> int:
    if n == 0:                    # условие остановки: обязательно, иначе вызовы будут бесконечными
        return 1
    return n * factorial(n - 1)   # сводим задачу к меньшей задаче того же вида

print(factorial(5))               # 5 × 4 × 3 × 2 × 1 = 120
```

Вызовы разворачиваются так:

```text
factorial(3)
= 3 * factorial(2)
= 3 * (2 * factorial(1))
= 3 * (2 * (1 * factorial(0)))
= 3 * (2 * (1 * 1))
= 6
```

Рекурсия изящна там, где «большая задача содержит меньшие копии самой себя» (например, папки внутри папок). Но если забыть условие остановки или уйти слишком глубоко (по умолчанию в Python около 1000 уровней), будет `RecursionError`. Многие рекурсивные функции можно переписать циклами.

## 10.10 Ловушка: изменяемые аргументы по умолчанию

```python
def add_item(item, box=[]):        # опасно! список по умолчанию создаётся один раз, при определении функции
    box.append(item)
    return box

print(add_item("яблоко"))          # ['яблоко']
print(add_item("банан"))           # ['яблоко', 'банан']  ← «яблоко» с прошлого раза всё ещё здесь!
```

Значение по умолчанию вычисляется **один раз — при определении функции**, и все вызовы делят один и тот же список. Правильно использовать `None` по умолчанию:

```python
def add_item(item, box=None):
    if box is None:
        box = []                   # при каждом вызове новый список
    box.append(item)
    return box

print(add_item("яблоко"))
print(add_item("банан"))
```

**Не используйте изменяемые вещи — списки, словари, множества — как значения по умолчанию.**

## 10.11 Частые ошибки

```python norun
def area(w, h):
    return w * h

print(area(3))
```

```text
TypeError: area() missing 1 required positional argument: 'h'
```

Неверное число аргументов: в определении 2 параметра, а при вызове передан 1.

```python norun
print(square(4))

def square(x):
    return x * x
```

```text
NameError: name 'square' is not defined
```

Вызов стоит раньше определения. Перенесите определение выше вызова.

```python norun
def square(x):
    x * x              # забыли return

print(square(4) + 1)
```

```text
TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'
```

В функции нет `return`, поэтому она вернула `None`, а `None + 1` — ошибка.

## 10.12 Итоги

- `def имя(параметры):` определяет функцию; часть с отступом — её тело; сначала определяем, потом вызываем.
- `return` возвращает результат вызывающему и завершает функцию; без `return` результат — `None`. `print` только показывает.
- Аргументы по умолчанию `def f(x, y=2)`; именованные аргументы `f(y=3, x=1)`; возврат нескольких значений даёт кортеж, который можно распаковать.
- Переменные внутри функции локальны; чтобы менять внешние значения, передавайте их через параметры и `return`, а не через `global`.
- Аннотации типов `def f(x: int) -> str:` и строки документации делают код понятнее.
- Функции — это значения, их можно передавать; `lambda` записывает маленькие функции в одну строку, часто для `sorted(key=...)`.
- Рекурсия — это функция, вызывающая саму себя; у неё обязательно должно быть условие остановки.
- Не используйте изменяемые объекты как значения по умолчанию — берите `None`.

### Задание 5: Что выведет программа

```python
x = 10

def f(x):
    x = x + 1
    return x

y = f(x)
print(x, y)

def g():
    return

print(g())
```

<details>
<summary>Ответ и разбор</summary>

`x` внутри `f` — это параметр (локальная переменная); его изменение не трогает внешний `x`, поэтому выводится `10 11`. В `g` стоит пустой `return`, поэтому она возвращает `None`.
</details>

### Задание 6: Изменяемый аргумент по умолчанию
