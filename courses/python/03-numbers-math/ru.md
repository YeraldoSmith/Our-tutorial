## 3.1 Арифметические операторы

| Оператор | Значение | Пример | Результат |
|----------|----------|--------|-----------|
| `+` | сложение | `7 + 2` | `9` |
| `-` | вычитание | `7 - 2` | `5` |
| `*` | умножение | `7 * 2` | `14` |
| `/` | деление | `7 / 2` | `3.5` |
| `//` | целочисленное деление (вниз) | `7 // 2` | `3` |
| `%` | остаток от деления | `7 % 2` | `1` |
| `**` | возведение в степень | `7 ** 2` | `49` |

```python
print(7 + 2, 7 - 2, 7 * 2)
print(7 / 2, 7 // 2, 7 % 2)
print(2 ** 10)
```

### `/` всегда даёт дробное число

```python
print(6 / 2)     # 3.0, а не 3
```

Даже если делится нацело, `/` возвращает `float`. Для целого результата используйте `//`.

### Целые и дробные вместе

Если хотя бы одно число `float`, результат тоже `float`:

```python
print(3 + 2.0)    # 5.0
print(2 * 1.5)    # 3.0
```

## 3.2 Целочисленное деление `//` и остаток `%`

Вспомним школу: 7 ÷ 2 = 3, остаток 1. В Python **частное** — это `//`, а **остаток** — `%`:

```text
7 // 2 = 3    (частное)
7 %  2 = 1    (остаток)
проверка: 3 × 2 + 1 = 7
```

Эти два оператора очень полезны:

```python
n = 17
print(n % 2)        # 1 → нечётное (чётные дают 0)
print(n % 10)       # 7 → последняя цифра
print(n // 10)      # 1 → всё, кроме последней цифры
```

### Классический пример: перевод времени

Переведём 3725 секунд в часы, минуты и секунды:

```python
total = 3725
hours = total // 3600            # в часе 3600 секунд
minutes = total % 3600 // 60     # оставшиеся секунды — в минуты
seconds = total % 60
print(hours, "ч", minutes, "мин", seconds, "с")
```

Вывод: `1 ч 2 мин 5 с`.

`divmod(a, b)` возвращает частное и остаток сразу:

```python
q, r = divmod(3725, 3600)
print(q, r)      # 1 125
```

> [!NOTE]
> Для отрицательных чисел `//` округляет **вниз** (в сторону меньшего): `-7 // 2` равно `-4`, а не `-3`, поэтому `-7 % 2` равно `1`. В повседневных задачах это редко встречается. В C и Java отрицательные числа обрабатываются иначе — там мы об этом напомним.

## 3.3 Приоритет операций

Как в математике, **умножение и деление выполняются раньше сложения и вычитания**, а **скобки — раньше всего**:

```python
print(2 + 3 * 4)      # 14: сначала 3 * 4
print((2 + 3) * 4)    # 20: сначала скобки
```

Полный порядок (от высшего к низшему):

```text
1. ( )                скобки
2. **                 степень
3. -x                 унарный минус
4. *  /  //  %        умножение, деление, целочисленное деление, остаток
5. +  -               сложение, вычитание
```

Операции одного уровня выполняются слева направо: `10 - 3 - 2` = `(10 - 3) - 2 = 5`. Исключение — `**`, она выполняется справа налево: `2 ** 3 ** 2` = `2 ** 9 = 512`.

> [!TIP]
> Сомневаетесь — **ставьте скобки**. Лишние скобки не вредят и делают код понятнее: `average = (a + b + c) / 3`.

Частая ловушка:

```python
print(-2 ** 2)     # -4: сначала 2 ** 2, потом минус
print((-2) ** 2)   # 4
```

## 3.4 Полезные математические функции

**Встроенные функции** — доступны без импорта:

```python
print(abs(-5))             # 5: модуль числа
print(max(3, 8, 1))        # 8: наибольшее
print(min(3, 8, 1))        # 1: наименьшее
print(round(3.14159, 2))   # 3.14: два знака после точки
print(round(7.6))          # 8: округление до целого
print(pow(2, 5))           # 32: то же, что 2 ** 5
```

### Сюрприз в `round`

```python
print(round(2.5))   # 2
print(round(3.5))   # 4
```

Если значение ровно посередине (.5), `round` в Python округляет к **ближайшему чётному** («банковское округление») — так меньше накапливается ошибка при суммировании больших объёмов данных. Если нужно привычное «половина вверх», модуль `decimal` (позже) даёт полный контроль.

## 3.5 Модуль math

Больше математики — в **модуле `math`**. **Модуль** — это ящик с дополнительными инструментами; `import` подключает его:

```python
import math

print(math.sqrt(16))       # 4.0: квадратный корень
print(math.pi)             # 3.141592653589793
print(math.floor(3.7))     # 3: округление вниз
print(math.ceil(3.2))      # 4: округление вверх
print(math.gcd(12, 18))    # 6: наибольший общий делитель
print(math.factorial(5))   # 120: 5×4×3×2×1
print(math.hypot(3, 4))    # 5.0: гипотенуза прямоугольного треугольника
```

`import math` пишут в начале файла, а перед именем функции ставят `math.`.

Пример: площадь и длина окружности:

```python
import math

r = 5
area = math.pi * r ** 2
circumference = 2 * math.pi * r
print("Площадь:", area)
print("Длина окружности:", circumference)
```

## 3.6 Красивый вывод чисел

Знаков после точки слишком много. В f-строке после двоеточия можно указать **формат**:

```python
import math

r = 5
area = math.pi * r ** 2
print(f"Площадь: {area:.2f}")            # два знака: 78.54
print(f"Население: {146000000:,}")       # разделители тысяч: 146,000,000
print(f"Доля: {0.256:.1%}")              # проценты: 25.6%
print(f"Номер: {7:03d}")                 # дополнить нулями до 3 знаков: 007
print(f"[{42:>6}]")                      # по правому краю, ширина 6: [    42]
print(f"[{42:<6}]")                      # по левому краю: [42    ]
```

| Формат | Значение | Пример |
|--------|----------|--------|
| `:.2f` | 2 знака после точки | `3.14159` → `3.14` |
| `:,` | разделитель тысяч | `1234567` → `1,234,567` |
| `:.1%` | проценты, 1 знак | `0.256` → `25.6%` |
| `:03d` | целое, ширина 3, с нулями | `7` → `007` |
| `:>6` / `:<6` / `:^6` | ширина 6, вправо/влево/по центру | |

> [!TIP]
> `:.2f` меняет только **отображение**; переменная хранит полное значение. Чтобы изменить само значение, используйте `round()`.

## 3.7 Законченный пример: калькулятор ИМТ

```python
weight = 68      # вес, кг
height = 1.75    # рост, м

bmi = weight / height ** 2
print(f"Ваш индекс массы тела: {bmi:.1f}")
```

Вывод: `Ваш индекс массы тела: 22.2`. `height ** 2` выполняется первым — степень приоритетнее деления.

## 3.8 Частые ошибки

```python norun
print(10 / 0)
```

```text
ZeroDivisionError: division by zero
```

Делить на 0 нельзя (через `//` и `%` тоже). Когда освоите `if`, проверяйте делитель заранее.

```python norun
print(math.sqrt(9))
```

```text
NameError: name 'math' is not defined
```

Забыли `import math`.

```python norun
x = 5
print(2x)
```

```text
SyntaxError: invalid decimal literal
```

В математике `2x` значит «2 умножить на x», а в Python знак умножения **обязателен**: `2 * x`.

## 3.9 Итоги

- Операторы: `+ - * /`, `//` целочисленное деление, `%` остаток, `**` степень; `/` всегда возвращает `float`.
- `//` и `%` нужны для проверки чётности, выделения цифр, перевода единиц; `divmod` даёт оба результата.
- Приоритет: скобки > `**` > унарный минус > `* / // %` > `+ -`; если не уверены — скобки.
- Встроенные `abs`, `max`, `min`, `round`, `pow`; `round` округляет .5 к ближайшему чётному.
- После `import math`: `math.sqrt`, `math.pi`, `math.floor`, `math.ceil` и другие.
- Форматы в f-строках: `:.2f`, `:,`, `:.1%`, `:03d`, `:>6`.
