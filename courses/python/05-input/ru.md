# 5. Ввод и диалог с пользователем

> 🎯 **Цели урока**: читать ввод пользователя через `input()`; понять, что ввод — **всегда строка**, и преобразовывать его через `int()` и `float()`; читать несколько значений из одной строки; написать первые по-настоящему интерактивные программы; узнать, как подаётся ввод при проверке заданий.
>
> ⏱ **Время**: 35 минут　|　📋 **Что нужно знать**: уроки 2–4

## 5.1 input(): программа слушает вас

До сих пор все данные были записаны прямо в программе. Чтобы **общаться** с пользователем, нужен ввод. `input()` **приостанавливает программу**, ждёт, пока пользователь наберёт строку и нажмёт Enter, и передаёт эту строку программе:

```python
name = input("Как тебя зовут? ")
print(f"Привет, {name}!")
```

Программа покажет `Как тебя зовут?` и будет ждать. В программе курса **введите текст в поле ввода под результатом** (например, `Саша`) и нажмите Enter — программа продолжит работу:

```text
Как тебя зовут? Саша
Привет, Саша!
```

Текст в скобках — **приглашение** (prompt), оно показывается первым и подсказывает, что вводить. Можно обойтись без него: `name = input()`.

> [!TIP]
> Если вы знаете, какой ввод понадобится программе, можно набрать его в поле ввода и нажать Enter **до** нажатия «▶ Запустить» — программа получит его сразу после старта.

## 5.2 Ввод — всегда строка

Это **очень важно**, и это самая частая ловушка новичков:

```python norun
age = input("Сколько тебе лет? ")
print(age + 1)
```

Введите `18` — и получите:

```text
TypeError: can only concatenate str (not "int") to str
```

Почему? Потому что `input()` **всегда возвращает строку**: даже если пользователь набрал цифры, вы получаете текст `"18"`, а не число `18`. Чтобы считать, его нужно сначала **преобразовать**:

```python
age = int(input("Сколько тебе лет? "))
print(f"В следующем году тебе будет {age + 1}")
```

`int(input(...))` — **вложенный вызов**: сначала выполняется внутренний `input()` и возвращает текст, который внешний `int()` превращает в целое число.

| Нужный тип | Запись |
|------------|--------|
| текст | `s = input()` |
| целое число | `n = int(input())` |
| дробное число | `x = float(input())` |

## 5.3 Простой калькулятор

```python
a = float(input("Первое число: "))
b = float(input("Второе число: "))
print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
print(f"{a} × {b} = {a * b}")
print(f"{a} ÷ {b} = {a / b:.4f}")
```

Запустите и введите `7` и `2`. Мы используем `float`, а не `int`, чтобы работали и дробные числа. Вводите их **через точку**: `2.5`, а не `2,5`. (Если второе число 0, последняя строка вызовет `ZeroDivisionError` — после следующего урока вы сможете обработать это через `if`.)

## 5.4 Несколько значений в одной строке

Иногда пользователь вводит несколько чисел в одной строке через пробел, например `3 4 5`. Разбейте строку и преобразуйте каждую часть:

```python
line = input("Три стороны треугольника через пробел: ")
parts = line.split()          # "3 4 5" → ['3', '4', '5']
a = int(parts[0])
b = int(parts[1])
c = int(parts[2])
print("Периметр:", a + b + c)
```

Короче — через `map`, которая применяет функцию к каждому элементу:

```python
a, b, c = map(int, input().split())
print(a + b + c)
```

`map(int, ...)` вызывает `int()` для каждого куска, полученного от `split()`, а множественное присваивание раздаёт их `a`, `b` и `c`. Это один из **самых распространённых** способов чтения ввода в задачах — запомните!

## 5.5 Очистка ввода

Пользователи часто случайно набирают лишние пробелы. `strip()` убирает пробелы по краям, а `lower()` приводит к одному регистру — программа становится «снисходительнее»:

```python
answer = input("Тебе нравится Python? (да/нет) ").strip().lower()
print(f"Твой ответ: {answer}")
```

Ввод `  ДА ` всё равно даст `да`.

> [!NOTE]
> `int()` сам игнорирует пробелы по краям: `int(" 42 ")` равно `42`. Но `int("4 2")` (пробел внутри) и `int("42.0")` — ошибки.

## 5.6 Ввод в заданиях на программирование

В заданиях на программирование проверяющая программа **сама подаёт ввод** и сравнивает ваш вывод с ожидаемым **посимвольно**. Поэтому:

> [!IMPORTANT]
> В заданиях **не пишите приглашение внутри `input()`**. Оно тоже печатается, смешивается с выводом, и ответ считается неверным. Пишите `n = int(input())`, а не `n = int(input("Введите: "))`.

Ввод и вывод в заданиях описываются так:

```text
Ввод: две строки, в каждой целое число
Вывод: их сумма

Пример ввода:     Пример вывода:
3                 8
5
```

**Каждая строка** примера ввода соответствует одному вызову `input()`.

## 5.7 Законченный пример: перевод температуры

```python
c = float(input())          # градусы Цельсия
f = c * 9 / 5 + 32
print(f"{c:.1f}°C = {f:.1f}°F")
```

Ввод `36.6` даёт `36.6°C = 97.9°F`.

## 5.8 Частые ошибки

### Забыли преобразовать

```python norun
a = input()
b = input()
print(a + b)     # ввод 3 и 5 даёт 35!
```

Ошибки нет, но результат неверный: сложение двух **строк** их склеивает. Помните про `int(input())`.

### Ввод нельзя преобразовать

```python norun
n = int(input())     # пользователь ввёл "abc" или "3.5"
```

```text
ValueError: invalid literal for int() with base 10: 'abc'
```

В уроке 12 мы научимся аккуратно обрабатывать это через `try/except`.

### Чтение лишних строк

```text
EOFError: EOF when reading a line
```

EOF — «конец файла»: ввод закончился. Программа попыталась прочитать ещё одну строку, а её нет. Проверьте, совпадает ли число вызовов `input()` с числом строк ввода и не нужно ли прочитать несколько значений одной строки одним `split()`.

## 5.9 Итоги

- `input("приглашение")` приостанавливает программу и читает строку; в программе курса — через поле ввода.
- `input()` **всегда возвращает строку**; перед вычислениями преобразуйте через `int()` / `float()`.
- Несколько значений в строке: `a, b = map(int, input().split())`.
- `strip()` и `lower()` делают обработку ввода снисходительнее.
- В заданиях — **без приглашения** в `input()`; каждая строка примера ввода — один вызов `input()`.
