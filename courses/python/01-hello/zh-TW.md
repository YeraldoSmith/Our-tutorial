## 1.1 Python 是什麼？為什麼先學它？

**Python** 是一種程式語言。程式語言就是人和電腦之間的「約定好的說話方式」：我們按照規則寫下指令，電腦就會一條一條地執行。

為什麼很多人把 Python 當作第一門語言？

- **讀起來像英語**：`print("你好")` 就是「列印：你好」，幾乎不用解釋。
- **規則少**：不用寫一堆大括號、分號，也不用先宣告型別。
- **用途廣**：網站後端、資料分析、自動化辦公、人工智慧（ChatGPT 這類大模型幾乎都用 Python 訓練）、科學計算、小遊戲……
- **資料多**：遇到問題，幾乎都能搜到答案。

> [!NOTE]
> 本教程使用 **Python 3**（目前最新的穩定版本是 3.14）。網上有些老教程用的是 Python 2，寫法不同（例如 `print "hello"` 沒有括號），它在 2020 年就已經停止維護了，**不要學**。

## 1.2 第一個程式

在右邊的程式碼編輯器裡，輸入下面這一行（或者點程式碼框上方的「▶ 放進編輯器執行」）：

```python
print("Hello, World!")
```

然後點選 **▶ 執行**（快捷鍵 <kbd>F5</kbd>）。下方「執行結果」裡會出現：

```text
Hello, World!
```

🎉 恭喜！你已經寫出了第一個程式。幾乎所有程式設計師學新語言時，第一件事都是讓電腦說一句 "Hello, World!"——這是從 1978 年流傳下來的傳統。

### 這一行程式碼到底做了什麼？

我們把它拆開看：

```text
print ( "Hello, World!" )
  │   │        │        │
  │   │        │        └─ 右括號：引數結束
  │   │        └────────── 要顯示的內容（一段文字，叫「字串」）
  │   └─────────────────── 左括號：開始告訴 print 要列印什麼
  └─────────────────────── 函式名：print（列印）
```

- `print` 是 Python 自帶的一個**函式**。函式就像一臺小機器：你把東西放進去，它幫你做一件事。`print` 這臺機器的工作是：**把括號裡的東西顯示到螢幕上**。
- 括號裡放的東西叫**引數**（argument）。
- `"Hello, World!"` 兩邊的**雙引號**告訴 Python：「這是一段文字，原樣顯示，不要把它當成命令」。帶引號的文字叫**字串**（string）。

### 換成中文也可以

```python
print("你好，世界！")
print("我正在學 Python。")
```

執行後會顯示兩行。程式是**從上往下、一行一行**執行的：先執行第 1 行，再執行第 2 行。

> [!TIP]
> 引號裡面可以寫任何文字：中文、英文、emoji 都行。但**引號本身、括號本身**必須是英文半形符號。這是新手最常犯的錯誤，下面會專門講。

## 1.3 字串：單引號和雙引號

字串可以用雙引號，也可以用單引號，效果完全一樣：

```python
print("我喜歡程式設計")
print('我也喜歡程式設計')
```

那為什麼要有兩種？當文字裡本身含有引號時就方便了：

```python
print("It's a good day.")       # 文字裡有單引號，外面就用雙引號
print('他說："程式設計很有趣"')       # 文字裡有雙引號，外面就用單引號
```

### 換行和特殊字元

如果想在一個字串裡換行，可以用 `\n`（反斜槓 + n，n 代表 new line，新的一行）：

```python
print("第一行\n第二行\n第三行")
```

輸出：

```text
第一行
第二行
第三行
```

像 `\n` 這樣以反斜槓開頭、有特殊含義的寫法叫**跳脫字元**。常用的還有：

| 寫法 | 含義 |
|------|------|
| `\n` | 換行 |
| `\t` | 製表符（Tab，一段空白，用來對齊） |
| `\\` | 一個真正的反斜槓 `\` |
| `\"` | 在雙引號字串裡寫一個雙引號 |

### 多行文字：三引號

很長的一段文字，可以用三個引號 `"""` 包起來，裡面可以直接回車換行：

```python
print("""靜夜思
床前明月光，
疑是地上霜。""")
```

## 1.4 一次列印多個東西

`print` 的括號裡可以放多個東西，用**逗號**隔開，它們之間會自動加一個空格：

```python
print("我今年", 18, "歲")
```

輸出：

```text
我今年 18 歲
```

注意 `18` 沒有加引號——它是一個**數字**，不是文字。`print` 既能列印文字，也能列印數字。

還可以直接讓 Python 做計算：

```python
print(1 + 2)
print("1 + 2")
print("一天有", 24 * 60, "分鐘")
```

輸出：

```text
3
1 + 2
一天有 1440 分鐘
```

看出區別了嗎？`1 + 2` 沒有引號，Python 會**計算**它，得到 `3`；`"1 + 2"` 有引號，是一段文字，原樣顯示。在 Python 裡 `*` 表示乘號。

### 控制分隔符和結尾

`print` 有兩個常用的「設定項」：

- `sep`：多個東西之間用什麼隔開（預設是一個空格）。
- `end`：列印完以後在末尾加什麼（預設是 `\n`，也就是換行）。

```python
print("2026", "11", "12", sep="-")
print("不換行", end="")
print("，接著上一行")
```

輸出：

```text
2026-11-12
不換行，接著上一行
```

## 1.5 註釋：寫給人看的話

以 `#` 開頭的內容叫**註釋**。Python 會完全忽略它，它是寫給人看的說明：

```python
# 這是一個註釋：下面這行會列印問候語
print("你好！")  # 註釋也可以寫在程式碼後面

# print("這一行不會執行，因為前面有 #")
```

註釋的兩大用途：

1. **解釋程式碼**：告訴別人（和三個月後的你自己）這段程式碼在做什麼、為什麼這麼做。
2. **臨時禁用程式碼**：除錯時在一行前加 `#`，讓它暫時不執行。

> [!TIP]
> 在編輯器裡選中幾行，按 <kbd>Ctrl</kbd> + <kbd>/</kbd>（Mac 上是 <kbd>⌘</kbd> + <kbd>/</kbd>）可以一次性加上或去掉註釋。

## 1.6 程式是怎麼執行的？

你點「執行」之後，背後發生了這些事：

```text
你寫的程式碼 (main.py)
      │
      ▼
Python 直譯器：讀一行 → 理解它 → 執行它 → 再讀下一行……
      │
      ▼
螢幕上顯示結果
```

Python 是一種**解釋型**語言：有一個叫「直譯器」的程式（就是你安裝的 Python），它逐行讀取你的程式碼並執行。後面學 C、Rust 時，你會見到另一種方式——**編譯型**：先把整個程式翻譯成機器能直接執行的檔案，再執行它。

在本課程的學習程式裡，你只需要點「▶ 執行」。以後在自己電腦的終端裡，也可以這樣執行：

```console
python3 hello.py
```

（Windows 上通常是 `python hello.py` 或 `py hello.py`，在「程式設計起步」課程裡有詳細說明。）

## 1.7 常見錯誤（一定要看！）

寫錯是正常的，專業程式設計師每天也會寫出幾十個錯誤。關鍵是**看懂錯誤資訊**。錯誤資訊雖然是英文，但格式很固定：

```text
  File "main.py", line 1
    print("你好"）
               ^
SyntaxError: invalid character '）' (U+FF09)
```

讀法：**在哪個檔案（main.py）、第幾行（line 1）、哪個位置（^ 指著的地方）、什麼錯誤（SyntaxError 語法錯誤）、具體原因**。

### 錯誤 1：用了中文標點

```python norun
print("你好"）
```

右括號 `）` 是中文的全形符號，Python 不認識。**程式碼裡的括號、引號、逗號、冒號，都必須用英文輸入法輸入。** 中文只能出現在引號裡面。

> [!WARNING]
> 中文輸入法很容易在不知不覺中打出全形符號。寫程式碼時，建議把輸入法切換到英文狀態；需要輸入中文文字時再切回來。全形 `（），：“”` 和半形 `(),:""` 看起來很像，要仔細看。

### 錯誤 2：拼寫錯誤或大小寫錯誤

```python norun
Print("你好")
```

```text
NameError: name 'Print' is not defined
```

Python **區分大小寫**：`print` 和 `Print` 是兩個完全不同的名字。Python 只認識小寫的 `print`。

### 錯誤 3：忘了引號

```python norun
print(你好)
```

```text
NameError: name '你好' is not defined
```

沒有引號，Python 會把 `你好` 當成一個「名字」（變數，下一課會學）去查詢，找不到就報錯。想表示文字，一定要加引號。

### 錯誤 4：引號或括號不成對

```python norun
print("你好)
```

```text
SyntaxError: unterminated string literal (detected at line 1)
```

`unterminated string literal` 意思是「沒有結束的字串」——少了一個結尾的引號。

> [!TIP]
> 在本課程的程式裡執行出錯時，錯誤資訊下面會有一個「💬 這是什麼意思？」的中文解釋框。先讀解釋，再回到程式碼裡找問題。

## 1.8 小結

- `print(...)` 把括號裡的內容顯示到螢幕上。
- 用引號包起來的文字叫**字串**，單引號、雙引號都可以；三引號可以寫多行。
- `\n` 表示換行；`print` 的 `sep` 和 `end` 可以控制分隔符和結尾。
- 沒有引號的 `1 + 2` 會被計算，有引號的 `"1 + 2"` 原樣顯示。
- `#` 開頭的是註釋，Python 會忽略它。
- 程式碼裡的符號必須是**英文半形**；Python **區分大小寫**。
- 錯誤資訊要看：檔案、行號、`^` 位置、錯誤型別和原因。
