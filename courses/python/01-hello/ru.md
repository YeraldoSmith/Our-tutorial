## 1.1 Что такое Python и почему начинать с него?

**Python** — это язык программирования. Язык программирования — это договорённый способ общения человека с компьютером: мы пишем инструкции по определённым правилам, а компьютер выполняет их одну за другой.

Почему так многие начинают именно с Python?

- **Читается почти как английский**: `print("Привет")` — это «напечатать: Привет». Объяснять почти нечего.
- **Мало правил**: не нужны горы фигурных скобок и точек с запятой, не нужно заранее объявлять типы.
- **Применяется везде**: серверная часть сайтов, анализ данных, автоматизация рутины, искусственный интеллект (большие языковые модели вроде ChatGPT обучают на Python), наука, небольшие игры…
- **Огромное сообщество**: какой бы ни была проблема, кто-то уже о ней спрашивал.

> [!NOTE]
> В курсе используется **Python 3** (самая новая стабильная версия — 3.14). В старых материалах в интернете встречается Python 2 с другим синтаксисом (например, `print "hello"` без скобок). Его поддержка прекращена в 2020 году — **не учите его**.

## 1.2 Первая программа

Наберите эту строку в редакторе кода справа (или нажмите «▶ Запустить» над блоком кода):

```python
print("Hello, World!")
```

Теперь нажмите **▶ Запустить** (клавиша <kbd>F5</kbd>). В области «Результат» появится:

```text
Hello, World!
```

🎉 Поздравляем, вы написали первую программу! Изучая новый язык, программисты первым делом заставляют компьютер сказать «Hello, World!» — эта традиция идёт с 1978 года.

### Что именно делает эта строка?

Разберём по частям:

```text
print ( "Hello, World!" )
  │   │        │        │
  │   │        │        └─ закрывающая скобка: конец аргумента
  │   │        └────────── что показать (кусок текста — «строка»)
  │   └─────────────────── открывающая скобка: начинаем говорить print, что печатать
  └─────────────────────── имя функции: print (печать)
```

- `print` — встроенная в Python **функция**. Функция похожа на маленький станок: вы кладёте в него что-то, а он выполняет работу. Работа `print` — **показать на экране то, что в скобках**.
- То, что стоит в скобках, называется **аргументом**.
- **Двойные кавычки** вокруг `"Hello, World!"` говорят Python: «это текст — покажи его как есть и не считай командой». Текст в кавычках называется **строкой** (string).

### В кавычках можно писать по-русски

```python
print("Привет, мир!")
print("Я изучаю Python.")
```

Программа покажет две строки. Программа выполняется **сверху вниз, по одной строке**: сначала строка 1, потом строка 2.

> [!TIP]
> Внутри кавычек можно писать что угодно: по-русски, по-английски, даже эмодзи. Но **сами кавычки и скобки** должны быть обычными (ASCII). «Ёлочки» `«»` и «лапки» `“”` из текстовых редакторов в коде не работают — подробнее ниже.

## 1.3 Строки: одинарные и двойные кавычки

Строку можно заключить в двойные или одинарные кавычки — разницы нет:

```python
print("Я люблю программировать")
print('Я тоже')
```

Зачем два вида? Это удобно, когда в самом тексте есть кавычка:

```python
print("It's a good day.")          # в тексте ' — снаружи берём "
print('Она сказала: "Это просто"')  # в тексте " — снаружи берём '
```

### Перевод строки и специальные символы

Чтобы начать новую строку внутри текста, пишут `\n` (обратная косая черта + n, от «new line»):

```python
print("Первая строка\nВторая строка\nТретья строка")
```

Вывод:

```text
Первая строка
Вторая строка
Третья строка
```

Сочетания, которые начинаются с обратной косой черты и имеют особый смысл, называются **escape-последовательностями**. Частые:

| Пишем | Значение |
|-------|----------|
| `\n` | новая строка |
| `\t` | табуляция (отступ для выравнивания) |
| `\\` | сам символ `\` |
| `\"` | двойная кавычка внутри строки в двойных кавычках |

### Многострочный текст: тройные кавычки

Длинный текст можно заключить в три кавычки `"""` и прямо внутри нажимать Enter:

```python
print("""Мороз и солнце;
день чудесный!
Ещё ты дремлешь,
друг прелестный —""")
```

## 1.4 Печать нескольких значений сразу

В `print` можно передать несколько значений через **запятую** — между ними автоматически появится пробел:

```python
print("Мне", 18, "лет")
```

Вывод:

```text
Мне 18 лет
```

Обратите внимание: `18` без кавычек — это **число**, а не текст. `print` умеет печатать и то, и другое.

Python может и посчитать:

```python
print(1 + 2)
print("1 + 2")
print("В сутках", 24 * 60, "минут")
```

Вывод:

```text
3
1 + 2
В сутках 1440 минут
```

Видите разницу? Без кавычек Python **вычисляет** `1 + 2` и получает `3`; в кавычках `"1 + 2"` — это текст, он выводится как есть. В Python `*` означает умножение.

### Разделитель и окончание

У `print` есть две полезные настройки:

- `sep` — что ставить между значениями (по умолчанию пробел);
- `end` — что добавить в самом конце (по умолчанию `\n`, то есть перевод строки).

```python
print("2026", "11", "12", sep="-")
print("Без перевода строки", end="")
print(", продолжение на той же строке")
```

Вывод:

```text
2026-11-12
Без перевода строки, продолжение на той же строке
```

## 1.5 Комментарии: заметки для людей

Всё, что идёт после `#`, — это **комментарий**. Python полностью его игнорирует; это пояснение для людей:

```python
# Это комментарий: следующая строка печатает приветствие
print("Привет!")  # комментарий можно писать и после кода

# print("эта строка не выполнится из-за #")
```

Для чего нужны комментарии:

1. **Объяснять код**: что он делает и почему — для других и для вас самих через три месяца.
2. **Временно отключать код**: при отладке поставьте `#` перед строкой, и она не выполнится.

> [!TIP]
> Выделите несколько строк в редакторе и нажмите <kbd>Ctrl</kbd> + <kbd>/</kbd> (на Mac — <kbd>⌘</kbd> + <kbd>/</kbd>), чтобы закомментировать или раскомментировать их все сразу.

## 1.6 Как выполняется программа?

Когда вы нажимаете «Запустить», происходит вот что:

```text
ваш код (main.py)
      │
      ▼
интерпретатор Python: прочитать строку → понять → выполнить → следующая строка…
      │
      ▼
результат на экране
```

Python — **интерпретируемый** язык: программа-«интерпретатор» (установленный у вас Python) читает код строка за строкой и выполняет его. Позже, изучая C или Rust, вы встретите другой подход — **компиляцию**: сначала вся программа переводится в файл, который машина выполняет напрямую, а потом этот файл запускается.

В программе этого курса достаточно нажать «▶ Запустить». В собственном терминале файл можно запустить так:

```console
python3 hello.py
```

(В Windows обычно `python hello.py` или `py hello.py`; подробности — в курсе «Первые шаги».)

## 1.7 Частые ошибки (обязательно прочитайте!)

Ошибаться нормально — профессионалы делают десятки ошибок в день. Главное — **уметь читать сообщение об ошибке**. Оно на английском, но формат всегда одинаковый:

```text
  File "main.py", line 1
    print("Привет)
          ^
SyntaxError: unterminated string literal (detected at line 1)
```

Читаем так: **в каком файле (main.py), в какой строке (line 1), в каком месте (там, куда указывает `^`), какая ошибка (SyntaxError — синтаксическая) и причина.**

### Ошибка 1: «неправильные» кавычки и скобки

```python norun
print(«Привет»)
```

Кавычки-«ёлочки» `«»` — это не кавычки для Python. **Кавычки, скобки, запятые и двоеточия в коде нужно набирать в английской раскладке.** Русский текст допустим только внутри кавычек.

> [!WARNING]
> Текстовые редакторы (Word, мессенджеры) часто сами превращают `"` в `«»` или `“”`. Если копируете код оттуда — проверьте кавычки.

### Ошибка 2: опечатка или заглавная буква

```python norun
Print("Привет")
```

```text
NameError: name 'Print' is not defined
```

Python **различает регистр**: `print` и `Print` — совершенно разные имена. Python знает только `print` со строчной буквы.

### Ошибка 3: забыли кавычки

```python norun
print(Привет)
```

```text
NameError: name 'Привет' is not defined
```

Без кавычек Python считает `Привет` «именем» (переменной — следующий урок) и ищет его. Не находит — и сообщает об ошибке. Текст всегда пишется в кавычках.

### Ошибка 4: непарные кавычки или скобки

```python norun
print("Привет)
```

```text
SyntaxError: unterminated string literal (detected at line 1)
```

«Unterminated string literal» значит «строка не закончена» — не хватает закрывающей кавычки.

> [!TIP]
> Если код в программе курса завершился ошибкой, под ней появится блок «💬 Что это значит?» с объяснением на русском. Прочитайте его, а потом ищите проблему в коде.

## 1.8 Итоги

- `print(...)` показывает то, что в скобках.
- Текст в кавычках — это **строка**; подходят одинарные и двойные кавычки; тройные позволяют писать несколько строк.
- `\n` — перевод строки; `sep` и `end` управляют разделителем и окончанием `print`.
- `1 + 2` без кавычек вычисляется; `"1 + 2"` в кавычках выводится как есть.
- `#` начинает комментарий, который Python игнорирует.
- Символы в коде должны быть обычными (ASCII); Python **различает регистр**.
- Читайте сообщения об ошибках: файл, строка, место `^`, тип ошибки и причина.
