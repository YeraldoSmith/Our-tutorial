## 1.1 Python 是什么？为什么先学它？

**Python** 是一种编程语言。编程语言就是人和电脑之间的「约定好的说话方式」：我们按照规则写下指令，电脑就会一条一条地执行。

为什么很多人把 Python 当作第一门语言？

- **读起来像英语**：`print("你好")` 就是「打印：你好」，几乎不用解释。
- **规则少**：不用写一堆大括号、分号，也不用先声明类型。
- **用途广**：网站后端、数据分析、自动化办公、人工智能（ChatGPT 这类大模型几乎都用 Python 训练）、科学计算、小游戏……
- **资料多**：遇到问题，几乎都能搜到答案。

> [!NOTE]
> 本教程使用 **Python 3**（目前最新的稳定版本是 3.14）。网上有些老教程用的是 Python 2，写法不同（例如 `print "hello"` 没有括号），它在 2020 年就已经停止维护了，**不要学**。

## 1.2 第一个程序

在右边的代码编辑器里，输入下面这一行（或者点代码框上方的「▶ 放进编辑器运行」）：

```python
print("Hello, World!")
```

然后点击 **▶ 运行**（快捷键 <kbd>F5</kbd>）。下方「运行结果」里会出现：

```text
Hello, World!
```

🎉 恭喜！你已经写出了第一个程序。几乎所有程序员学新语言时，第一件事都是让电脑说一句 "Hello, World!"——这是从 1978 年流传下来的传统。

### 这一行代码到底做了什么？

我们把它拆开看：

```text
print ( "Hello, World!" )
  │   │        │        │
  │   │        │        └─ 右括号：参数结束
  │   │        └────────── 要显示的内容（一段文字，叫「字符串」）
  │   └─────────────────── 左括号：开始告诉 print 要打印什么
  └─────────────────────── 函数名：print（打印）
```

- `print` 是 Python 自带的一个**函数**。函数就像一台小机器：你把东西放进去，它帮你做一件事。`print` 这台机器的工作是：**把括号里的东西显示到屏幕上**。
- 括号里放的东西叫**参数**（argument）。
- `"Hello, World!"` 两边的**双引号**告诉 Python：「这是一段文字，原样显示，不要把它当成命令」。带引号的文字叫**字符串**（string）。

### 换成中文也可以

```python
print("你好，世界！")
print("我正在学 Python。")
```

运行后会显示两行。程序是**从上往下、一行一行**执行的：先执行第 1 行，再执行第 2 行。

> [!TIP]
> 引号里面可以写任何文字：中文、英文、emoji 都行。但**引号本身、括号本身**必须是英文半角符号。这是新手最常犯的错误，下面会专门讲。

## 1.3 字符串：单引号和双引号

字符串可以用双引号，也可以用单引号，效果完全一样：

```python
print("我喜欢编程")
print('我也喜欢编程')
```

那为什么要有两种？当文字里本身含有引号时就方便了：

```python
print("It's a good day.")       # 文字里有单引号，外面就用双引号
print('他说："编程很有趣"')       # 文字里有双引号，外面就用单引号
```

### 换行和特殊字符

如果想在一个字符串里换行，可以用 `\n`（反斜杠 + n，n 代表 new line，新的一行）：

```python
print("第一行\n第二行\n第三行")
```

输出：

```text
第一行
第二行
第三行
```

像 `\n` 这样以反斜杠开头、有特殊含义的写法叫**转义字符**。常用的还有：

| 写法 | 含义 |
|------|------|
| `\n` | 换行 |
| `\t` | 制表符（Tab，一段空白，用来对齐） |
| `\\` | 一个真正的反斜杠 `\` |
| `\"` | 在双引号字符串里写一个双引号 |

### 多行文字：三引号

很长的一段文字，可以用三个引号 `"""` 包起来，里面可以直接回车换行：

```python
print("""静夜思
床前明月光，
疑是地上霜。""")
```

## 1.4 一次打印多个东西

`print` 的括号里可以放多个东西，用**逗号**隔开，它们之间会自动加一个空格：

```python
print("我今年", 18, "岁")
```

输出：

```text
我今年 18 岁
```

注意 `18` 没有加引号——它是一个**数字**，不是文字。`print` 既能打印文字，也能打印数字。

还可以直接让 Python 做计算：

```python
print(1 + 2)
print("1 + 2")
print("一天有", 24 * 60, "分钟")
```

输出：

```text
3
1 + 2
一天有 1440 分钟
```

看出区别了吗？`1 + 2` 没有引号，Python 会**计算**它，得到 `3`；`"1 + 2"` 有引号，是一段文字，原样显示。在 Python 里 `*` 表示乘号。

### 控制分隔符和结尾

`print` 有两个常用的「设置项」：

- `sep`：多个东西之间用什么隔开（默认是一个空格）。
- `end`：打印完以后在末尾加什么（默认是 `\n`，也就是换行）。

```python
print("2026", "11", "12", sep="-")
print("不换行", end="")
print("，接着上一行")
```

输出：

```text
2026-11-12
不换行，接着上一行
```

## 1.5 注释：写给人看的话

以 `#` 开头的内容叫**注释**。Python 会完全忽略它，它是写给人看的说明：

```python
# 这是一个注释：下面这行会打印问候语
print("你好！")  # 注释也可以写在代码后面

# print("这一行不会运行，因为前面有 #")
```

注释的两大用途：

1. **解释代码**：告诉别人（和三个月后的你自己）这段代码在做什么、为什么这么做。
2. **临时禁用代码**：调试时在一行前加 `#`，让它暂时不运行。

> [!TIP]
> 在编辑器里选中几行，按 <kbd>Ctrl</kbd> + <kbd>/</kbd>（Mac 上是 <kbd>⌘</kbd> + <kbd>/</kbd>）可以一次性加上或去掉注释。

## 1.6 程序是怎么运行的？

你点「运行」之后，背后发生了这些事：

```text
你写的代码 (main.py)
      │
      ▼
Python 解释器：读一行 → 理解它 → 执行它 → 再读下一行……
      │
      ▼
屏幕上显示结果
```

Python 是一种**解释型**语言：有一个叫「解释器」的程序（就是你安装的 Python），它逐行读取你的代码并执行。后面学 C、Rust 时，你会见到另一种方式——**编译型**：先把整个程序翻译成机器能直接执行的文件，再运行它。

在本课程的学习程序里，你只需要点「▶ 运行」。以后在自己电脑的终端里，也可以这样运行：

```console
python3 hello.py
```

（Windows 上通常是 `python hello.py` 或 `py hello.py`，在「编程起步」课程里有详细说明。）

## 1.7 常见错误（一定要看！）

写错是正常的，专业程序员每天也会写出几十个错误。关键是**看懂错误信息**。错误信息虽然是英文，但格式很固定：

```text
  File "main.py", line 1
    print("你好"）
               ^
SyntaxError: invalid character '）' (U+FF09)
```

读法：**在哪个文件（main.py）、第几行（line 1）、哪个位置（^ 指着的地方）、什么错误（SyntaxError 语法错误）、具体原因**。

### 错误 1：用了中文标点

```python norun
print("你好"）
```

右括号 `）` 是中文的全角符号，Python 不认识。**代码里的括号、引号、逗号、冒号，都必须用英文输入法输入。** 中文只能出现在引号里面。

> [!WARNING]
> 中文输入法很容易在不知不觉中打出全角符号。写代码时，建议把输入法切换到英文状态；需要输入中文文字时再切回来。全角 `（），：“”` 和半角 `(),:""` 看起来很像，要仔细看。

### 错误 2：拼写错误或大小写错误

```python norun
Print("你好")
```

```text
NameError: name 'Print' is not defined
```

Python **区分大小写**：`print` 和 `Print` 是两个完全不同的名字。Python 只认识小写的 `print`。

### 错误 3：忘了引号

```python norun
print(你好)
```

```text
NameError: name '你好' is not defined
```

没有引号，Python 会把 `你好` 当成一个「名字」（变量，下一课会学）去查找，找不到就报错。想表示文字，一定要加引号。

### 错误 4：引号或括号不成对

```python norun
print("你好)
```

```text
SyntaxError: unterminated string literal (detected at line 1)
```

`unterminated string literal` 意思是「没有结束的字符串」——少了一个结尾的引号。

> [!TIP]
> 在本课程的程序里运行出错时，错误信息下面会有一个「💬 这是什么意思？」的中文解释框。先读解释，再回到代码里找问题。

## 1.8 小结

- `print(...)` 把括号里的内容显示到屏幕上。
- 用引号包起来的文字叫**字符串**，单引号、双引号都可以；三引号可以写多行。
- `\n` 表示换行；`print` 的 `sep` 和 `end` 可以控制分隔符和结尾。
- 没有引号的 `1 + 2` 会被计算，有引号的 `"1 + 2"` 原样显示。
- `#` 开头的是注释，Python 会忽略它。
- 代码里的符号必须是**英文半角**；Python **区分大小写**。
- 错误信息要看：文件、行号、`^` 位置、错误类型和原因。
