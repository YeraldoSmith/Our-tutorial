## 13.1 Вы всё время пользовались объектами

```python
name = "hello"
print(name.upper())          # у «объекта»-строки есть метод upper
nums = [3, 1, 2]
nums.sort()                  # у объекта-списка есть метод sort
print(nums, type(nums))
```

В Python **всё — объекты**: строки, списки, словари, функции… У каждого объекта есть свои **данные** (символы строки, элементы списка) и **операции** над ним (`upper`, `sort`, `append`); такие операции называются **методами** (method).

`str` и `list` — встроенные в Python **типы**, их ещё называют **классами** (class). В этом уроке мы научимся определять **свои классы** — например, «персонажа» в игре с именем и очками здоровья, который умеет атаковать и получать урон.

## 13.2 Определяем класс

```python
class Dog:
    def __init__(self, name, age):     # вызывается автоматически при создании объекта: задаёт его данные
        self.name = name               # self.name — собственный «атрибут» этого объекта
        self.age = age

    def bark(self):                    # метод: функция, принадлежащая классу; первый параметр — всегда self
        print(f"{self.name}: Гав!")

    def birthday(self):
        self.age += 1                  # методы могут менять данные объекта
        print(f"{self.name} теперь {self.age} года")

a = Dog("Шарик", 3)                    # создаём объект (его ещё называют «экземпляром») по классу
b = Dog("Бобик", 1)
a.bark()
b.bark()
a.birthday()
print(a.age, b.age)                    # данные двух собак независимы: 4 1
```

По частям:

- **`class Dog:`** определяет класс с именем `Dog`. Имена классов принято писать в стиле CamelCase **с заглавной буквы** (`BankAccount`, `GameCharacter`).
- **Класс — это чертёж, объекты — вещи, построенные по нему**: `Dog` — проект «собаки», а `a` и `b` — две конкретные собаки.
- **`__init__`** (по два подчёркивания с каждой стороны) — **метод инициализации**: `Dog("Шарик", 3)` создаёт новый объект и автоматически вызывает `__init__(новый_объект, "Шарик", 3)`.
- **`self`** означает «этот самый объект». `a.bark()` по сути то же, что `Dog.bark(a)`, поэтому внутри `bark` `self` — это `a`. Методы обязательно определяются с `self` первым параметром, но при вызове его не передают.
- **`self.name = name`** сохраняет параметр `name` в атрибут объекта `self.name`, чтобы он был доступен в других методах.

## 13.3 Красивый вывод объектов: `__str__`

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(3, 4)
print(p)                     # <__main__.Point object at 0x...>: ничего не понятно
```

Определите метод `__str__`, чтобы сказать Python, что показывать при печати объекта:

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f"({self.x}, {self.y})"

    def distance_to_origin(self):
        return (self.x ** 2 + self.y ** 2) ** 0.5

p = Point(3, 4)
print(p)                             # (3, 4)
print("расстояние до начала координат", p.distance_to_origin())
```

## 13.4 Полный пример: банковский счёт

Хранить вместе данные (баланс) и правила (нельзя уходить в минус) — именно то, что лучше всего удаётся классам:

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("сумма вклада должна быть больше 0")
        self.balance += amount

    def withdraw(self, amount):
        if amount > self.balance:
            raise ValueError(f"недостаточно средств: осталось только {self.balance} руб.")
        self.balance -= amount

    def __str__(self):
        return f"счёт владельца {self.owner}, баланс {self.balance} руб."

acc = BankAccount("Петя", 100)
acc.deposit(50)
print(acc)
try:
    acc.withdraw(500)
except ValueError as e:
    print("снятие не удалось:", e)
acc.withdraw(30)
print(acc)
```

Тем, кто пользуется этим классом, не нужно знать, как хранится баланс: они просто вызывают `deposit` и `withdraw`. А правило «нельзя в минус» живёт внутри класса и не может быть забыто. Это называется **инкапсуляцией** (encapsulation).

## 13.5 Атрибуты класса и атрибуты экземпляра

- **атрибуты экземпляра**: `self.xxx`, у каждого объекта своя копия (у каждой собаки своё имя);
- **атрибуты класса**: записаны прямо внутри `class`, **общие** для всех объектов (все собаки — «псовые»).

```python
class Dog:
    species = "псовые"            # атрибут класса: общий для всех Dog
    count = 0

    def __init__(self, name):
        self.name = name          # атрибут экземпляра: у каждой собаки свой
        Dog.count += 1            # атрибут класса меняем через имя класса

a, b = Dog("Шарик"), Dog("Бобик")
print(a.species, b.species)       # псовые псовые
print("создано собак:", Dog.count)
```

## 13.6 Наследование: расширяем существующий класс

У многих классов есть общее: и собаки, и кошки — животные с именем, которые подают голос, только по-разному. **Наследование** (inheritance) даёт новому классу все атрибуты и методы существующего, и остаётся только добавить или изменить то, что отличается:

```python
class Animal:                              # родительский (базовый) класс
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "…"

    def introduce(self):
        return f"Я {self.name}, и я говорю: {self.speak()}"

class Dog(Animal):                         # Dog наследует Animal
    def speak(self):                       # переопределяем метод родителя
        return "Гав"

class Cat(Animal):
    def __init__(self, name, indoor):
        super().__init__(name)             # сначала вызываем __init__ родителя, чтобы задать name
        self.indoor = indoor               # затем добавляем свой атрибут

    def speak(self):
        return "Мяу~"

for pet in [Dog("Шарик"), Cat("Мурка", indoor=True), Animal("какое-то животное")]:
    print(pet.introduce())
```

- в `class Dog(Animal):` родительский класс указывается в скобках;
- методы, которых нет у потомка (`introduce`), берутся у родителя; метод с тем же именем у потомка (`speak`) заменяет родительский;
- `super().__init__(...)` вызывает метод родителя, чтобы не повторять код;
- один и тот же вызов `pet.introduce()` делает разное для разных объектов — это **полиморфизм** (polymorphism).

> [!TIP]
> Наследование полезно, но не злоупотребляйте им. Если «A — **разновидность** B» (собака — разновидность животного), используйте наследование; если «у A **есть** B» (у машины есть двигатель), сделайте B атрибутом A (это **композиция**). На практике композиция часто проще и понятнее глубоких цепочек наследования.

## 13.7 Современный способ: `@dataclass`

Многие классы нужны только для того, чтобы **хранить данные**, и каждый раз писать `__init__`, `__str__`, сравнения и прочее утомительно. Начиная с Python 3.7, **`dataclasses`** генерируют это за вас:

```python
from dataclasses import dataclass

@dataclass
class Student:
    name: str
    score: int
    grade: int = 1                    # значения по умолчанию разрешены

a = Student("Петя", 88)
b = Student("Маша", 95, grade=2)
print(a)                              # красивый вывод даром: Student(name='Петя', score=88, grade=1)
print(a == Student("Петя", 88))       # сравнение «равно» даром: True

students = [a, b, Student("Коля", 88)]
students.sort(key=lambda s: (-s.score, s.name))      # сначала высокий балл, при равенстве — по имени
print([s.name for s in students])
```

`@dataclass`, записанный над определением класса, — это **декоратор** (decorator). Достаточно перечислить поля с аннотациями типов, и `__init__`, `__repr__` и `__eq__` появятся сами. **Если нужен класс «для данных», в первую очередь берите `@dataclass`.**

## 13.8 `@property`: методы, которые выглядят как атрибуты

Некоторые значения **вычисляются** из других атрибутов или требуют **проверки** при изменении. `@property` позволяет пользоваться методом как обычным атрибутом:

```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    @property
    def area(self):                  # используется без скобок: r.area
        return self.width * self.height

r = Rectangle(3, 4)
print(r.area)                        # 12
r.width = 10
print(r.area)                        # 40: всегда считается по текущим ширине и высоте
```

## 13.9 Специальные методы: поддержка `+`, `==`, `len`…

Методы, имена которых начинаются и заканчиваются двумя подчёркиваниями (как `__init__` и `__str__`), называются **специальными методами** («магическими методами»). Определите их — и ваши объекты будут поддерживать встроенный синтаксис Python:

```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):             # v1 + v2
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, k):                 # v * 3
        return Vector(self.x * k, self.y * k)

    def __eq__(self, other):              # v1 == v2
        return self.x == other.x and self.y == other.y

    def __len__(self):                    # len(v): здесь — число измерений
        return 2

    def __repr__(self):                   # как он выглядит в списках и интерактивном режиме
        return f"Vector({self.x}, {self.y})"

v = Vector(1, 2) + Vector(3, 4)
print(v, v * 3, len(v))
print(Vector(1, 1) == Vector(1, 1))
print([Vector(0, 0), v])
```

| Специальный метод | Какой синтаксис поддерживает |
|-------------------|------------------------------|
| `__init__` | создание объекта `ИмяКласса(...)` |
| `__str__` / `__repr__` | `print(obj)` / показ в интерактивном режиме и в списках |
| `__eq__`, `__lt__` | `==`, `<` (с `__lt__` можно использовать `sorted`) |
| `__add__`, `__sub__`, `__mul__` | `+`, `-`, `*` |
| `__len__` | `len(obj)` |
| `__getitem__` | `obj[i]` |
| `__contains__` | `x in obj` |

> [!NOTE]
> Python не так важно, «какого типа» объект, как то, «что он умеет»: определите `__len__` — и заработает `len()`; сделайте объект перебираемым через `for` — и его можно использовать как последовательность. Это **утиная типизация**: «если оно ходит как утка и крякает как утка, то это утка».

## 13.10 Частые ошибки

```python norun
class Dog:
    def bark():                  # забыли self
        print("Гав")

Dog().bark()
```

```text
TypeError: Dog.bark() takes 0 positional arguments but 1 was given
```

При вызове `d.bark()` Python автоматически передаёт объект первым аргументом, поэтому в определении метода обязательно должен быть `self`.

```python norun
class Dog:
    def __init__(self, name):
        name = name              # забыли self. — это просто присваивание локальной переменной

d = Dog("Шарик")
print(d.name)
```

```text
AttributeError: 'Dog' object has no attribute 'name'
```

Пишите `self.name = name`, чтобы атрибут сохранился в объекте.

```python norun
class Dog:
    def __init__(self, name):
        self.name = name

d = Dog()
```

```text
TypeError: Dog.__init__() missing 1 required positional argument: 'name'
```

При создании объекта передайте аргументы, которых ждёт `__init__`: `Dog("Шарик")`.

## 13.11 Итоги

- Объект = данные (атрибуты) + операции (методы); класс — чертёж, а объекты (экземпляры) строятся по нему.
- `class Имя:` определяет класс; `__init__(self, ...)` задаёт начальные данные; первый параметр метода — `self`, сам объект.
- `self.атрибут` — атрибут экземпляра, свой у каждого объекта; атрибуты в теле класса — атрибуты класса, общие для всех объектов.
- `__str__` определяет, как `print` показывает объект; `@property` позволяет обращаться к методу как к атрибуту; специальные методы `__add__`, `__eq__`, `__len__` и другие дают объектам встроенный синтаксис.
- Наследование: `class Потомок(Родитель):` — переопределяйте методы и вызывайте родителя через `super()`; наследование — для «является разновидностью», композиция — для «имеет».
- Для классов, которые только хранят данные, `@dataclass` автоматически создаёт `__init__`, `__repr__` и `__eq__`.

### Задание 5: Что выведет программа

```python
class Counter:
    total = 0

    def __init__(self):
        self.count = 0
        Counter.total += 1

    def click(self):
        self.count += 1

a = Counter()
b = Counter()

```

<details>
<summary>Ответ и разбор</summary>

</details>

### Задание 6: Что такое `self`?

В вызове `d.bark()` на что указывает `self` внутри метода `bark`?

- на класс `Dog`
- на сам объект `d`
- на метод `bark`
- на новый созданный `Dog`

<details>
<summary>Ответ и разбор</summary>

`d.bark()` — то же самое, что `Dog.bark(d)`, поэтому `self` — это объект `d`, у которого вызван метод. Через `self` метод может читать и менять собственные данные этого объекта.
</details>
