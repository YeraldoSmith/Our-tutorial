## 2.1 Переменная — это имя для данных

В уроке 1 мы печатали данные напрямую. Настоящим программам нужно **запоминать** данные и использовать их позже: игра помнит очки, имя и здоровье игрока. Для этого и нужны **переменные**:

```python
score = 100
name = "Саша"
print(name, "набрал", score, "очков")
```

Вывод:

```text
Саша набрал 100 очков
```

`score = 100` означает: **создать имя `score` и связать его со значением `100`**. Дальше, где бы вы ни написали `score`, Python подставит `100`.

Представьте переменную как **ярлык, приклеенный к значению**:

```text
   score ──►  100
   name  ──►  "Саша"
```

> [!IMPORTANT]
> Этот `=` — **не «равно» из математики**, а **присваивание**: отдать значение справа имени слева. Читайте как «score **получает** 100». Чтобы проверить равенство, нужны два знака: `==` (урок 6).

## 2.2 Изменение переменной

Переменная потому так и называется, что её значение может меняться:

```python
score = 100
print(score)
score = 120        # ярлык переклеен на новое значение
print(score)
```

Вывод:

```text
100
120
```

Чаще значение меняют **на основе текущего**:

```python
score = 100
score = score + 10    # сначала правая часть: 100 + 10 = 110, затем запись в score
print(score)
```

`score = score + 10` в математике — бессмыслица, а в программировании — обычное дело: **вычислить правую часть, затем присвоить левой**. Это так часто нужно, что в Python есть сокращения:

```python
score = 100
score += 10     # то же, что score = score + 10
score -= 30     # то же, что score = score - 30
score *= 2      # то же, что score = score * 2
print(score)    # (100 + 10 - 30) * 2 = 160
```

### Присваивание одной переменной другой

```python
a = 5
b = a       # b тоже связана с 5
a = 8       # a теперь 8, b это не затрагивает
print(a, b)
```

Будет выведено `8 5`. `b = a` отдаёт `b` значение, которое было у `a` **в тот момент**; последующие изменения `a` на `b` не влияют.

## 2.3 Правила именования

Назвать переменную как угодно нельзя. Нужно соблюдать **правила** (их нарушение — ошибка):

1. только **буквы, цифры и подчёркивание `_`**;
2. **нельзя начинать с цифры**: `player1` можно, `1player` нельзя;
3. **регистр важен**: `Score` и `score` — разные переменные;
4. нельзя использовать **ключевые слова** Python: `if`, `for`, `class`, `True`, `None` и т. д.

И есть **соглашения** (их нарушение не ошибка, но все им следуют):

- **строчные слова через подчёркивание** — «змеиный регистр» (snake_case): `player_name`, `max_speed`;
- **осмысленные имена**: `total_price` гораздо лучше, чем `tp`, `a` или `x1`;
- значения, которые никогда не меняются (константы), — **ЗАГЛАВНЫМИ**: `PI = 3.14159`, `MAX_LEVEL = 99`.

| Имя | Можно? | Примечание |
|-----|--------|------------|
| `age` | ✅ | |
| `user_name` | ✅ | рекомендуемый стиль |
| `userName` | ✅ | работает, но в Python принято подчёркивание |
| `_count` | ✅ | подчёркивание в начале имеет особый смысл (позже) |
| `2nd_place` | ❌ | начинается с цифры |
| `my-name` | ❌ | `-` читается как минус |
| `class` | ❌ | ключевое слово |
| `возраст` | ✅ | Python 3 разрешает русские буквы, но так **не принято** — пишите имена по-английски |

> [!TIP]
> Придумывая имя, спросите себя: через три месяца я сразу пойму, что хранит эта переменная?

## 2.4 Типы данных

У каждого значения в Python есть **тип**, который определяет, что с этим значением можно делать. Четыре основных:

| Тип | Название | Примеры | Для чего |
|-----|----------|---------|----------|
| `int` | целое число | `42`, `-7`, `0` | счёт, возраст, очки |
| `float` | число с плавающей точкой (дробное) | `3.14`, `-0.5`, `2.0` | цены, рост, температура |
| `str` | строка (текст) | `"привет"`, `'abc'`, `""` | имена, сообщения |
| `bool` | логическое значение | `True`, `False` | да/нет, вкл/выкл |

`type()` показывает тип значения:

```python
print(type(42))
print(type(3.14))
print(type("привет"))
print(type(True))
```

Вывод:

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

### На что обратить внимание

- `2` — это `int`, `2.0` — `float`, `"2"` — `str`: **выглядят похоже, а типы разные**.
- `True` и `False` пишутся с **заглавной буквы**; `true` вызовет `NameError`.
- Большие числа удобно разделять подчёркиванием: `population = 146_000_000` (Python его игнорирует). Обратите внимание: дробная часть в Python отделяется **точкой**, а не запятой: `3.14`, не `3,14`.
- Есть особое значение **`None`** — «**здесь ничего нет**», тип `NoneType`. Например, `winner = None`, пока никто не победил.

### Динамическая типизация

В Python у переменной нет фиксированного типа — **тип есть у значения**. Одна и та же переменная может сначала указывать на число, а потом на строку:

```python
x = 10
print(type(x))
x = "десять"
print(type(x))
```

Это **динамическая типизация**: удобно, но легко ошибиться, поэтому хорошая привычка — хранить в переменной всегда одно и то же по смыслу. (Java, C и Rust — языки со **статической типизацией**: тип переменной задаётся при объявлении. Разницу вы увидите позже.)

## 2.5 Преобразование типов

Преобразовывать типы приходится часто. Самый частый случай: **число и текст нельзя склеить напрямую**.

```python norun
age = 18
print("Мне " + age + " лет")    # ❌ ошибка
```

```text
TypeError: can only concatenate str (not "int") to str
```

Строку можно соединить через `+` только со строкой. Решение — **превратить число в строку**:

```python
age = 18
print("Мне " + str(age) + " лет")
```

Основные функции преобразования:

| Функция | Что делает | Пример | Результат |
|---------|------------|--------|-----------|
| `int(x)` | в целое | `int("42")`, `int(3.9)` | `42`, `3` (дробная часть отбрасывается — **не** округление) |
| `float(x)` | в дробное | `float("3.5")`, `float(2)` | `3.5`, `2.0` |
| `str(x)` | в строку | `str(100)` | `"100"` |
| `bool(x)` | в логическое | `bool(0)`, `bool("hi")` | `False`, `True` |

```python
print(int("42") + 8)       # 50: текст "42" сначала стал числом
print("42" + "8")          # 428: склеены две строки
print(int(3.9))            # 3
print(round(3.9))          # 4: для округления — round
```

Не всё можно преобразовать: `int("abc")` и `int("3.5")` вызывают `ValueError`, потому что это не запись целого числа.

> [!NOTE]
> Правила `bool()`: `0`, `0.0`, пустая строка `""` и `None` превращаются в `False`, почти всё остальное — в `True`. Это пригодится для условий в уроке 6.

## 2.6 Несколько присваиваний сразу

```python
x, y, z = 1, 2, 3        # три переменные за раз
print(x, y, z)

a = b = 0                # обе равны 0
print(a, b)
```

Очень полезный приём — **обмен значениями двух переменных**:

```python
left = "яблоко"
right = "банан"
left, right = right, left
print(left, right)       # банан яблоко
```

Во многих языках для обмена нужна временная переменная; в Python хватает одной строки.

## 2.7 f-строки: значения переменных внутри текста

Склеивать через `+` и `str()` неудобно. В Python есть способ лучше — **f-строки**: поставьте `f` перед строкой и пишите `{имя}`, чтобы вставить значение:

```python
name = "Саша"
age = 18
height = 1.756
print(f"Я {name}, мне {age} лет, рост {height} м")
print(f"В следующем году мне будет {age + 1}")   # в скобках может быть любое выражение
print(f"Рост около {height:.2f} м")              # :.2f — два знака после точки
```

Вывод:

```text
Я Саша, мне 18 лет, рост 1.756 м
В следующем году мне будет 19
Рост около 1.76 м
```

f-строки — самый распространённый способ форматирования в современном Python; дальше они встретятся почти в каждом уроке. Подробнее — в уроке 4.

## 2.8 Частые ошибки

### Переменная используется до присваивания

```python norun
print(total)
total = 100
```

```text
NameError: name 'total' is not defined
```

Программа выполняется сверху вниз; на строке 1 `total` ещё нет. **Сначала присвоить, потом использовать.**

### Разное написание

```python norun
user_name = "Петя"
print(username)        # пропущено подчёркивание
```

Тоже `NameError`. Python не догадывается — имя должно совпадать в точности.

### Число плюс строка

```python norun
count = 5
print("Количество: " + count)
```

`TypeError`. Используйте `str(count)` или просто f-строку: `print(f"Количество: {count}")`.

## 2.9 Итоги

- `имя = значение` отдаёт значение переменной; `=` — это **присваивание**, а не равенство.
- Переменную можно переприсвоить; `x += 1` — сокращение для `x = x + 1`.
- Правила: буквы/цифры/подчёркивание, не с цифры, регистр важен, без ключевых слов; принято `snake_case`, константы ЗАГЛАВНЫМИ.
- Основные типы: `int`, `float`, `str`, `bool` и `None` для «ничего»; проверка — `type()`.
- Преобразование: `int()`, `float()`, `str()`, `bool()`; `int()` отбрасывает дробную часть, `round()` округляет.
- `a, b = b, a` меняет местами; f-строки `f"…{переменная}…"` вставляют значения в текст.
