## 11.1 `import`: пользуемся готовыми инструментами

Вместе с Python устанавливаются сотни **модулей** (module) — всё вместе это **стандартная библиотека**. Модуль — это файл `.py` с готовыми функциями и переменными. `import` «подключает» его:

```python
import math

print(math.sqrt(16))       # квадратный корень: 4.0
print(math.pi)             # число пи
print(math.ceil(2.1))      # округление вверх: 3
```

Писать `import` можно по-разному:

```python
import math                       # пользуемся как math.sqrt
from math import sqrt, pi         # берём sqrt и pi напрямую, без math.
import datetime as dt             # даём модулю короткое имя

print(sqrt(2), pi)
print(dt.date.today().year >= 2024)
```

> [!TIP]
> Обычно рекомендуют вариант `import math`: по `math.sqrt` сразу видно, откуда функция. **Не** пишите `from math import *` (подключить всё) — имена легко пересекутся с вашими переменными.

### Часто используемые модули стандартной библиотеки

| Модуль | Назначение | Пример |
|--------|-----------|--------|
| `math` | математические функции | `math.sqrt(2)`, `math.floor(3.7)` |
| `random` | случайные числа | `random.randint(1, 6)`, `random.choice(lst)` |
| `datetime` | даты и время | `datetime.date.today()` |
| `statistics` | статистика | `statistics.mean(nums)`, `statistics.median(nums)` |
| `collections` | дополнительные структуры данных | `Counter`, `defaultdict`, `deque` |
| `pathlib` | пути к файлам | `Path("data.txt").exists()` |
| `json`, `csv` | форматы данных | см. вторую половину урока |
| `time` | замер времени, паузы | `time.sleep(1)`, `time.perf_counter()` |
| `os`, `sys` | операционная система и интерпретатор | `sys.version`, `os.getcwd()` |

```python
import random
import statistics
from datetime import date, timedelta

random.seed(1)                                   # фиксируем зерно: каждый запуск одинаковый
dice = [random.randint(1, 6) for _ in range(10)]
print("10 бросков кубика:", dice)
print("среднее:", statistics.mean(dice), " медиана:", statistics.median(dice))

d = date(2025, 1, 1)
print(d + timedelta(days=100))                   # дата через 100 дней
print(d.isoweekday())                            # день недели (1 = понедельник … 7 = воскресенье)
```

Чтобы узнать, что умеет модуль, загляните в [документацию Python](https://docs.python.org/3/library/index.html) или наберите `help(math)` в интерактивном режиме.

## 11.2 Пишем свои модули

Когда программа растёт, её можно разбить на несколько файлов. Допустим, в одной папке два файла:

```python norun
# файл geometry.py
PI = 3.14159

def circle_area(r):
    return PI * r * r
```

```python norun
# файл main.py
import geometry

print(geometry.circle_area(2))
print(geometry.PI)
```

При запуске `main.py` строка `import geometry` найдёт `geometry.py` в той же папке, и его функциями можно будет пользоваться. **Имя модуля — это имя файла без `.py`**, поэтому не используйте в именах файлов пробелы и русские буквы, а также **не повторяйте имена стандартной библиотеки** (не называйте свой файл `math.py` или `random.py`, иначе `import random` подключит ваш файл).

### `if __name__ == "__main__":`

У каждого модуля есть особая переменная `__name__`: при прямом запуске файла она равна `"__main__"`, а когда файл подключают через `import` — имени модуля.

```python
def main():
    print("программа начинается здесь")

print("__name__ равно:", __name__)

if __name__ == "__main__":      # выполняется, только когда файл запущен напрямую
    main()
```

Поместите «то, что делается при прямом запуске», внутрь `if __name__ == "__main__":` — и файл **можно и запускать напрямую, и подключать из других файлов, ничего не выполняя случайно**. Это стандартный способ писать программы на Python.

> [!NOTE]
> Учебная программа и сайт запускают по одному файлу, поэтому примеры из нескольких файлов в этом уроке помечены как незапускаемые. Чтобы попробовать, создайте на компьютере папку, положите в неё оба файла и выполните в терминале `python main.py` (о терминале — в уроке 3 части 1).

## 11.3 Чтение и запись файлов

Данные в переменных исчезают, когда программа завершается. Чтобы **сохранить** их, нужно записать их в **файл**.

### Запись в файл

```python
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("первая строка\n")      # write не добавляет перевод строки: пишите \n сами
    f.write("вторая строка\n")
    print("третья строка", file=f)  # print тоже умеет писать в файл (с переводом строки)

print("готово")
```

- `open(имя_файла, режим, encoding=...)` открывает файл и даёт **файловый объект** `f`;
- режим `"w"` — запись (**существующий файл очищается**); `"a"` — дописывание в конец; `"r"` — чтение (по умолчанию);
- **`with ... as f:`** — файл **закрывается автоматически**, когда блок с отступом заканчивается, даже если случилась ошибка. Всегда используйте `with`.

### Чтение файла

```python
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("яблоки 5\nбананы 3\nапельсины 8\n")

with open("notes.txt", encoding="utf-8") as f:       # режим по умолчанию — "r"
    content = f.read()                                 # прочитать всё сразу (одна строка)
print(repr(content))

with open("notes.txt", encoding="utf-8") as f:
    for line in f:                                     # читаем построчно (чаще всего, экономит память)
        name, count = line.split()
        print(f"{name}: {count} шт.")
```

При построчном чтении каждая строка заканчивается символом `\n`; `line.strip()` убирает его (`split()` выше убирает его сам).

### Всегда пишите `encoding="utf-8"`!

В файлах хранятся **байты**, которые превращаются в текст по какой-то **кодировке** (UTF-8 мы разбирали в уроке о токенизации). Если её не указать, Python возьмёт **кодировку операционной системы по умолчанию**: в русской Windows это часто cp1251, в китайской — GBK, в macOS и Linux — UTF-8. В итоге программа, которая работает на одном компьютере, на другом показывает «кракозябры» или падает:

```text
UnicodeDecodeError: 'charmap' codec can't decode byte 0x98 in position 5: character maps to <undefined>
```

**Сделайте привычкой: всегда пишите `encoding="utf-8"`, открывая текстовый файл.** (Согласно PEP 686, с Python 3.15 по умолчанию используется UTF-8; но на многих компьютерах ещё стоят старые версии, так что продолжайте её указывать.)

## 11.4 `pathlib`: современная работа с путями

Пути в разных системах записываются по-разному: в Windows — `C:\Users\petya\data.txt`, в macOS/Linux — `/home/petya/data.txt`. С `pathlib` об этом можно не думать:

```python
from pathlib import Path

folder = Path("my_data")
folder.mkdir(exist_ok=True)                      # создать папку (без ошибки, если уже есть)
file = folder / "hello.txt"                      # пути соединяются через / — правильно в любой системе
file.write_text("Привет, pathlib!\n", encoding="utf-8")   # записать файл одной строкой
print(file.read_text(encoding="utf-8"))          # прочитать файл одной строкой
print(file.exists(), file.name, file.suffix)     # True hello.txt .txt
print(sorted(p.name for p in folder.glob("*.txt")))   # все файлы .txt в папке
```

> [!NOTE]
> **Относительный путь** вроде `"notes.txt"` отсчитывается от **текущей рабочей папки**, а это не обязательно папка, где лежит ваш файл `.py`. Если программа не находит файл, сначала выведите `print(Path.cwd())`, чтобы увидеть, где вы находитесь.

## 11.5 CSV: табличные данные

**CSV** (значения, разделённые запятыми) — простейший табличный формат, его открывают Excel, LibreOffice и другие. Одна запись — одна строка, столбцы разделены запятыми:

```python
import csv

rows = [["имя", "русский", "математика"], ["Петя", 90, 85], ["Маша", 95, 92]]
with open("scores.csv", "w", newline="", encoding="utf-8") as f:
    csv.writer(f).writerows(rows)

with open("scores.csv", newline="", encoding="utf-8") as f:
    for row in csv.DictReader(f):              # каждая строка — словарь, ключи из заголовка
        total = int(row["русский"]) + int(row["математика"])
        print(row["имя"], "сумма", total)
```

- открывайте CSV-файлы с `newline=""`, чтобы в Windows не появлялись лишние пустые строки;
- всё прочитанное — **строки**; перед вычислениями переводите через `int()` или `float()`;
- чтобы Excel правильно показал русские буквы, файл можно записать с `encoding="utf-8-sig"`.

## 11.6 JSON: сохраняем структурированные данные

Данные «списки + словари» из прошлого урока можно сохранить в файл **JSON** как есть. JSON — самый распространённый формат данных в интернете, и его читают и пишут почти все языки программирования:

```python
import json

data = {"name": "Петя", "age": 12, "hobbies": ["футбол", "рисование"], "member": True}

with open("profile.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)   # записать в файл

with open("profile.json", encoding="utf-8") as f:
    print(f.read())                                     # посмотрим, как выглядит файл

with open("profile.json", encoding="utf-8") as f:
    loaded = json.load(f)                               # прочитать обратно: снова словарь
print(loaded["hobbies"][0], type(loaded))

text = json.dumps(data, ensure_ascii=False)             # dumps / loads переводят в строку и обратно
print(text)
print(json.loads(text) == data)
```

- `ensure_ascii=False` сохраняет русские и другие буквы **как есть**, иначе они превращаются в `\u041f\u0435\u0442\u044f`;
- `indent=2` расставляет отступы, чтобы человеку было удобно читать;
- `True`/`False`/`None` из Python в JSON записываются как `true`/`false`/`null`.

## 11.7 Частые ошибки

```python norun
with open("нет_такого_файла.txt", encoding="utf-8") as f:
    print(f.read())
```

```text
FileNotFoundError: [Errno 2] No such file or directory: 'нет_такого_файла.txt'
```

Имя файла написано с ошибкой или файл не в текущей рабочей папке. Сначала проверьте через `Path("...").exists()` или выведите текущую папку через `print(Path.cwd())`.

```python norun
import random

def random():          # своя функция с тем же именем, что у модуля
    return 4

print(random.randint(1, 6))
```

```text
AttributeError: 'function' object has no attribute 'randint'
```

Имя `random` перезаписано вашей функцией. Не давайте своим переменным, функциям и файлам имена модулей.

```python norun
with open("data.txt", "w") as f:
    f.write(123)
```

```text
TypeError: write() argument must be str, not int
```

`write` принимает только строки: пишите `f.write(str(123))` (и не забывайте `encoding="utf-8"`).

## 11.8 Итоги

- `import модуль`, `from модуль import имя`, `import модуль as псевдоним`; в стандартной библиотеке есть `math`, `random`, `datetime`, `statistics`, `pathlib`, `json`, `csv` и многое другое.
- Ваши файлы `.py` — это модули; не повторяйте имена стандартной библиотеки; `if __name__ == "__main__":` отделяет «запуск напрямую» от «подключения».
- Файлы: `with open(имя, режим, encoding="utf-8") as f:`; `"r"` — чтение, `"w"` — перезапись, `"a"` — дописывание; `for line in f` читает построчно.
- **Всегда пишите `encoding="utf-8"`**, иначе на других системах текст может превратиться в «кракозябры».
- `pathlib.Path` работает с путями на любой платформе: `/` для соединения, `read_text`, `write_text`, `exists`, `glob`.
- CSV — модулем `csv` (с `newline=""`); JSON — через `json.dump/load` (с `ensure_ascii=False`).

<!-- exercise: why-encoding -->
### Задание 5: Зачем указывать кодировку?

Главная причина всегда писать `encoding="utf-8"` при открытии текстовых файлов:

- файлы становятся меньше
- чтобы программа читала и писала русский, китайский и другой текст без «кракозябр» и ошибок на любой операционной системе (например, в русской Windows)
- файлы читаются быстрее
- без этого файл нельзя открыть

<details>
<summary>Ответ и разбор</summary>

Без неё Python использует кодировку системы по умолчанию — в русской Windows часто cp1251, в китайской — GBK. Файл, записанный в UTF-8 и прочитанный там в другой кодировке, превращается в «кракозябры» или вызывает `UnicodeDecodeError`.
</details>

<!-- exercise: why-with -->
### Задание 6: Зачем `with`

Чем `with open(...) as f:` лучше простого `f = open(...)`?

- можно открывать файлы побольше
- файл закрывается автоматически в конце блока, даже если посередине случилась ошибка
- `encoding="utf-8"` добавляется автоматически
- файл автоматически копируется в резервную копию

<details>
<summary>Ответ и разбор</summary>

`with` гарантирует, что файл будет закрыт. Пока файл не закрыт, записанное может ещё не попасть на диск, а система тратит ресурсы. Кодировку за вас он не выбирает.
</details>
