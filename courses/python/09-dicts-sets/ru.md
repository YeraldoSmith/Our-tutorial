# 9. Словари и множества

> 🎯 **Цели урока**: с помощью **словарей** искать данные по «имени», а не по «позиции»; добавлять, удалять, изменять, находить и перебирать элементы словаря; **считать** что-либо словарём (частоты слов); понять, почему список не может быть ключом словаря; с помощью **множеств** убирать повторы и находить пересечения и объединения; понять, почему поиск в словарях и множествах намного быстрее, чем в списках.
>
> ⏱ **Время**: 60 минут　|　📋 **Что нужно знать**: уроки 7 и 8

## 9.1 Зачем нужны словари?

Допустим, вы делаете телефонную книгу. Со списком, чтобы найти номер Маши, придётся сравнивать имена одно за другим от начала до конца. Но настоящие телефонные книги, словари и глоссарии **ищут сразу по имени**.

**Словарь** (dict) в Python устроен именно так: он хранит много пар «**ключ** (key) → **значение** (value)», и значение можно получить прямо по ключу.

```python
phone = {"Петя": "8-900-111-22-33", "Маша": "8-900-444-55-66", "Коля": "8-900-777-88-99"}
print(phone["Маша"])        # по ключу: 8-900-444-55-66
print(len(phone))           # 3 пары ключ-значение
print(phone)
```

Словари записываются в **фигурных скобках** `{ }`; каждая пара — `ключ: значение`, пары разделяются запятыми.

## 9.2 Получаем значения: `[]` и `get`

```python
ages = {"Петя": 12, "Маша": 13}
print(ages["Петя"])                 # 12
print(ages.get("Маша"))             # 13
print(ages.get("Коля"))             # None: для отсутствующего ключа — None, без ошибки
print(ages.get("Коля", 0))          # 0: можно указать значение по умолчанию
print("Коля" in ages)               # False: in проверяет «ключи»
```

Обращение `словарь[ключ]` к **несуществующему** ключу — ошибка:

```python norun
ages = {"Петя": 12}
print(ages["Коля"])
```

```text
KeyError: 'Коля'
```

Поэтому, если не уверены, что ключ есть, сначала проверьте через `in` или используйте `get`.

## 9.3 Добавляем, изменяем, удаляем

Словари **изменяемы**:

```python
stock = {"яблоки": 5, "бананы": 3}
stock["апельсины"] = 10     # нового ключа нет — добавляется пара
stock["яблоки"] = 8         # ключ уже есть — меняется значение
stock["бананы"] += 2        # прибавить 2 к старому значению
print(stock)

del stock["апельсины"]      # удалить пару
n = stock.pop("бананы")     # удалить и вернуть значение
print(n, stock)
```

> [!NOTE]
> **Ключи в словаре не повторяются**: присваивание существующему ключу просто перезаписывает значение. А значения повторяться могут — двум людям может быть одинаково лет.

## 9.4 Перебор словаря

```python
scores = {"русский": 90, "математика": 85, "английский": 92}

for subject in scores:                      # прямой перебор даёт ключи
    print(subject)

for subject, score in scores.items():       # .items(): ключи и значения вместе (чаще всего)
    print(f"{subject}: {score} баллов")

print(list(scores.keys()))                  # все ключи
print(list(scores.values()))                # все значения
print("сумма:", sum(scores.values()))
```

Словарь **помнит порядок добавления** (начиная с Python 3.7): элементы перебираются в том порядке, в каком были добавлены.

## 9.5 Подсчёт с помощью словаря

«Посчитать, сколько раз встречается каждая вещь» — одна из самых частых задач программирования, и словари для неё созданы:

```python
text = "the cat and the dog and the bird"
counts = {}
for word in text.split():
    counts[word] = counts.get(word, 0) + 1     # если слово новое — начинаем с 0, затем +1
print(counts)

# сортируем по количеству, от частых к редким
for word, n in sorted(counts.items(), key=lambda kv: kv[1], reverse=True):
    print(word, n)
```

`counts.get(word, 0) + 1` — классический приём подсчёта: при первой встрече слова `get` возвращает 0. `sorted(..., key=lambda kv: kv[1])` сортирует по **второму элементу** каждой пары (количеству); `lambda` — маленькая одноразовая функция, подробнее о ней в следующем уроке про функции.

В стандартной библиотеке Python есть и специальный инструмент для подсчёта — `Counter`:

```python
from collections import Counter

counts = Counter("the cat and the dog and the bird".split())
print(counts.most_common(2))      # 2 самых частых: [('the', 3), ('and', 2)]
print(Counter("hello"))           # можно считать и буквы
```

## 9.6 Генераторы словарей

Похожи на генераторы списков (урок 8):

```python
squares = {n: n * n for n in range(1, 6)}
print(squares)                            # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

prices = {"яблоки": 5, "арбуз": 20, "виноград": 12}
cheap = {k: v for k, v in prices.items() if v < 15}
print(cheap)                              # оставляем только дешёвое
```

## 9.7 Комбинируем: словари в списках, списки в словарях

Реальные данные часто вложенные. Например, сведения об учениках класса:

```python
students = [
    {"name": "Петя", "age": 12, "hobbies": ["футбол", "рисование"]},
    {"name": "Маша", "age": 13, "hobbies": ["фортепиано"]},
]
for s in students:
    print(f"{s['name']} ({s['age']} лет) любит: {', '.join(s['hobbies'])}")

students[1]["hobbies"].append("плавание")     # берём словарь, в нём список, и меняем его
print(students[1])
```

Такая структура «списки + словари» почти не отличается от **JSON** — самого распространённого формата данных в интернете; в уроке 11 мы научимся сохранять её в файл.

## 9.8 Что может быть ключом?

Ключи должны быть **неизменяемыми** (хешируемыми, hashable) значениями: числа, строки, кортежи подходят; изменяемые значения вроде списков и словарей — нет.

```python
distance = {("Москва", "Санкт-Петербург"): 634, ("Москва", "Казань"): 719}   # кортеж-ключ: «пара городов»
print(distance[("Москва", "Санкт-Петербург")])
```

```python norun
bad = {["Москва", "Казань"]: 719}
```

```text
TypeError: unhashable type: 'list'
```

> [!NOTE]
> Почему? Словарь решает, где хранить ключ, по его «хешу» — числу, вычисленному из содержимого. Если бы содержимое ключа могло меняться, менялся бы и хеш, и ключ больше нельзя было бы найти.

## 9.9 Множества: набор неповторяющихся вещей

**Множество** (set) тоже записывается в фигурных скобках, но в нём только значения, без ключей. Два свойства: **элементы не повторяются** и **нет порядка**.

```python
tags = {"python", "учебник", "python", "программирование"}
print(tags)                       # повторный "python" хранится один раз (порядок может отличаться от записанного)
print(len(tags))                  # 3

nums = [3, 1, 3, 2, 1, 3]
print(set(nums))                  # убрать повторы: {1, 2, 3}
print(sorted(set(nums)))          # убрать повторы и отсортировать: [1, 2, 3]

tags.add("новичкам")
tags.discard("программирование")  # удалить (без ошибки, если элемента нет)
print("учебник" in tags)          # True
```

> [!WARNING]
> Пустое множество записывается `set()`. А `{}` — это **пустой словарь**!

Самое полезное во множествах — **операции над множествами**:

```python
a = {"Петя", "Маша", "Коля"}          # участвовали в олимпиаде по математике
b = {"Маша", "Коля", "Лена"}          # участвовали в олимпиаде по английскому
print(a & b)        # пересечение: участвовали в обеих
print(a | b)        # объединение: хотя бы в одной
print(a - b)        # разность: только в математике
print(a ^ b)        # симметрическая разность: ровно в одной
```

## 9.10 Почему поиск в словарях и множествах такой быстрый?

Чтобы вычислить `x in lst`, Python сравнивает элементы по одному с начала; при миллионе элементов это может занять миллион сравнений. Словари и множества хранятся как **хеш-таблицы**: позиция вычисляется прямо по хешу, поэтому поиск занимает примерно **один шаг**, сколько бы элементов ни было:

```python
import time

n = 200_000
lst = list(range(n))
st = set(lst)

start = time.perf_counter()
for _ in range(200):
    (n - 1) in lst               # нужное число в самом конце
t_list = time.perf_counter() - start

start = time.perf_counter()
for _ in range(200):
    (n - 1) in st
t_set = time.perf_counter() - start

print(f"список: {t_list:.4f} с   множество: {t_set:.6f} с")
```

Поэтому, **если нужно много раз спрашивать «есть ли там…?», используйте множество или словарь, а не список**.

## 9.11 Частые ошибки

```python norun
counts = {}
counts["apple"] += 1
```

```text
KeyError: 'apple'
```

Ключа ещё нет, прибавлять 1 не к чему. Пишите `counts["apple"] = counts.get("apple", 0) + 1`.

```python norun
d = {"a": 1, "b": 2, "c": 3}
for k in d:
    if d[k] < 2:
        del d[k]
```

```text
RuntimeError: dictionary changed size during iteration
```

Нельзя удалять элементы словаря во время его перебора. Перебирайте копию: `for k in list(d):`.

```python norun
s = {}
s.add(1)
```

```text
AttributeError: 'dict' object has no attribute 'add'
```

`{}` — пустой словарь; пустое множество — `set()`.

## 9.12 Итоги

- Словарь `{ключ: значение}` ищет значения по ключу; `d[k]` для отсутствующего ключа даёт `KeyError`, а `d.get(k, по_умолчанию)` — нет.
- Добавление и изменение — это `d[k] = v`; удаление — `del d[k]` или `d.pop(k)`; `in` проверяет ключи.
- Перебор — `for k, v in d.items()`; словари сохраняют порядок добавления.
- Подсчёт: `d[x] = d.get(x, 0) + 1` или `collections.Counter`; сортировка — `sorted(d.items(), key=...)`.
- Ключи должны быть неизменяемыми (числа, строки, кортежи); списки ключами быть не могут.
- Множество `{a, b}` — неповторяющиеся элементы без порядка; `set()` — пустое множество; `& | - ^` — пересечение, объединение, разность и симметрическая разность.
- Поиск в словарях и множествах занимает примерно один шаг — намного быстрее, чем в списках.

### Задание 5: Что выведет программа

```python
d = {"a": 1}
d["b"] = 2
d["a"] += 10
print(d)
print(len(d), "c" in d, d.get("c", 0))
```

<details>
<summary>Ответ и разбор</summary>

`d["b"] = 2` добавляет новый ключ; `d["a"] += 10` превращает 1 в 11. Поэтому сначала выводится `{'a': 11, 'b': 2}`, затем `2 False 0`: длина 2, ключа `"c"` нет, `get` возвращает значение по умолчанию 0.
</details>
