# 8. Списки и кортежи

> 🎯 **Цели урока**: хранить группу значений в списке и добавлять, удалять, изменять, искать и сортировать их; обходить списки через `for` и `enumerate`; начать пользоваться списковыми включениями; понять ловушку «два имени — один список»; познакомиться с кортежами и распаковкой.
>
> ⏱ **Время**: 60 минут　|　📋 **Что нужно знать**: уроки 4 и 7

## 8.1 Зачем нужны списки?

Чтобы хранить оценки класса из 40 учеников, не заводить же 40 переменных `score1`, `score2`… **Список** (list) хранит много значений в **одной** переменной, по порядку:

```python
scores = [88, 92, 75, 64, 99]
names = ["Аня", "Борис", "Вера"]
mixed = [1, "two", 3.0, True]      # разные типы допустимы (но обычно так не делают)
empty = []                         # пустой список
print(scores)
print(len(scores))                 # 5: количество элементов
```

Списки записываются в **квадратных скобках** `[ ]`, элементы разделяются **запятыми**.

## 8.2 Индексы и срезы: как у строк

Индексы, отрицательные индексы и срезы работают **точно так же**, как у строк в уроке 4:

```python
fruits = ["яблоко", "банан", "апельсин", "виноград", "арбуз"]
print(fruits[0])       # яблоко
print(fruits[-1])      # арбуз
print(fruits[1:3])     # ['банан', 'апельсин']
print(fruits[::-1])    # в обратном порядке
print("апельсин" in fruits)  # True
```

## 8.3 Списки можно изменять

В отличие от строк, **списки изменяемы** (mutable): их элементы можно менять напрямую:

```python
scores = [88, 92, 75]
scores[2] = 80         # третий элемент становится 80
print(scores)          # [88, 92, 80]
```

### Добавление элементов

```python
nums = [1, 2, 3]
nums.append(4)         # один в конец: [1, 2, 3, 4]
nums.insert(0, 0)      # вставить по индексу 0: [0, 1, 2, 3, 4]
nums.extend([5, 6])    # несколько в конец: [0, 1, 2, 3, 4, 5, 6]
print(nums)
```

### Удаление элементов

```python
nums = [10, 20, 30, 20, 40]
nums.remove(20)        # удалить первое 20: [10, 30, 20, 40]
last = nums.pop()      # удалить и вернуть последний: last = 40
first = nums.pop(0)    # удалить и вернуть элемент с индексом 0: first = 10
del nums[0]            # удалить по индексу
print(nums, last, first)
nums.clear()           # очистить
print(nums)            # []
```

### Поиск и подсчёт

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]
print(nums.index(5))   # 4: индекс первого 5
print(nums.count(1))   # 2: сколько единиц
print(min(nums), max(nums), sum(nums))   # 1 9 31
print(sum(nums) / len(nums))             # среднее 3.875
```

### Сортировка

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]
nums.sort()                  # сортировка на месте (меняет сам nums)
print(nums)                  # [1, 1, 2, 3, 4, 5, 6, 9]
nums.sort(reverse=True)      # по убыванию
print(nums)

data = [3, 1, 2]
new = sorted(data)           # возвращает новый отсортированный список; исходный не меняется
print(data, new)             # [3, 1, 2] [1, 2, 3]

words = ["banana", "Apple", "cherry"]
print(sorted(words))                  # ['Apple', 'banana', 'cherry']: заглавные идут первыми
print(sorted(words, key=str.lower))   # без учёта регистра
print(sorted(words, key=len))         # по длине
```

> [!IMPORTANT]
> `nums.sort()` **меняет список** и возвращает `None`; `sorted(nums)` **не трогает его** и возвращает новый. Новички часто пишут `nums = nums.sort()` — и получают `nums`, равный `None`!

### Шпаргалка

| Операция | Код |
|----------|-----|
| добавить в конец | `lst.append(x)` |
| вставить | `lst.insert(i, x)` |
| объединить | `lst.extend(другой)` или `lst + другой` |
| удалить по значению | `lst.remove(x)` |
| удалить и вернуть по индексу | `lst.pop(i)` (последний, если i не указан) |
| индекс / количество | `lst.index(x)` / `lst.count(x)` |
| сортировка | `lst.sort()` / `sorted(lst)` |
| разворот | `lst.reverse()` / `lst[::-1]` |
| длина, минимум, максимум, сумма | `len`, `min`, `max`, `sum` |

## 8.4 Обход списка

```python
names = ["Аня", "Борис", "Вера"]
for name in names:
    print(f"Привет, {name}")
```

Если нужны **и индекс, и значение**, используйте `enumerate`:

```python
names = ["Аня", "Борис", "Вера"]
for i, name in enumerate(names, start=1):
    print(f"{i}. {name}")
```

```text
1. Аня
2. Борис
3. Вера
```

Чтобы пройти по двум спискам параллельно, используйте `zip`:

```python
names = ["Аня", "Борис", "Вера"]
scores = [88, 95, 72]
for name, score in zip(names, scores):
    print(f"{name}: {score} баллов")
```

## 8.5 Построение списка в цикле

Самый частый приём: начать с пустого списка и делать `append` в цикле:

```python
n = int(input())
numbers = []
for _ in range(n):
    numbers.append(int(input()))
print("Вы ввели:", numbers)
print("Максимум:", max(numbers))
```

Если n чисел записаны **в одной строке**, используйте `split` + `map` из урока 5 и превратите результат в список через `list()`:

```python
numbers = list(map(int, input().split()))
print(numbers)
```

### Фильтрация

```python
scores = [88, 45, 92, 59, 75, 30]
passed = []
for s in scores:
    if s >= 60:
        passed.append(s)
print(passed)        # [88, 92, 75]
```

## 8.6 Списковые включения

«Цикл + фильтр + append» встречается так часто, что в Python для него есть краткая запись — **списковое включение** (list comprehension):

```python
scores = [88, 45, 92, 59, 75, 30]
passed = [s for s in scores if s >= 60]
print(passed)                          # [88, 92, 75]

squares = [x * x for x in range(1, 6)]
print(squares)                         # [1, 4, 9, 16, 25]

words = ["hello", "world"]
print([w.upper() for w in words])      # ['HELLO', 'WORLD']
```

Читается так: `[что вычислить  for x in откуда  if условие]` — «для каждого x (прошедшего условие) вычислить новое значение и положить в новый список».

> [!TIP]
> Включения хороши для **простых** преобразований и фильтров. Сложную логику понятнее записать обычным циклом `for`.

## 8.7 Вложенные списки: таблицы и матрицы

Элементами списка могут быть другие списки — так представляют двумерную таблицу:

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
]
print(matrix[1])        # [4, 5, 6]: вторая строка
print(matrix[1][2])     # 6: строка 2, столбец 3

for row in matrix:
    for value in row:
        print(value, end=" ")
    print()
```

## 8.8 Ловушка: два имени — один список

```python
a = [1, 2, 3]
b = a          # b и a ссылаются на ОДИН И ТОТ ЖЕ список
b.append(4)
print(a)       # [1, 2, 3, 4] — a тоже изменился!
```

В уроке 2 мы говорили: переменные — это ярлыки. `b = a` не копирует список, а наклеивает второй ярлык на **тот же самый список**. Изменение через любое имя видно через другое:

```text
a ──┐
    ├──► [1, 2, 3, 4]
b ──┘
```

Чтобы получить независимую копию, используйте `copy()` или срез:

```python
a = [1, 2, 3]
b = a.copy()       # или b = a[:] или b = list(a)
b.append(4)
print(a, b)        # [1, 2, 3] [1, 2, 3, 4]
```

> [!NOTE]
> Числа и строки неизменяемы, поэтому `y = x; y += 1` никогда не влияет на `x`: `y += 1` связывает `y` с новым числом. Эффект «поменял одно — изменились оба» бывает только у изменяемых объектов (списков, а также словарей и множеств из следующего урока).

## 8.9 Кортежи: списки, которые нельзя менять

**Кортеж** (tuple) похож на список, но записывается в **круглых скобках** и **не может быть изменён** после создания:

```python
point = (3, 4)
print(point[0])        # 3
colors = ("red", "green", "blue")
print(len(colors), "green" in colors)
```

```python norun
point[0] = 5           # TypeError: 'tuple' object does not support item assignment
```

Когда нужен кортеж? Когда группа значений **не должна меняться**: координаты `(x, y)`, цвет RGB `(255, 128, 0)`, дата `(2026, 11, 12)`. Неизменяемость защищает от случайных изменений.

### Упаковка и распаковка

Кортежами вы уже пользовались:

```python
x, y = 3, 4        # справа 3, 4 — кортеж (упаковка), слева он распаковывается
x, y = y, x        # обмен из урока 2 работает благодаря кортежам
```

```python
point = (3, 4)
x, y = point
print(x, y)

first, *rest = [1, 2, 3, 4]   # * собирает все оставшиеся элементы
print(first, rest)            # 1 [2, 3, 4]
```

> [!NOTE]
> Кортеж из одного элемента пишется с запятой: `(5,)`. `(5)` — это просто число 5 в скобках.

## 8.10 Частые ошибки

```python norun
nums = [1, 2, 3]
print(nums[3])
```

```text
IndexError: list index out of range
```

У списка длины 3 индексы 0, 1, 2.

```python norun
nums = [3, 1, 2]
nums = nums.sort()
print(nums[0])
```

```text
TypeError: 'NoneType' object is not subscriptable
```

`sort()` вернул `None` и затёр `nums`. Пишите просто `nums.sort()` или `nums = sorted(nums)`.

```python norun
nums = [1, 2, 3]
nums.remove(5)
```

```text
ValueError: list.remove(x): x not in list
```

Такого значения в списке нет. Сначала проверьте `if 5 in nums:`.

## 8.11 Итоги

- Список `[a, b, c]` хранит значения по порядку; индексы, срезы, `in` и `len` — как у строк.
- Списки **изменяемы**: `append`, `insert`, `extend`, `remove`, `pop`, `del`, `sort`…
- `lst.sort()` сортирует на месте и возвращает `None`; `sorted(lst)` возвращает новый список; `key=` задаёт, по чему сортировать.
- Обход: `for x in lst`; с индексами — `enumerate`; параллельно — `zip`.
- Списковые включения `[выражение for x in последовательность if условие]`.
- `b = a` не копирует список; копирует `b = a.copy()`.
- Кортежи `(a, b)` неизменяемы; упаковка и распаковка дают множественное присваивание и обмен.

### Задание 5: Что выведет программа

```python
a = [1, 2, 3]
b = a
c = a.copy()
b.append(4)
c.append(5)
print(a)
print(len(b), len(c))
```

<details>
<summary>Ответ и разбор</summary>

`b` — тот же список, что `a`, поэтому после `b.append(4)` `a` равен `[1, 2, 3, 4]`; `c` — копия, и 5 попадает только в неё. Итак, `a` выводится как `[1, 2, 3, 4]`, длина `b` — 4, длина `c` — тоже 4 (`[1, 2, 3, 5]`).
</details>
