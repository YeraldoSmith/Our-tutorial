>

Работа с текстом — одна из самых частых задач в программировании: имена пользователей, анализ статей, отчёты, очистка данных… В этом уроке подробно разбираем строки (`str`).

## 4.1 Строка — последовательность символов

Строка — это **символы по порядку**. У каждого символа есть номер позиции — **индекс**, и **счёт идёт с 0**:

```text
 строка:   P   y   t   h   o   n
 индекс:   0   1   2   3   4   5
 отриц.:  -6  -5  -4  -3  -2  -1
```

Квадратные скобки `[индекс]` берут один символ:

```python
word = "Python"
print(word[0])     # P: первый символ
print(word[3])     # h
print(word[-1])    # n: отрицательные индексы считаются с конца; -1 — последний
print(word[-2])    # o
print(len(word))   # 6: длина (количество символов)
```

> [!IMPORTANT]
> Индексы **начинаются с 0**, поэтому в строке длины 6 у последнего символа индекс 5 (= длина − 1). Так устроены все основные языки. Поначалу все путаются — с практикой это станет привычным.

Несуществующий индекс — ошибка:

```python norun
word = "Python"
print(word[6])
```

```text
IndexError: string index out of range
```

## 4.2 Срезы: берём кусок

`строка[начало:конец]` берёт часть от `начала` до `конца`, **не включая** конец:

```python
word = "Python"
print(word[0:2])    # Py: индексы 0, 1
print(word[2:5])    # tho: индексы 2, 3, 4
print(word[:3])     # Pyt: без начала — с самого начала
print(word[3:])     # hon: без конца — до самого конца
print(word[-3:])    # hon: последние три символа
print(word[:])      # Python: вся строка
```

Удобно запомнить так: **позиции среза — это промежутки между символами**:

```text
   | P | y | t | h | o | n |
   0   1   2   3   4   5   6
word[2:5] режет от промежутка 2 до промежутка 5 → "tho"
```

### Шаг

Третье число — **шаг** (на сколько прыгать):

```python
digits = "0123456789"
print(digits[::2])     # 02468: каждый второй
print(digits[1::2])    # 13579
print(digits[::-1])    # 9876543210: шаг -1 идёт задом наперёд!
```

`s[::-1]` — классический способ перевернуть строку.

В отличие от индекса, **срез не вызывает ошибку** при выходе за границы — вы просто получите то, что есть: `"abc"[1:100]` даёт `"bc"`.

## 4.3 Строку нельзя изменить

Символы созданной строки **изменить нельзя**:

```python norun
word = "Python"
word[0] = "J"
```

```text
TypeError: 'str' object does not support item assignment
```

Чтобы «изменить» строку, создайте новую:

```python
word = "Python"
word = "J" + word[1:]
print(word)     # Jython
```

Это свойство называется **неизменяемостью** (immutability). Все методы строк ниже **возвращают новую строку**, а исходная остаётся прежней:

```python
name = "alice"
upper_name = name.upper()
print(name)          # alice: исходная не изменилась
print(upper_name)    # ALICE
```

## 4.4 Склеивание, повторение и проверка вхождения

```python
first = "Привет"
second = "мир"
print(first + ", " + second + "!")   # склеивание: Привет, мир!
print("ха" * 3)                       # повторение: хахаха
print("-" * 20)                       # разделительная линия
print("иве" in first)                 # True: входит ли подстрока?
print("xyz" not in first)             # True
```

## 4.5 Полезные методы строк

**Метод** — функция, принадлежащая значению; вызывается как `значение.метод()`. У строк их десятки; вот самые нужные.

### Регистр

```python
s = "привет Мир"
print(s.upper())        # ПРИВЕТ МИР
print(s.lower())        # привет мир
print(s.title())        # Привет Мир: каждое слово с заглавной
print(s.capitalize())   # Привет мир: только первая буква
```

### Удаление пробелов

Во вводе пользователя часто бывают лишние пробелы и переводы строк:

```python
s = "   python   \n"
print("[" + s.strip() + "]")    # [python]: убрать пробельные символы по краям
print("[" + s.lstrip() + "]")   # только слева
print("[" + s.rstrip() + "]")   # только справа
```

### Поиск и замена

```python
s = "I like cats. Cats are cute."
print(s.find("cats"))           # 7: индекс первого вхождения
print(s.find("dogs"))           # -1: не найдено
print(s.count("ats"))           # 2: сколько раз встречается
print(s.replace("cats", "dogs"))   # I like dogs. Cats are cute.
print(s.startswith("I"))        # True
print(s.endswith("."))          # True
```

`replace` и `find` **учитывают регистр**: `"Cats"` не заменилось.

### Разбиение и соединение

Эта пара используется постоянно:

```python
sentence = "яблоко банан вишня"
words = sentence.split()        # разбить по пробелам
print(words)                    # ['яблоко', 'банан', 'вишня']

date = "2026-11-12"
parts = date.split("-")         # разбить по "-"
print(parts)                    # ['2026', '11', '12']

print(".".join(parts))          # 2026.11.12: соединить через "."
print(" + ".join(["1", "2", "3"]))   # 1 + 2 + 3
```

`split` возвращает **список** (группу значений в квадратных скобках — урок 8). `join` делает обратное: склеивает группу строк через разделитель.

### Проверка содержимого

```python
print("2026".isdigit())    # True: только цифры
print("abc".isalpha())     # True: только буквы
print("abc123".isalnum())  # True: буквы или цифры
print("   ".isspace())     # True: только пробельные символы
print("Hello".islower())   # False
```

### Шпаргалка

| Метод | Что делает |
|-------|------------|
| `s.upper()` / `s.lower()` | верхний / нижний регистр |
| `s.strip()` | убрать пробелы по краям (`strip("x")` — заданные символы) |
| `s.replace(a, b)` | заменить все a на b |
| `s.find(x)` | индекс первого x или -1 |
| `s.count(x)` | число вхождений x |
| `s.split(sep)` | разбить в список (по пробелам, если sep не задан) |
| `sep.join(список)` | соединить строки списка через sep |
| `s.startswith(x)` / `s.endswith(x)` | начинается / заканчивается на x? |
| `s.isdigit()` / `s.isalpha()` | только цифры / только буквы? |
| `s.center(w)` / `s.ljust(w)` / `s.rjust(w)` | по центру / влево / вправо в ширине w |
| `s.zfill(w)` | дополнить нулями слева до ширины w |

Методы можно **вызывать цепочкой**:

```python
raw = "  Hello, PYTHON!  "
print(raw.strip().lower().replace("!", "?"))   # hello, python?
```

## 4.6 Ещё о форматировании f-строками

f-строки уже встречались в уроках 2 и 3. Ещё несколько полезных приёмов:

```python
name = "Bob"
score = 87.456
print(f"{name:>10}|")          # вправо в ширине 10
print(f"{name:<10}|")          # влево
print(f"{name:^10}|")          # по центру
print(f"{name:*^10}")          # по центру, заполнение *: ***Bob****
print(f"{score:8.2f}|")        # ширина 8, два знака
print(f"{score=}")             # приём для отладки: выводит score=87.456
```

Аккуратная таблица:

```python
print(f"{'Товар':<8}{'Кол':>4}{'Цена':>8}")
print(f"{'Яблоко':<8}{3:>4}{4.5:>8.2f}")
print(f"{'Банан':<8}{12:>4}{0.99:>8.2f}")
```

### Escape-последовательности и «сырые» строки

Вспомним урок 1: `\n` — перевод строки, `\t` — табуляция, `\\` — обратная косая черта, `\"` — кавычка. Если в строке много обратных косых черт (пути Windows, регулярные выражения), поставьте перед ней `r` — получится **«сырая» строка** (raw string), где `\` не экранирует:

```python
print("C:\\new\\table")     # обычной строке нужны двойные \\
print(r"C:\new\table")      # сырая строка: что видим, то и получаем
```

## 4.7 Обход строки (анонс)

Чтобы что-то сделать с **каждым символом**, используют цикл `for` (подробно — в уроке 7):

```python
for ch in "abc":
    print(ch.upper())
```

Выведет `A`, `B`, `C` в трёх строках — пусть пока просто примелькается.

## 4.8 Итоги

- Индексы начинаются с **0**; `s[-1]` — последний символ; `len(s)` — длина.
- Срез `s[начало:конец:шаг]` включает начало и не включает конец; `s[::-1]` переворачивает.
- Строки **неизменяемы**; каждый метод возвращает новую строку.
- `+` склеивает, `*` повторяет, `in` проверяет вхождение.
- Главные методы: `upper/lower`, `strip`, `replace`, `find/count`, `split/join`, `startswith/endswith`, `isdigit/isalpha`.
- f-строки: `{x:>10}` выравнивание, `{x:.2f}` знаки после точки, `{x=}` отладка; `r"..."` — сырая строка.
