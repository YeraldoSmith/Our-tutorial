## 6.1 Программе тоже нужно принимать решения

Жизнь полна решений: **если** идёт дождь — берём зонт; **если** набрал не меньше 60 баллов — сдал, **иначе** пересдача. С программами так же: в зависимости от ситуации выполняется разный код. Это **условие** (ветвление).

```python
temperature = 35
if temperature > 30:
    print("Жарко! Пейте больше воды.")
print("Хорошего дня")
```

Вывод:

```text
Жарко! Пейте больше воды.
Хорошего дня
```

Поменяйте `temperature` на `20` и запустите снова — первое сообщение исчезнет.

## 6.2 Операторы сравнения

Результат условия — **логическое значение**: `True` (истина) или `False` (ложь).

| Оператор | Значение | Пример | Результат |
|----------|----------|--------|-----------|
| `==` | равно | `3 == 3` | `True` |
| `!=` | не равно | `3 != 4` | `True` |
| `>` | больше | `5 > 7` | `False` |
| `<` | меньше | `5 < 7` | `True` |
| `>=` | больше или равно | `7 >= 7` | `True` |
| `<=` | меньше или равно | `8 <= 7` | `False` |

```python
age = 18
print(age >= 18)        # True
print(age == 20)        # False
print("abc" == "abc")   # True: строки тоже можно сравнивать
print("Abc" == "abc")   # False: разный регистр
```

> [!WARNING]
> **`=` присваивает, `==` сравнивает.** `if age = 18:` — синтаксическая ошибка. Её делают новички во всех языках.

Python допускает и **цепочки сравнений**, как в математике:

```python
x = 5
print(0 < x < 10)      # True: x между 0 и 10
```

## 6.3 Устройство оператора if

```text
if условие:
    код, который выполняется, если условие истинно
    (сколько угодно строк)
код дальше (выполняется всегда)
```

Два главных момента:

1. После `if условие` **обязательно двоеточие** `:`.
2. Код, относящийся к `if`, **должен быть с отступом** (всегда 4 пробела). Строки с отступом образуют **блок**; возврат к прежнему отступу завершает блок.

```python
score = 95
if score >= 90:
    print("Отлично!")        # относится к if
    print("Так держать")     # тоже относится к if
print("Оценка записана")      # не относится к if, выполняется всегда
```

> [!IMPORTANT]
> В C, Java и JavaScript блоки обозначаются фигурными скобками `{ }`, а в Python блок **полностью определяется отступом**. Поэтому Python строг к отступам: у каждой строки блока должно быть одинаковое число пробелов в начале. Редактор программы курса сам ставит отступ после Enter, а <kbd>Tab</kbd> вставляет 4 пробела.

## 6.4 else: иначе

```python
age = int(input())
if age >= 18:
    print("взрослый")
else:
    print("несовершеннолетний")
```

После `else` тоже двоеточие; его блок выполняется, когда условие **ложно**. Из двух веток всегда выполняется **ровно одна**.

### Чётное или нечётное

```python
n = int(input())
if n % 2 == 0:
    print("чётное")
else:
    print("нечётное")
```

## 6.5 elif: несколько условий

Если вариантов больше двух, используйте `elif` (сокращение от else if):

```python
score = int(input())
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
elif score >= 60:
    print("D")
else:
    print("F")
```

Python проверяет условия **сверху вниз**, **выполняет первое истинное и пропускает все остальные**. При вводе `85`: `85 >= 90` ложно → `85 >= 80` истинно → выводится `B`, дальше ничего не проверяется.

> [!TIP]
> Раз выполняется только первая истинная ветка, `elif score >= 80` не нужно писать как `elif 80 <= score < 90`: если мы сюда дошли, `score >= 90` уже ложно. Но **порядок важен**: поставьте `score >= 60` первым — и за 95 баллов получится D!

## 6.6 Логические операторы: and, or, not

Объединяем несколько условий:

| Оператор | Значение | Пример |
|----------|----------|--------|
| `and` | и (оба истинны) | `age >= 18 and has_ticket` |
| `or` | или (хотя бы одно истинно) | `day == "суббота" or day == "воскресенье"` |
| `not` | не (отрицание) | `not is_raining` |

```python
age = 20
has_ticket = True
if age >= 18 and has_ticket:
    print("Проходите")

day = "воскресенье"
if day == "суббота" or day == "воскресенье":
    print("Хороших выходных!")

is_raining = False
if not is_raining:
    print("Пойдём гулять")
```

### Классика: високосный год

Год високосный, если делится на 4 **и** не делится на 100, **или** делится на 400:

```python
year = int(input())
if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:
    print("високосный")
else:
    print("обычный")
```

Проверьте 2024 (високосный), 1900 (обычный), 2000 (високосный). Скобки делают логику понятной.

> [!WARNING]
> Новички часто пишут `if day == "суббота" or "воскресенье":` — это **неправильно**! Это читается как `(day == "суббота") or ("воскресенье")`, а непустая строка всегда считается истинной, так что условие истинно всегда. Пишите обе части полностью: `day == "суббота" or day == "воскресенье"` или `day in ("суббота", "воскресенье")`.

## 6.7 Вложенные условия

Внутри `if` можно написать ещё один `if`; каждый уровень добавляет 4 пробела:

```python
age = int(input())
member = input()      # yes или no
if age < 12:
    print("Детский билет: бесплатно")
else:
    if member == "yes":
        print("Билет для участника клуба: 300 ₽")
    else:
        print("Обычный билет: 500 ₽")
```

Глубокую вложенность трудно читать. Часто её можно «выпрямить» через `elif` или `and`:

```python
age = int(input())
member = input()
if age < 12:
    print("Детский билет: бесплатно")
elif member == "yes":
    print("Билет для участника клуба: 300 ₽")
else:
    print("Обычный билет: 500 ₽")
```

## 6.8 Истинность: не только True и False

После `if` не обязательно сравнение — подходит любое значение. Python рассматривает его как `bool(значение)` (урок 2): `0`, `0.0`, `""`, `None` и пустые списки `[]` считаются ложными, всё остальное — истинным.

```python
name = input()
if name:                 # то же, что if name != ""
    print(f"Привет, {name}")
else:
    print("Вы ничего не ввели")
```

## 6.9 Условное выражение: if в одну строку

Простой выбор из двух помещается в строку:

```python
age = 20
status = "взрослый" if age >= 18 else "несовершеннолетний"
print(status)
```

Форма: `значение1 if условие else значение2`. Хорошо для простых случаев; для сложных используйте обычный `if`.

## 6.10 Оператор match

В Python 3.10 появился `match` — удобен, когда нужно делать разное для разных значений одной величины:

```python
command = input()
match command:
    case "start":
        print("Игра началась")
    case "pause" | "stop":          # | означает «или»
        print("Пауза")
    case "quit":
        print("Пока!")
    case _:                          # _ подходит под всё остальное
        print("Неизвестная команда")
```

`match` умеет гораздо больше (разбирать списки, словари и другие структуры — «структурное сопоставление с образцом»); мы ещё встретимся с ним. Для простых решений `if/elif` вполне хватает.

## 6.11 Частые ошибки

```python norun
if x = 5:
```

```text
SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?
```

Сравнивают через `==`. Python даже догадался, что вы имели в виду.

```python norun
if x > 5
    print("много")
```

```text
SyntaxError: expected ':'
```

Нет двоеточия.

```python norun
if x > 5:
print("много")
```

```text
IndentationError: expected an indented block after 'if' statement on line 1
```

Нет отступа.

```python norun
if x > 5:
    print("много")
     print("очень много")
```

```text
IndentationError: unexpected indent
```

Разные отступы в одном блоке (во второй строке лишний пробел).

## 6.12 Итоги

- Операторы сравнения `== != > < >= <=` дают `True`/`False`; `=` присваивает, `==` сравнивает.
- `if условие:` + **блок с отступом**; `else:` — для остального; `elif` — для нескольких вариантов: **сверху вниз выполняется только первая истинная ветка**.
- `and`, `or`, `not` объединяют условия; по обе стороны `or` пишите полные условия.
- Условием может быть любое значение: `0`, `""`, `None` и пустые контейнеры ложны.
- `значение1 if условие else значение2` — выбор в одну строку; `match/case` — ветвление по значению.

### Задание 5: Что выведет программа

```python
x = 15
if x > 10:
    print("A")
```
