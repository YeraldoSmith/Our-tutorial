## 7.1 Зачем нужны циклы?

Допустим, нужно вывести числа от 1 до 5:

```python
print(1)
print(2)
print(3)
print(4)
print(5)
```

А от 1 до 1000? Копировать 1000 строк нелепо. **Цикл** выполняет один и тот же код **много раз**. Неутомимо повторять — это то, что компьютер умеет лучше всего.

## 7.2 Цикл while: пока условие истинно

```python
i = 1
while i <= 5:
    print(i)
    i += 1
print("готово")
```

По шагам:

```text
i = 1 → 1 <= 5 истинно → печать 1, i становится 2
i = 2 → 2 <= 5 истинно → печать 2, i становится 3
  ...
i = 5 → 5 <= 5 истинно → печать 5, i становится 6
i = 6 → 6 <= 5 ложно   → выход из цикла, печать «готово»
```

`while` похож на `if`: `while условие:` и блок с отступом. Разница в том, что `if` выполняется один раз, а `while` **повторяется, пока условие не станет ложным**.

### Осторожно: бесконечный цикл

```python norun
i = 1
while i <= 5:
    print(i)
    # забыли i += 1
```

`i` всё время 1, условие всё время истинно, и программа печатает 1 **вечно** — это **бесконечный цикл**. В программе курса нажмите «■ Стоп», в терминале — <kbd>Ctrl</kbd>+<kbd>C</kbd>.

> [!TIP]
> Когда пишете `while`, задайте себе три вопроса: ① с какого значения начинается переменная цикла? ② при каком условии цикл продолжается? ③ **приближается ли** переменная к завершению на каждом шаге?

### while подходит, когда число повторений неизвестно

Например, спрашивать, пока ответ не будет верным:

```python input="abc\npython"
password = input()
while password != "python":
    print("Неверный пароль, попробуйте ещё раз")
    password = input()
print("Вход выполнен!")
```

## 7.3 Цикл for: по одному элементу

Цикл `for` **по очереди обрабатывает каждый элемент группы**:

```python
for ch in "абв":
    print(ch)
```

Будут выведены три строки: `а`, `б`, `в`. На каждом шаге переменная `ch` получает следующий символ.

### range(): последовательность чисел

`for` чаще всего используют с `range()`, чтобы «повторить n раз» или «пройти по числам»:

```python
for i in range(5):
    print(i)
```

Выведет `0 1 2 3 4` (по одному в строке). Внимание: **`range(5)` — это от 0 до 4, без 5**: «начало включается, конец нет», как в срезах.

Три формы `range`:

| Форма | Числа |
|-------|-------|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 6)` | 1, 2, 3, 4, 5 |
| `range(0, 10, 2)` | 0, 2, 4, 6, 8 (шаг 2) |
| `range(10, 0, -1)` | 10, 9, 8, …, 1 (обратный отсчёт) |

```python
for i in range(1, 6):
    print(f"Проход номер {i}")
```

> [!NOTE]
> `for i in range(1, 6)` делает ровно то же, что пример с `while` из 7.2, но короче и надёжнее (не забудешь `i += 1`). **Если число повторений известно, выбирайте `for`.**

## 7.4 Классические приёмы

### Приём 1: накопление суммы

Вычислим 1 + 2 + … + 100:

```python
total = 0                  # ① до цикла — переменная для результата, начинаем с 0
for i in range(1, 101):
    total += i             # ② на каждом шаге добавляем текущее число
print(total)               # ③ после цикла используем результат: 5050
```

### Приём 2: накопление произведения

Вычислим 5! = 1 × 2 × 3 × 4 × 5:

```python
result = 1                 # для умножения начинаем с 1, а не с 0!
for i in range(1, 6):
    result *= i
print(result)              # 120
```

### Приём 3: подсчёт

Сколько букв `o` в предложении?

```python
text = "hello world, good morning"
count = 0
for ch in text:
    if ch == "o":
        count += 1
print(count)               # 5
```

### Приём 4: поиск максимума

Прочитаем 5 чисел и найдём наибольшее:

```python
biggest = int(input())      # первое число считаем текущим максимумом
for _ in range(4):          # читаем оставшиеся 4
    n = int(input())
    if n > biggest:
        biggest = n
print(biggest)
```

Если переменная цикла не нужна, её по соглашению называют `_`.

### Приём 5: чтение n чисел

Во многих задачах сначала дают количество n, затем n чисел:

```python
n = int(input())
total = 0
for _ in range(n):
    total += int(input())
print(total)
```

## 7.5 break и continue

- **`break`** — немедленно **выйти из всего цикла**.
- **`continue`** — пропустить остаток текущего шага и **сразу перейти к следующему**.

```python
for i in range(1, 11):
    if i == 6:
        break           # остановиться на 6
    print(i, end=" ")
print()
# вывод: 1 2 3 4 5

for i in range(1, 11):
    if i % 2 == 0:
        continue        # пропустить чётные
    print(i, end=" ")
print()
# вывод: 1 3 5 7 9
```

### while True + break: «делай, а когда… — выходи»

```python input="hello\nquit"
while True:
    cmd = input()
    if cmd == "quit":
        break
    print(f"Вы ввели: {cmd}")
print("Программа завершена")
```

`while True` означает «повторять всегда», а `break` внутри завершает цикл. Это самая распространённая форма интерактивной программы.

### Найти первое подходящее число

```python
n = 100
while True:
    n += 1
    if n % 7 == 0:
        break
print("Первое кратное 7 больше 100:", n)    # 105
```

## 7.6 Вложенные циклы

Цикл внутри цикла: на каждый шаг внешнего цикла внутренний выполняется полностью.

```python
for row in range(1, 4):
    for col in range(1, 5):
        print(f"({row},{col})", end=" ")
    print()          # перевод строки после каждой строки таблицы
```

```text
(1,1) (1,2) (1,3) (1,4)
(2,1) (2,2) (2,3) (2,4)
(3,1) (3,2) (3,3) (3,4)
```

### Таблица умножения

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i * j}", end="\t")
    print()
```

Диапазон внутреннего цикла `range(1, i + 1)` зависит от внешнего `i`: в первой строке одна запись, во второй две… поэтому получается треугольник. `\t` — табуляция для выравнивания.

### Рисуем фигуры

```python
n = 4
for i in range(1, n + 1):
    print("*" * i)
```

```text
*
**
***
****
```

Умножение строки `"*" * i` рисует i звёздочек за раз.

## 7.7 for…else (полезно знать)

У цикла может быть `else`, который выполняется, **если цикл завершился сам (не через `break`)**. Удобно для поиска:

```python
n = 29
for d in range(2, n):
    if n % d == 0:
        print(n, "не простое, делится на", d)
        break
else:
    print(n, "простое")
```

## 7.8 Частые ошибки

### Ошибка на единицу

Хотели от 1 до 10, а написали:

```python
for i in range(1, 10):
    print(i)      # только до 9!
```

`range` не включает конец; нужно `range(1, 11)`. Ошибка «на один больше или меньше» так распространена во всех языках, что у неё есть название — **off-by-one**. Проверяя цикл, **внимательно смотрите на первый и последний шаг**.

### Накопитель не на своём месте

```python
for i in range(1, 4):
    total = 0          # ❌ обнуляется на каждом шаге
    total += i
print(total)           # 3, а не 6
```

Инициализируйте **до** цикла.

### Бесконечный цикл

Переменная из условия `while` внутри цикла не меняется или меняется не в ту сторону (`i -= 1` вместо `i += 1`). Если программа «зависла», подозревайте это в первую очередь. При проверке ответа программа курса сообщит «Превышено время».

## 7.9 Итоги

- `while условие:` повторяет, пока условие истинно; убедитесь, что оно когда-нибудь станет ложным.
- `for переменная in группа:` обрабатывает элементы по одному; `range(начало, конец, шаг)` не включает конец.
- Число повторений известно → `for`; неизвестно (пока что-то не случится) → `while`.
- Приёмы: сумма (с 0), произведение (с 1), подсчёт, максимум, чтение n чисел.
- `break` выходит из цикла, `continue` переходит к следующему шагу; `while True` + `break` — обычный интерактивный цикл.
- Вложенные циклы: один шаг внешнего = полный проход внутреннего; следите за ошибкой на единицу.
