>
> ⏱ **Время**: 30 минут　|　📋 **Что нужно знать**: урок 1

Многие застревают не потому, что программирование сложное, а потому, что им никто не объяснил некоторые бытовые вещи о компьютере. Этот урок закладывает такой фундамент.

## 2.1 Файлы и папки

Всё, что хранится в компьютере, — фотографии, документы, музыка, программы — лежит в **файлах**. Файлы находятся в **папках** (их ещё называют **каталогами**, directory), а папки могут содержать другие папки, образуя дерево:

```text
C:\Users\sasha\                 ← ваша папка пользователя (Windows)
├── Desktop\                     ← Рабочий стол
├── Documents\                   ← Документы
│   ├── Резюме.docx
│   └── code\                    ← заведём папку для кода
│       ├── hello.py
│       └── game\
│           └── main.py
└── Downloads\                   ← Загрузки
```

> [!TIP]
> Создайте прямо сейчас в «Документах» папку `code` и храните там все учебные программы. **В именах папок используйте только латинские буквы, цифры и дефис** — без пробелов и кириллицы. Некоторые инструменты программиста ломаются на путях с пробелами и не-латинскими буквами.

## 2.2 Расширение: «ярлык типа» файла

Часть имени после последней точки называется **расширением**. Оно сообщает компьютеру, что это за файл:

| Расширение | Тип |
|------------|-----|
| `.txt` | простой текст |
| `.docx` | документ Word |
| `.jpg` `.png` | изображения |
| `.exe` | программа Windows |
| `.py` | исходный код на Python |
| `.c` `.h` | исходный код на C |
| `.cpp` | исходный код на C++ |
| `.java` | исходный код на Java |
| `.rs` | исходный код на Rust |
| `.go` | исходный код на Go |
| `.js` `.ts` | исходный код на JavaScript / TypeScript |
| `.md` | документ Markdown (уроки этого курса — .md-файлы) |

### Обязательно включите показ расширений

Windows и macOS по умолчанию **скрывают** расширения. Отсюда классическая проблема: вы думаете, что файл называется `hello.py`, а на самом деле он `hello.py.txt` и не запускается.

- **Windows 11**: Проводник → «Просмотр» вверху → «Показать» → отметьте «Расширения имён файлов».
- **Windows 10**: Проводник → «Вид» → отметьте «Расширения имён файлов».
- **macOS**: Finder → меню «Finder» → «Настройки» → «Дополнения» → отметьте «Показывать все расширения имён файлов».
- **Linux**: большинство файловых менеджеров уже показывают их.

## 2.3 Код — это простой текст

Файлы с кодом — **простые текстовые файлы**: только символы, без шрифтов, цвета и жирности. Поэтому:

- ✅ Пишите код в **редакторе кода**: программа этого курса, VS Code, Блокнот (Windows), TextEdit (macOS, в режиме «простой текст»).
- ❌ **Не пишите** код в Word, Pages или Google Документах — они добавляют скрытое форматирование и заменяют прямые кавычки `"` на «ёлочки» `«»` или `“”`, и код ломается.

> [!NOTE]
> При сохранении текстового файла выбирается «кодировка» — способ превращать символы в нули и единицы. **Всегда выбирайте UTF-8**: она умеет записывать любые алфавиты мира и используется по умолчанию всеми современными инструментами. Как она устроена — в уроке 6.

## 2.4 Путь: адрес файла

**Путь** — это полный адрес файла: от самой внешней папки вниз до самого файла:

- Windows: `C:\Users\sasha\Documents\code\hello.py` (разделитель — **обратная косая черта** `\`, в начале буква диска `C:`)
- macOS: `/Users/sasha/Documents/code/hello.py` (разделитель — **косая черта** `/`)
- Linux: `/home/sasha/code/hello.py`

Пути бывают двух видов:

- **Абсолютный** — полный адрес с самого верха, как в примерах выше.
- **Относительный** — адрес относительно папки, в которой вы «находитесь» сейчас. Если вы в `code`, то `game/main.py` означает `code/game/main.py`; `..` — «папка уровнем выше».

Пути понадобятся в следующем уроке о терминале.

## 2.5 «Неправильные» кавычки и символы ⚠️

Языки программирования понимают только обычную **ASCII**-пунктуацию: `( ) , ; : " ' . ! ?`. Похожие на неё символы доставляют массу проблем:

- **Типографские кавычки** `« »`, `“ ”`, `„ “` — их автоматически подставляют Word, мессенджеры и многие сайты.
- **Полноширинные символы** `（ ），；：` — их вводят китайские и японские раскладки; иногда они попадаются в скопированном коде.
- **Тире и длинные дефисы** `—`, `–` вместо обычного минуса `-`.

Сравните (присмотритесь к кавычкам и скобкам):

```text
✅ print("Привет")        ← обычные скобки и кавычки
❌ print(«Привет»)        ← «ёлочки»
❌ print(“Привет”)        ← «лапки»
❌ print（"Привет"）      ← полноширинные скобки
```

Как этого избежать:

1. Пишите код в редакторе кода, а не в текстовом процессоре.
2. Копируя код с сайтов и из чатов, проверяйте кавычки.
3. Скобки, кавычки и прочие символы кода набирайте в **английской раскладке** (обычно переключение — <kbd>Alt</kbd>+<kbd>Shift</kbd>, <kbd>Win</kbd>+<kbd>Пробел</kbd> или <kbd>Ctrl</kbd>+<kbd>Пробел</kbd> на Mac).
4. Если появилась ошибка, прочитайте объяснение программы курса — она распознаёт такие символы.

> [!IMPORTANT]
> Русский текст **допустим** в двух местах: внутри кавычек (`"Привет"`) и в комментариях (`# комментарий`). Всё остальное — ключевые слова, имена, символы — пишется латиницей и ASCII-символами.

## 2.6 Символы клавиатуры, нужные программисту

В программировании много символов, которые редко нужны в обычной жизни. Их названия пригодятся и при чтении документации:

| Символ | Название | Английское название | Как набрать (англ. раскладка) |
|--------|----------|---------------------|-------------------------------|
| `( )` | круглые скобки | parentheses | <kbd>Shift</kbd> + <kbd>9</kbd> / <kbd>0</kbd> |
| `[ ]` | квадратные скобки | square brackets | клавиши <kbd>Х</kbd> <kbd>Ъ</kbd> |
| `{ }` | фигурные скобки | curly braces | <kbd>Shift</kbd> + <kbd>Х</kbd> / <kbd>Ъ</kbd> |
| `< >` | угловые скобки | angle brackets | <kbd>Shift</kbd> + <kbd>Б</kbd> / <kbd>Ю</kbd> |
| `"` | двойная кавычка | double quote | <kbd>Shift</kbd> + <kbd>Э</kbd> |
| `'` | одинарная кавычка / апостроф | single quote | <kbd>Э</kbd> |
| `` ` `` | обратная кавычка | backtick | <kbd>Ё</kbd> |
| `;` | точка с запятой | semicolon | <kbd>Ж</kbd> |
| `:` | двоеточие | colon | <kbd>Shift</kbd> + <kbd>Ж</kbd> |
| `=` | знак равенства | equals sign | <kbd>=</kbd> |
| `_` | подчёркивание | underscore | <kbd>Shift</kbd> + <kbd>-</kbd> |
| `#` | решётка | hash | <kbd>Shift</kbd> + <kbd>3</kbd> |
| `\` | обратная косая черта | backslash | <kbd>\</kbd> |
| `/` | косая черта | slash | <kbd>.</kbd> справа от <kbd>Ю</kbd> |
| `\|` | вертикальная черта | pipe | <kbd>Shift</kbd> + <kbd>\</kbd> |
| `&` | амперсанд | ampersand | <kbd>Shift</kbd> + <kbd>7</kbd> |
| `*` | звёздочка | asterisk | <kbd>Shift</kbd> + <kbd>8</kbd> |
| `%` | процент | percent | <kbd>Shift</kbd> + <kbd>5</kbd> |
| `~` | тильда | tilde | <kbd>Shift</kbd> + <kbd>Ё</kbd> |
| `^` | «крышка» | caret | <kbd>Shift</kbd> + <kbd>6</kbd> |

## 2.7 Сочетания клавиш, которые нужно знать

С сочетаниями клавиш работа идёт гораздо быстрее. В Windows/Linux — <kbd>Ctrl</kbd>, в macOS — <kbd>⌘ Command</kbd>:

| Действие | Windows / Linux | macOS |
|----------|-----------------|-------|
| Копировать | <kbd>Ctrl</kbd>+<kbd>C</kbd> | <kbd>⌘</kbd>+<kbd>C</kbd> |
| Вставить | <kbd>Ctrl</kbd>+<kbd>V</kbd> | <kbd>⌘</kbd>+<kbd>V</kbd> |
| Вырезать | <kbd>Ctrl</kbd>+<kbd>X</kbd> | <kbd>⌘</kbd>+<kbd>X</kbd> |
| Отменить | <kbd>Ctrl</kbd>+<kbd>Z</kbd> | <kbd>⌘</kbd>+<kbd>Z</kbd> |
| Повторить | <kbd>Ctrl</kbd>+<kbd>Y</kbd> или <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> |
| Выделить всё | <kbd>Ctrl</kbd>+<kbd>A</kbd> | <kbd>⌘</kbd>+<kbd>A</kbd> |
| Сохранить | <kbd>Ctrl</kbd>+<kbd>S</kbd> | <kbd>⌘</kbd>+<kbd>S</kbd> |
| Найти | <kbd>Ctrl</kbd>+<kbd>F</kbd> | <kbd>⌘</kbd>+<kbd>F</kbd> |
| Закомментировать | <kbd>Ctrl</kbd>+<kbd>/</kbd> | <kbd>⌘</kbd>+<kbd>/</kbd> |
| Увеличить / уменьшить отступ | <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | так же |

В программе курса есть ещё: <kbd>F5</kbd> — запуск, <kbd>Ctrl</kbd>+<kbd>Enter</kbd> — проверка ответа, <kbd>Alt</kbd>+<kbd>←</kbd>/<kbd>→</kbd> — предыдущий/следующий урок.

## 2.8 Попробуйте

Эта программа печатает часто используемые символы. Запустите её, а потом **наберите заново сами** (без копирования), чтобы потренироваться:

```python
print("круглые ( )  квадратные [ ]  фигурные { }")
print("кавычки \" '  точка с запятой ;  двоеточие :  равно =")
print("Путь: C:\\Users\\code\\hello.py")
```

Посмотрите на третью строку: чтобы поместить в строку одну обратную косую черту `\`, пишут две — `\\` (escape-последовательности из урока 1).

## 2.9 Итоги

- Данные хранятся в **файлах**, файлы — в **папках**, папки образуют дерево.
- **Расширение** — тип файла; включите показ расширений, чтобы не попасться на `hello.py.txt`.
- Код — **простой текст**: пишите в редакторе кода, не в Word; кодировка — **UTF-8**.
- **Путь** — адрес файла, абсолютный или относительный; в Windows `\`, в macOS/Linux `/`.
- В коде нужны обычные ASCII-символы — остерегайтесь «ёлочек», «лапок» и полноширинных знаков.
- Выучите названия символов и сочетания клавиш — набирать код станет гораздо проще.
