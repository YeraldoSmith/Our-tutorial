# 3. Терминал (командная строка)

> 🎯 **Цели урока**: открыть терминал; понять «приглашение»; освоить `pwd`, `ls`, `cd`, `mkdir` и другие команды; запустить программу из терминала; понять, что такое PATH и ошибка «command not found».
>
> ⏱ **Время**: 40 минут　|　📋 **Что нужно знать**: урок 2 (файлы, папки, пути)

## 3.1 Что такое терминал?

Обычно мы управляем компьютером мышью, щёлкая по значкам, — это **графический интерфейс** (GUI). Программисты часто используют и другой способ: **вводят команды текстом** в окне, а компьютер выполняет их и выводит результат тоже текстом. Окно называется **терминалом**, программа внутри, которая понимает команды, — **оболочкой** (shell), а такой способ работы — **командной строкой**.

Зачем это учить?

- Многие инструменты разработчика существуют **только** в виде программ для командной строки (компиляторы, Git, менеджеры пакетов…).
- Инструкции по установке и документация почти всегда дают команды, которые нужно ввести.
- Когда привыкнете, многие действия будут гораздо быстрее, чем мышью, и их можно автоматизировать скриптами.

> [!NOTE]
> Программа курса сама запускает ваш код, так что **можно двигаться дальше, даже если терминал пока непривычен**. Но рано или поздно он понадобится, поэтому стоит освоиться уже сейчас.

## 3.2 Как открыть терминал

- **Windows 11**: найдите «Терминал» в меню «Пуск». По умолчанию открывается **PowerShell**. В Windows 10 ищите «PowerShell».
- **macOS**: нажмите <kbd>⌘</kbd> + <kbd>Пробел</kbd> (Spotlight), наберите «Терминал» или Terminal, нажмите Enter. Оболочка по умолчанию — **zsh**.
- **Linux**: в большинстве окружений — <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>T</kbd>. Оболочка обычно **bash**.

Вы увидите строку вроде:

```console
PS C:\Users\sasha>                 ← Windows PowerShell
sasha@MacBook ~ %                  ← macOS zsh
sasha@ubuntu:~$                    ← Linux bash
```

Это **приглашение** (prompt): «я готов, вводите команду». Обычно в нём видна **текущая папка** (`~` — ваша домашняя папка).

> [!IMPORTANT]
> В руководствах команды часто начинаются с `$` или `>`. Это приглашение — **его вводить не нужно**. Видите `$ python3 --version` — набирайте только `python3 --version`.

## 3.3 Первые команды

Терминал всегда «стоит» в какой-то папке — это **текущий (рабочий) каталог**. Следующие команды позволяют осмотреться и перемещаться:

| Назначение | macOS / Linux | Windows PowerShell |
|------------|---------------|--------------------|
| показать, где вы находитесь | `pwd` | `pwd` (или `Get-Location`) |
| показать содержимое папки | `ls` | `ls` (или `dir`) |
| войти в папку | `cd имя` | `cd имя` |
| подняться на уровень выше | `cd ..` | `cd ..` |
| вернуться в домашнюю папку | `cd ~` или `cd` | `cd ~` |
| создать папку | `mkdir имя` | `mkdir имя` |
| очистить экран | `clear` | `cls` (или `clear`) |
| показать содержимое файла | `cat файл` | `cat файл` (или `type`) |
| вывести текст | `echo привет` | `echo привет` |

Хорошая новость: в PowerShell у многих команд есть псевдонимы с такими же именами, как в macOS/Linux, поэтому почти всё из таблицы работает во всех трёх системах.

### Повторите за мной

Вводите по одной строке, нажимая Enter после каждой, и смотрите на результат:

```console
pwd
ls
mkdir code
cd code
pwd
cd ..
pwd
```

Вы увидите путь домашней папки, список её содержимого, создание папки `code`, путь с `code` на конце после входа в неё и возврат на уровень выше.

> [!TIP]
> Если `mkdir code` сообщает, что папка уже есть, значит, вы создали её в уроке 2, — просто выполните `cd code`.

## 3.4 Два приёма, экономящих кучу времени

1. **Автодополнение по <kbd>Tab</kbd>**: наберите первые буквы имени папки и нажмите <kbd>Tab</kbd> — терминал допишет остальное. `cd Doc` + <kbd>Tab</kbd> превращается в `cd Documents`. Быстрее и без опечаток.
2. **История по <kbd>↑</kbd>**: стрелка вверх возвращает прежние команды — поправьте и нажмите Enter вместо того, чтобы набирать заново.

И одна **спасительная** комбинация: если программа зависла или не останавливается (например, бесконечный цикл), нажмите <kbd>Ctrl</kbd> + <kbd>C</kbd>, чтобы прервать её. В терминале <kbd>Ctrl</kbd> + <kbd>C</kbd> — **не копирование**! (Копировать там обычно <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd>, в macOS — <kbd>⌘</kbd> + <kbd>C</kbd>.)

## 3.5 Запуск программ из терминала

Чтобы запустить программу, наберите её имя. Проверим, установлен ли Python:

```console
python3 --version
```

В Windows обычно:

```console
python --version
```

или `py --version`. Если видите что-то вроде `Python 3.13.x`, Python установлен. (Если нет — в следующем уроке покажем, как установить.)

### Запустим файл на Python

1. В редакторе (например, «Файл → Сохранить как» в программе курса) сохраните этот код как `hello.py` в папке `code`:

   ```python
   print("Я запустил эту программу из терминала!")
   ```

2. В терминале перейдите в эту папку и запустите файл:

   ```console
   cd ~/Documents/code
   python3 hello.py
   ```

   В Windows:

   ```console
   cd ~\Documents\code
   python hello.py
   ```

3. Терминал выведет: `Я запустил эту программу из терминала!`

Общий вид команды: **программа аргумент1 аргумент2 …**. `python3 hello.py` означает «запусти программу python3 и передай ей аргумент hello.py». Аргументы, начинающиеся с дефисов, как `--version`, называются **опциями** и меняют поведение программы.

## 3.6 PATH: где терминал ищет программы?

Вы набираете `python3` — откуда терминал знает, где установлен Python? Из **переменной окружения** **PATH**: это список папок, в которых терминал по порядку ищет программу с именем `python3`.

```text
PATH = C:\Windows\System32 ; C:\Python313 ; C:\Users\sasha\.cargo\bin ; ...
             │                    │                     │
        python здесь? нет    нашёл! запускаю      (дальше не ищет)
```

Если ни в одной папке её нет, появится ошибка:

```console
python3: command not found                                    ← macOS / Linux
python3 : Имя "python3" не распознано как имя командлета, функции, файла сценария или выполняемой программы.   ← Windows
```

Обе значат «**не могу найти такую команду**». Обычные причины:

1. Программа **не установлена**.
2. Установлена, но **не добавлена в PATH** (при установке Python в Windows отметьте «Add python.exe to PATH»).
3. Только что установили, но **не перезапустили терминал** — PATH читается только при запуске терминала. Закройте его и откройте новый.
4. **Опечатка**, или в этой системе имя другое (в Windows `python` вместо `python3`).

Посмотреть, что в PATH:

```console
echo $PATH          # macOS / Linux
echo $env:PATH      # Windows PowerShell
```

## 3.7 Осторожно: опасные команды

У команд в терминале **нет корзины**. Будьте особенно осторожны с этими командами и не запускайте их, пока не разберётесь:

- `rm` (удалить файлы), `rm -r` (удалить папку со всем содержимым), в Windows `del` и `Remove-Item`
- всё, что начинается с `sudo` (выполнение с правами администратора)
- длинные команды из интернета, которых вы не понимаете

> [!WARNING]
> Никогда не запускайте присланную кем-то команду, которую не понимаете, особенно с `rm -rf`, `format` или `curl ... | sh`. Устанавливая программы, берите команды только с официальных сайтов.

## 3.8 Итоги

- **Терминал** — окно для ввода команд, **оболочка** их понимает; приглашение означает «жду ввода», символ `$` из руководств вводить не нужно.
- Основное: `pwd` — где я, `ls` — что здесь, `cd` — войти, `cd ..` — выше, `mkdir` — новая папка, `clear` — очистить экран.
- <kbd>Tab</kbd> дополняет, <kbd>↑</kbd> возвращает историю, <kbd>Ctrl</kbd>+<kbd>C</kbd> останавливает программу.
- Программы запускаются как `программа аргументы`, например `python3 hello.py`.
- «Command not found»: не установлено, нет в PATH, терминал не перезапущен или опечатка.
- У команд удаления нет корзины; не запускайте то, чего не понимаете.

### Задание 1: На уровень выше

Текущий каталог — `/home/sasha/code/game`, нужно попасть в `/home/sasha/code`. Какая команда?

- `cd game`
- `cd ..`
- `mkdir ..`
- `ls ..`

<details>
<summary>Ответ и разбор</summary>

`cd ..` — `..` означает папку уровнем выше. `ls ..` только показывает её содержимое и никуда не перемещает.
</details>

### Задание 2: Не останавливается

Программа в терминале застряла в бесконечном цикле. Какие клавиши её остановят?

- <kbd>Ctrl</kbd> + <kbd>S</kbd>
- <kbd>Ctrl</kbd> + <kbd>C</kbd>
- <kbd>Tab</kbd>
- <kbd>↑</kbd>

<details>
<summary>Ответ и разбор</summary>

<kbd>Ctrl</kbd> + <kbd>C</kbd>. В терминале это «прервать», а не «копировать».
</details>

### Задание 3: Команда не найдена

Вы только что установили Python и набрали `python --version` в терминале, который **был открыт раньше**, но команда не найдена. Что попробовать в первую очередь?

- Переустановить операционную систему
- Закрыть терминал и открыть новый
- Набрать `PYTHON --VERSION`
- Удалить папку Python

<details>
<summary>Ответ и разбор</summary>

Терминал читает PATH только при запуске. После того как установщик изменил PATH, нужен новый терминал. Если не помогло — проверьте, была ли отмечена опция «добавить в PATH».
</details>
