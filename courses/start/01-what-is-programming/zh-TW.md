# 1. 什麼是程式設計？

> 🎯 **本課目標**：明白「程式」「程式語言」「編譯」「解釋」這幾個詞是什麼意思；認識學習程式的介面；親手執行第一段程式碼。
>
> ⏱ **預計用時**：20 分鐘　｜　📋 **前置知識**：無

## 1.1 程式就是一份「菜譜」

想象你要教一個**完全聽話、但一點常識都沒有**的機器人做西紅柿炒蛋。你不能只說「炒個菜」，必須一步一步寫清楚：

```text
1. 開啟冰箱，拿出 2 個雞蛋和 1 個西紅柿
2. 把雞蛋打進碗裡，攪拌 30 下
3. 西紅柿切成 8 塊
4. 開火，鍋裡倒 1 勺油，等 1 分鐘
5. 倒入雞蛋，翻炒到凝固，盛出
6. 倒入西紅柿，翻炒 2 分鐘
7. 倒回雞蛋，加半勺鹽，翻炒 30 秒
8. 關火
```

這份清單就是一個**程式**（program）：一組**按順序執行的、精確的指令**。電腦就是那個機器人——它非常快（每秒能執行幾十億條指令），從不疲倦，但它**不會猜你的意思**。你寫什麼，它就做什麼；你寫錯了，它也照做（或者乾脆停下來報錯）。

**程式設計**（programming），就是寫這份指令清單的過程。

> [!NOTE]
> 你每天用的東西都是程式：微信、瀏覽器、遊戲、手機的計算器、地鐵的閘機、汽車裡的控制系統……它們背後都是程式設計師寫的一行行程式碼。

## 1.2 為什麼需要「程式語言」？

電腦真正能直接理解的只有**機器碼**——一串串 0 和 1，例如：

```text
10111000 00000001 00000000 00000000 00000000
```

人很難讀寫這種東西。於是人們發明了**程式語言**：一種介於人類語言和機器碼之間的、規則嚴格的「中間語言」。比如用 Python 讓電腦顯示一句話：

```python
print("你好！")
```

是不是好懂多了？程式語言寫成的文字叫**原始碼**（source code），簡稱**程式碼**。

### 為什麼有這麼多種程式語言？

就像有螺絲刀、錘子、扳手一樣，不同的語言擅長不同的事：

| 語言 | 特點 | 常見用途 |
|------|------|----------|
| **Python** | 簡單好讀，庫多 | 入門、資料分析、人工智慧、自動化指令碼 |
| **JavaScript / TypeScript** | 瀏覽器裡唯一原生支援的語言 | 網頁、網站前端、也能寫後端 |
| **Java** | 穩定、生態成熟 | 企業後臺系統、安卓應用 |
| **C** | 接近硬體，速度快 | 作業系統、嵌入式裝置、微控制器 |
| **C++** | 又快又能組織大程式 | 遊戲引擎、瀏覽器、圖形軟體 |
| **Rust** | 快，並且編譯器幫你防止記憶體錯誤 | 系統軟體、命令列工具、高效能服務 |
| **Go** | 簡潔，擅長併發 | 雲服務、網路伺服器、運維工具（Docker、Kubernetes） |
| **彙編** | 幾乎一條指令對應一條機器碼 | 理解 CPU、效能最佳化、安全研究 |

> [!TIP]
> 學會第一門語言最難。之後再學別的語言，你會發現大部分概念（變數、條件、迴圈、函式）都是相通的，只是寫法不同。所以**第一門語言選簡單的**——本教程推薦 Python。

## 1.3 程式碼是怎麼變成電腦能執行的東西的？

原始碼要先「翻譯」成機器能執行的指令。有兩種主要的翻譯方式：

**編譯**（compile）——像**翻譯一整本書**：

```text
原始碼 main.c ──[編譯器]──► 可執行檔案 main.exe ──► 執行
                (一次性全部翻譯)        (以後可以直接執行，很快)
```

C、C++、Rust、Go 屬於這一類。翻譯這一步由**編譯器**（compiler）完成。如果程式碼有語法錯誤，編譯器會拒絕翻譯，並告訴你哪裡錯了。

**解釋**（interpret）——像**同聲傳譯**：

```text
原始碼 main.py ──[直譯器：讀一行、執行一行]──► 結果
```

Python、JavaScript 屬於這一類。**直譯器**（interpreter）邊讀邊執行。好處是寫完馬上能執行，方便試驗。

Java 介於兩者之間：先編譯成一種中間格式（位元組碼），再由 Java 虛擬機器執行。

> [!NOTE]
> 不用死記這些分類。你只需要知道：**寫好的程式碼要經過編譯器或直譯器處理才能執行**；當它們發現問題時，會給出**錯誤資訊**。學會讀錯誤資訊，是程式設計最重要的技能之一（第 5 課專門講）。

## 1.4 認識學習程式

本教程配套的學習程式分成三欄：

```text
┌──────────────┬──────────────────────────┬─────────────────────────────┐
│ ① 課程目錄    │ ② 課文 / 練習              │ ③ 程式碼編輯器   [▶ 執行]      │
│              │                          │                             │
│ 🚀 程式設計起步   │  你現在讀的就是這裡        │  在這裡寫程式碼                 │
│   1. 什麼是…  │                          │                             │
│ 🐍 Python    │  程式碼框上方有              ├─────────────────────────────┤
│ ...          │  「▶ 放進編輯器執行」       │ ④ 執行結果                   │
│              │                          │   程式的輸出、錯誤資訊、解釋    │
│ 已完成 0/115  │ [◀ 上一課] [下一課 ▶]      │ ⑤ 輸入框：程式要你輸入時用     │
└──────────────┴──────────────────────────┴─────────────────────────────┘
```

1. **課程目錄**：點課程名展開，點課名開啟。學完的課後面會出現 ✓。
2. **課文 / 練習**：上方有兩個標籤頁。讀完課文，到「✍️ 練習」裡做題。
3. **程式碼編輯器**：在這裡寫程式碼。左上角可以選程式語言。
4. **執行結果**：點「▶ 執行」（或按 <kbd>F5</kbd>）後，程式的輸出顯示在這裡。出錯時，下面會有「💬 這是什麼意思？」的中文解釋。
5. **輸入框**：有的程式會等你輸入內容，在這裡輸入並按回車。

其他常用功能：

- 選單「檢視」可以**放大文字**（<kbd>Ctrl</kbd> + <kbd>+</kbd>）、切換**深色模式**、切換**介面語言**。
- 選單「工具 → 檢查開發工具」：看看電腦上裝了哪些程式設計工具，沒裝的會告訴你怎麼裝。
- 你的學習進度和寫過的程式碼會**自動儲存**。

## 1.5 動手：執行你的第一段程式碼

點下面程式碼框上方的「▶ 放進編輯器執行」，程式碼會出現在右邊的編輯器裡，然後點「▶ 執行」：

```python
print("你好，我開始學程式設計了！")
print("1 + 1 =", 1 + 1)
print("一年有", 365 * 24 * 60, "分鐘")
```

你應該看到：

```text
你好，我開始學程式設計了！
1 + 1 = 2
一年有 525600 分鐘
```

現在試著**改一改**：把「我開始學程式設計了」改成你自己的話，把 `365` 改成 `366`（閏年），再執行一次。

> [!TIP]
> 程式設計最好的學習方法就是**改程式碼、執行、看結果**。不要怕弄壞——改壞了點「恢復初始程式碼」或者重新放一次例子就好。電腦不會因為你寫錯程式碼而壞掉。

### 故意犯個錯

把第一行的英文右括號 `)` 改成中文的 `）`，再執行：

```python norun
print("你好，我開始學程式設計了！"）
```

你會看到紅色的錯誤資訊，以及下面的中文解釋。這就是程式設計的日常：**寫 → 執行 → 看錯誤 → 修改 → 再執行**。

## 1.6 程式設計需要什麼能力？

很多人擔心自己「數學不好」「英語不好」學不會程式設計。其實：

- **數學**：入門階段只需要小學的加減乘除。做遊戲、人工智慧時才需要更多數學，到時候再學。
- **英語**：程式語言的關鍵字只有幾十個英文單詞（`print`、`if`、`for`、`while`……），用多了自然就記住了。錯誤資訊看不懂？學習程式會給你解釋，第 5 課還有常用詞表。
- **最重要的**是：耐心、細心（一個符號都不能錯）、把大問題拆成小步驟的習慣——這些都可以在練習中培養。

## 1.7 小結

- **程式**是一組精確的、按順序執行的指令；**程式設計**就是寫這些指令。
- 電腦只懂機器碼；**程式語言**讓人能用接近人類語言的方式寫程式，寫出來的叫**原始碼**。
- 原始碼由**編譯器**（整體翻譯）或**直譯器**（邊讀邊執行）處理後才能執行。
- 學習程式：左邊選課，中間讀課文做練習，右邊寫程式碼點「▶ 執行」。
- 學程式設計的訣竅：多改、多執行、認真看錯誤資訊。

下面哪一句話最準確地描述了「程式」？

- 一臺電腦的硬體
- 一組按順序執行的、精確的指令

### 練習 2：編譯還是解釋？

「先把整個原始碼翻譯成可執行檔案，以後直接執行這個檔案」，這種方式叫什麼？

- 解釋
- 編譯
- 下載
- 複製

<details>
<summary>答案與解析</summary>

編譯。C、C++、Rust、Go 都是先編譯再執行的語言；Python 和 JavaScript 通常是解釋執行的。
</details>

### 練習 3：第一段程式碼

編寫程式，輸出下面兩行：

```text
Hello!
1 + 2 = 3
```

第二行的 `3` 要讓電腦**計算**出來，不要直接寫在引號裡。

<details>
<summary>提示</summary>

第一行：`print("Hello!")`。第二行：`print("1 + 2 =", 1 + 2)` ——逗號會自動在兩部分之間加一個空格。
</details>

<!-- exercise: predict-calc -->
### 練習 4：讀程式碼，寫輸出

下面的程式會輸出什麼？先自己想，再填寫答案。

```python
print(2 * 3)
print("2 * 3")
```

<details>
<summary>答案與解析</summary>

第一行沒有引號，電腦會計算 `2 * 3`，輸出 `6`；第二行有引號，是一段文字，原樣輸出 `2 * 3`。
</details>
