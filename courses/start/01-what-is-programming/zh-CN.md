# 1. 什么是编程？

> 🎯 **本课目标**：明白「程序」「编程语言」「编译」「解释」这几个词是什么意思；认识学习程序的界面；亲手运行第一段代码。
>
> ⏱ **预计用时**：20 分钟　｜　📋 **前置知识**：无

## 1.1 程序就是一份「菜谱」

想象你要教一个**完全听话、但一点常识都没有**的机器人做西红柿炒蛋。你不能只说「炒个菜」，必须一步一步写清楚：

```text
1. 打开冰箱，拿出 2 个鸡蛋和 1 个西红柿
2. 把鸡蛋打进碗里，搅拌 30 下
3. 西红柿切成 8 块
4. 开火，锅里倒 1 勺油，等 1 分钟
5. 倒入鸡蛋，翻炒到凝固，盛出
6. 倒入西红柿，翻炒 2 分钟
7. 倒回鸡蛋，加半勺盐，翻炒 30 秒
8. 关火
```

这份清单就是一个**程序**（program）：一组**按顺序执行的、精确的指令**。电脑就是那个机器人——它非常快（每秒能执行几十亿条指令），从不疲倦，但它**不会猜你的意思**。你写什么，它就做什么；你写错了，它也照做（或者干脆停下来报错）。

**编程**（programming），就是写这份指令清单的过程。

> [!NOTE]
> 你每天用的东西都是程序：微信、浏览器、游戏、手机的计算器、地铁的闸机、汽车里的控制系统……它们背后都是程序员写的一行行代码。

## 1.2 为什么需要「编程语言」？

电脑真正能直接理解的只有**机器码**——一串串 0 和 1，例如：

```text
10111000 00000001 00000000 00000000 00000000
```

人很难读写这种东西。于是人们发明了**编程语言**：一种介于人类语言和机器码之间的、规则严格的「中间语言」。比如用 Python 让电脑显示一句话：

```python
print("你好！")
```

是不是好懂多了？编程语言写成的文字叫**源代码**（source code），简称**代码**。

### 为什么有这么多种编程语言？

就像有螺丝刀、锤子、扳手一样，不同的语言擅长不同的事：

| 语言 | 特点 | 常见用途 |
|------|------|----------|
| **Python** | 简单好读，库多 | 入门、数据分析、人工智能、自动化脚本 |
| **JavaScript / TypeScript** | 浏览器里唯一原生支持的语言 | 网页、网站前端、也能写后端 |
| **Java** | 稳定、生态成熟 | 企业后台系统、安卓应用 |
| **C** | 接近硬件，速度快 | 操作系统、嵌入式设备、单片机 |
| **C++** | 又快又能组织大程序 | 游戏引擎、浏览器、图形软件 |
| **Rust** | 快，并且编译器帮你防止内存错误 | 系统软件、命令行工具、高性能服务 |
| **Go** | 简洁，擅长并发 | 云服务、网络服务器、运维工具（Docker、Kubernetes） |
| **汇编** | 几乎一条指令对应一条机器码 | 理解 CPU、性能优化、安全研究 |

> [!TIP]
> 学会第一门语言最难。之后再学别的语言，你会发现大部分概念（变量、条件、循环、函数）都是相通的，只是写法不同。所以**第一门语言选简单的**——本教程推荐 Python。

## 1.3 代码是怎么变成电脑能执行的东西的？

源代码要先「翻译」成机器能执行的指令。有两种主要的翻译方式：

**编译**（compile）——像**翻译一整本书**：

```text
源代码 main.c ──[编译器]──► 可执行文件 main.exe ──► 运行
                (一次性全部翻译)        (以后可以直接运行，很快)
```

C、C++、Rust、Go 属于这一类。翻译这一步由**编译器**（compiler）完成。如果代码有语法错误，编译器会拒绝翻译，并告诉你哪里错了。

**解释**（interpret）——像**同声传译**：

```text
源代码 main.py ──[解释器：读一行、执行一行]──► 结果
```

Python、JavaScript 属于这一类。**解释器**（interpreter）边读边执行。好处是写完马上能运行，方便试验。

Java 介于两者之间：先编译成一种中间格式（字节码），再由 Java 虚拟机执行。

> [!NOTE]
> 不用死记这些分类。你只需要知道：**写好的代码要经过编译器或解释器处理才能运行**；当它们发现问题时，会给出**错误信息**。学会读错误信息，是编程最重要的技能之一（第 5 课专门讲）。

## 1.4 认识学习程序

本教程配套的学习程序分成三栏：

```text
┌──────────────┬──────────────────────────┬─────────────────────────────┐
│ ① 课程目录    │ ② 课文 / 练习              │ ③ 代码编辑器   [▶ 运行]      │
│              │                          │                             │
│ 🚀 编程起步   │  你现在读的就是这里        │  在这里写代码                 │
│   1. 什么是…  │                          │                             │
│ 🐍 Python    │  代码框上方有              ├─────────────────────────────┤
│ ...          │  「▶ 放进编辑器运行」       │ ④ 运行结果                   │
│              │                          │   程序的输出、错误信息、解释    │
│ 已完成 0/115  │ [◀ 上一课] [下一课 ▶]      │ ⑤ 输入框：程序要你输入时用     │
└──────────────┴──────────────────────────┴─────────────────────────────┘
```

1. **课程目录**：点课程名展开，点课名打开。学完的课后面会出现 ✓。
2. **课文 / 练习**：上方有两个标签页。读完课文，到「✍️ 练习」里做题。
3. **代码编辑器**：在这里写代码。左上角可以选编程语言。
4. **运行结果**：点「▶ 运行」（或按 <kbd>F5</kbd>）后，程序的输出显示在这里。出错时，下面会有「💬 这是什么意思？」的中文解释。
5. **输入框**：有的程序会等你输入内容，在这里输入并按回车。

其他常用功能：

- 菜单「视图」可以**放大文字**（<kbd>Ctrl</kbd> + <kbd>+</kbd>）、切换**深色模式**、切换**界面语言**。
- 菜单「工具 → 检查开发工具」：看看电脑上装了哪些编程工具，没装的会告诉你怎么装。
- 你的学习进度和写过的代码会**自动保存**。

## 1.5 动手：运行你的第一段代码

点下面代码框上方的「▶ 放进编辑器运行」，代码会出现在右边的编辑器里，然后点「▶ 运行」：

```python
print("你好，我开始学编程了！")
print("1 + 1 =", 1 + 1)
print("一年有", 365 * 24 * 60, "分钟")
```

你应该看到：

```text
你好，我开始学编程了！
1 + 1 = 2
一年有 525600 分钟
```

现在试着**改一改**：把「我开始学编程了」改成你自己的话，把 `365` 改成 `366`（闰年），再运行一次。

> [!TIP]
> 编程最好的学习方法就是**改代码、运行、看结果**。不要怕弄坏——改坏了点「恢复初始代码」或者重新放一次例子就好。电脑不会因为你写错代码而坏掉。

### 故意犯个错

把第一行的英文右括号 `)` 改成中文的 `）`，再运行：

```python norun
print("你好，我开始学编程了！"）
```

你会看到红色的错误信息，以及下面的中文解释。这就是编程的日常：**写 → 运行 → 看错误 → 修改 → 再运行**。

## 1.6 编程需要什么能力？

很多人担心自己「数学不好」「英语不好」学不会编程。其实：

- **数学**：入门阶段只需要小学的加减乘除。做游戏、人工智能时才需要更多数学，到时候再学。
- **英语**：编程语言的关键字只有几十个英文单词（`print`、`if`、`for`、`while`……），用多了自然就记住了。错误信息看不懂？学习程序会给你解释，第 5 课还有常用词表。
- **最重要的**是：耐心、细心（一个符号都不能错）、把大问题拆成小步骤的习惯——这些都可以在练习中培养。

## 1.7 小结

- **程序**是一组精确的、按顺序执行的指令；**编程**就是写这些指令。
- 电脑只懂机器码；**编程语言**让人能用接近人类语言的方式写程序，写出来的叫**源代码**。
- 源代码由**编译器**（整体翻译）或**解释器**（边读边执行）处理后才能运行。
- 学习程序：左边选课，中间读课文做练习，右边写代码点「▶ 运行」。
- 学编程的诀窍：多改、多运行、认真看错误信息。

### 练习 1：什么是程序？

下面哪一句话最准确地描述了「程序」？

- 一台电脑的硬件
- 一组按顺序执行的、精确的指令
- 一种可以和电脑聊天的软件
- 只有专家才能看懂的密码

<details>
<summary>答案与解析</summary>

程序就是指令清单，就像菜谱。硬件是电脑的实体部分；聊天软件只是程序的一种。
</details>

<!-- exercise: compile-or-interpret -->
### 练习 2：编译还是解释？

「先把整个源代码翻译成可执行文件，以后直接运行这个文件」，这种方式叫什么？

- 解释
- 编译
- 下载
- 复制

<details>
<summary>答案与解析</summary>

编译。C、C++、Rust、Go 都是先编译再运行的语言；Python 和 JavaScript 通常是解释执行的。
</details>

<!-- exercise: first-code -->
### 练习 3：第一段代码

编写程序，输出下面两行：

```text
Hello!
1 + 2 = 3
```

第二行的 `3` 要让电脑**计算**出来，不要直接写在引号里。

<details>
<summary>提示</summary>

第一行：`print("Hello!")`。第二行：`print("1 + 2 =", 1 + 2)` ——逗号会自动在两部分之间加一个空格。
</details>

<!-- exercise: predict-calc -->
### 练习 4：读代码，写输出

下面的程序会输出什么？先自己想，再填写答案。

```python
print(2 * 3)
print("2 * 3")
```

<details>
<summary>答案与解析</summary>

第一行没有引号，电脑会计算 `2 * 3`，输出 `6`；第二行有引号，是一段文字，原样输出 `2 * 3`。
</details>
