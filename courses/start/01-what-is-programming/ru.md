# 1. Что такое программирование?

> 🎯 **Цели урока**: понять слова «программа», «язык программирования», «компиляция» и «интерпретация»; познакомиться с программой курса; запустить свой первый код.
>
> ⏱ **Время**: 20 минут　|　📋 **Что нужно знать**: ничего

## 1.1 Программа — это рецепт

Представьте, что вы учите робота жарить яичницу. Робот выполняет **любую** команду, но здравого смысла у него **нет совсем**. Сказать «сделай завтрак» не получится — нужно расписать каждый шаг:

```text
1. Открыть холодильник, достать 2 яйца и масло
2. Поставить сковороду на плиту, включить средний огонь
3. Положить 1 чайную ложку масла, подождать 1 минуту
4. Разбить яйца на сковороду
5. Посолить щепоткой соли
6. Жарить 3 минуты
7. Выключить огонь и переложить на тарелку
```

Этот список — **программа**: последовательность **точных инструкций, выполняемых по порядку**. Компьютер — это и есть робот: он невероятно быстр (миллиарды инструкций в секунду) и никогда не устаёт, но **никогда не догадывается, что вы имели в виду**. Он делает ровно то, что написано; если написано неправильно — тоже сделает (или остановится и сообщит об ошибке).

**Программирование** — это процесс написания таких списков инструкций.

> [!NOTE]
> Всё, чем вы пользуетесь каждый день, — программы: мессенджеры, браузеры, игры, калькулятор в телефоне, турникеты в метро, системы управления в автомобилях… За всем этим — строки кода, написанные программистами.

## 1.2 Зачем нужны языки программирования?

Напрямую компьютер понимает только **машинный код** — цепочки нулей и единиц, например:

```text
10111000 00000001 00000000 00000000 00000000
```

Людям такое читать и писать очень трудно. Поэтому придумали **языки программирования** — строгие «промежуточные» языки между человеческим языком и машинным кодом. Вот как на Python вывести сообщение:

```python
print("Привет!")
```

Гораздо понятнее, правда? Текст на языке программирования называется **исходным кодом**, или просто **кодом**.

### Почему языков так много?

Как отвёртки, молотки и гаечные ключи, разные языки хороши для разных задач:

| Язык | Сильные стороны | Где применяется |
|------|-----------------|-----------------|
| **Python** | простой, читаемый, много библиотек | первый язык, анализ данных, ИИ, скрипты автоматизации |
| **JavaScript / TypeScript** | единственный язык, который браузер выполняет сам | веб-страницы, фронтенд, бэкенд тоже |
| **Java** | стабильный, зрелая экосистема | корпоративные системы, Android-приложения |
| **C** | близок к железу, быстрый | операционные системы, встраиваемые устройства, микроконтроллеры |
| **C++** | быстрый и подходит для больших программ | игровые движки, браузеры, графические программы |
| **Rust** | быстрый, а компилятор не даёт допустить ошибки памяти | системные программы, утилиты, высоконагруженные сервисы |
| **Go** | простой, отлично работает с параллельностью | облачные сервисы, серверы, DevOps-инструменты (Docker, Kubernetes) |
| **Ассемблер** | почти одна строка — одна машинная команда | понимание процессора, оптимизация, исследования безопасности |

> [!TIP]
> Первый язык — самый трудный. Потом большинство идей (переменные, условия, циклы, функции) переносится на другие языки — меняется только запись. Поэтому **первый язык лучше выбрать простой**: в этом курсе мы советуем Python.

## 1.3 Как код становится тем, что компьютер может выполнить?

Исходный код нужно «перевести» в инструкции для машины. Есть два основных способа.

**Компиляция** — как **перевод целой книги**:

```text
исходник main.c ──[компилятор]──► исполняемый файл main.exe ──► запуск
               (переводим всё один раз)     (дальше запускаем напрямую, быстро)
```

Так работают C, C++, Rust и Go. Переводчик называется **компилятором**. Если в коде есть «грамматическая» ошибка, компилятор откажется переводить и укажет, где проблема.

**Интерпретация** — как **синхронный перевод**:

```text
исходник main.py ──[интерпретатор: прочитать строку, выполнить строку]──► результат
```

Так работают Python и JavaScript. **Интерпретатор** читает и сразу выполняет, поэтому код можно запустить сразу после написания — удобно для экспериментов.

Java — посередине: код компилируется в промежуточный формат (байт-код), который затем выполняет виртуальная машина Java.

> [!NOTE]
> Заучивать классификацию не нужно. Запомните главное: **перед запуском код проходит через компилятор или интерпретатор**, и если они находят проблему, то выводят **сообщение об ошибке**. Умение читать такие сообщения — один из важнейших навыков (ему посвящён урок 5).

## 1.4 Знакомство с программой курса

Окно программы состоит из трёх колонок:

```text
┌──────────────┬──────────────────────────┬─────────────────────────────┐
│ ① Курсы       │ ② Урок / Задания          │ ③ Редактор кода [▶ Запустить]│
│              │                          │                             │
│ 🚀 Первые шаги│  вы читаете это здесь     │  здесь пишем код             │
│   1. Что…    │                          │                             │
│ 🐍 Python    │  над блоками кода есть    ├─────────────────────────────┤
│ ...          │  кнопка «▶ Запустить»     │ ④ Результат                  │
│              │                          │   вывод, ошибки, объяснения   │
│ пройдено 0/115│ [◀ Назад] [Дальше ▶]     │ ⑤ Поле ввода для программы    │
└──────────────┴──────────────────────────┴─────────────────────────────┘
```

1. **Курсы**: щёлкните курс, чтобы раскрыть его, затем выберите урок. Пройденные уроки отмечаются ✓.
2. **Урок / Задания**: две вкладки сверху. Прочитайте урок, потом решите «✍️ Задания».
3. **Редактор кода**: здесь пишем код. Язык выбирается вверху слева.
4. **Результат**: нажмите «▶ Запустить» (или <kbd>F5</kbd>) — здесь появится вывод программы. Если что-то пошло не так, блок «💬 Что это значит?» объяснит ошибку простыми словами.
5. **Поле ввода**: некоторые программы ждут, что вы что-то введёте, — печатайте здесь и нажимайте Enter.

Ещё полезное:

- В меню «Вид» можно **увеличить текст** (<kbd>Ctrl</kbd> + <kbd>+</kbd>), включить **тёмную тему** и сменить **язык интерфейса**.
- «Инструменты → Проверить инструменты разработки» покажет, что установлено, и подскажет, как установить недостающее.
- Прогресс и ваш код **сохраняются автоматически**.

## 1.5 Практика: запустите первый код

Нажмите «▶ Запустить» над блоком ниже — код окажется в редакторе справа. Затем нажмите «▶ Запустить» над редактором:

```python
print("Привет, я начал учиться программировать!")
print("1 + 1 =", 1 + 1)
print("В году", 365 * 24 * 60, "минут")
```

Вы должны увидеть:

```text
Привет, я начал учиться программировать!
1 + 1 = 2
В году 525600 минут
```

Теперь **измените что-нибудь**: напишите в первой строке свою фразу, замените `365` на `366` (високосный год) и запустите снова.

> [!TIP]
> Лучший способ учиться — **изменить код, запустить, посмотреть результат**. Не бойтесь что-то сломать: если запутались, загрузите пример заново. Неправильный код не может повредить компьютер.

### Ошибёмся нарочно

Удалите закрывающую скобку `)` в конце первой строки и запустите:

```python norun
print("Привет, я начал учиться программировать!"
```

Вы увидите красное сообщение об ошибке и объяснение под ним. Это обычная работа программиста: **написать → запустить → прочитать ошибку → исправить → запустить снова**.

## 1.6 Какие нужны способности?

Многие боятся, что «плохо знают математику» или «плохо знают английский». На самом деле:

- **Математика**: на старте нужна только школьная арифметика. Для игр и ИИ математики понадобится больше — её можно выучить потом.
- **Английский**: ключевых слов в языке всего несколько десятков (`print`, `if`, `for`, `while`…), и они запоминаются сами. Сообщения об ошибках объясняет программа курса, а в уроке 5 есть словарик.
- **Что действительно важно**: терпение, внимательность (важен каждый символ) и привычка разбивать большую задачу на маленькие шаги — всё это развивается практикой.

## 1.7 Итоги

- **Программа** — точный список инструкций, выполняемых по порядку; **программирование** — их написание.
- Компьютер понимает только машинный код; **языки программирования** позволяют писать программы на чём-то более близком к человеческому языку. Написанное — это **исходный код**.
- Исходный код обрабатывает **компилятор** (сначала переводит всё) или **интерпретатор** (читает и выполняет на ходу).
- Программа курса: слева выбираем урок, в центре читаем и решаем задания, справа пишем код и нажимаем «▶ Запустить».
- Секрет: чаще меняйте код, чаще запускайте, внимательно читайте ошибки.

### Задание 1: Что такое программа?

Какое утверждение точнее всего описывает «программу»?

- Аппаратная часть компьютера
- Последовательность точных инструкций, выполняемых по порядку
- Приложение, с которым можно поболтать
- Секретный шифр, понятный только специалистам

<details>
<summary>Ответ и разбор</summary>

Программа — это список инструкций, как рецепт. Аппаратная часть — это «железо»; чат — лишь один из примеров программ.
</details>

<!-- exercise: compile-or-interpret -->
### Задание 2: Компиляция или интерпретация?

«Сначала весь исходный код переводится в исполняемый файл, а потом запускается этот файл». Как это называется?

- Интерпретация
- Компиляция
- Загрузка
- Копирование

<details>
<summary>Ответ и разбор</summary>

Компиляция. C, C++, Rust и Go компилируются перед запуском; Python и JavaScript обычно интерпретируются.
</details>

<!-- exercise: first-code -->
### Задание 3: Первый код

Напишите программу, которая выводит две строки:

```text
Hello!
1 + 2 = 3
```

Число `3` во второй строке должен **вычислить** компьютер — не пишите его внутри кавычек.

<details>
<summary>Подсказка</summary>

Первая строка: `print("Hello!")`. Вторая: `print("1 + 2 =", 1 + 2)` — запятая добавляет пробел между частями.
</details>

<!-- exercise: predict-calc -->
### Задание 4: Прочитайте код и напишите вывод

Что выведет эта программа? Сначала подумайте, потом впишите ответ.

```python
print(2 * 3)
print("2 * 3")
```

<details>
<summary>Ответ и разбор</summary>

В первой строке кавычек нет, поэтому компьютер вычисляет `2 * 3` и выводит `6`; во второй — текст в кавычках, он выводится как есть: `2 * 3`.
</details>
