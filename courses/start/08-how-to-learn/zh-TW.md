# 8. 怎樣學好程式設計

> 🎯 **本課目標**：根據自己的目標選好學習路線；掌握高效的練習方法；知道去哪裡找資料和專案靈感；建立一個可持續的學習計劃。
>
> ⏱ **預計用時**：25 分鐘　｜　📋 **前置知識**：無

恭喜你完成了「程式設計起步」的前 7 課！最後一課不講技術，講**方法**——同樣花 100 個小時，方法對不對，效果可能差好幾倍。

## 8.1 選擇學習路線

不要同時學好幾門語言。先用一門語言把**程式設計思維**練紮實，再根據興趣擴充套件：

```text
                      ┌──► JavaScript/TypeScript ──► 網站前端、全堆疊
                      │
程式設計起步 ──► Python ───┼──► Java ──► 企業後端、安卓
                      │
                      ├──► Go ──► 雲服務、網路伺服器、運維工具
                      │
                      ├──► C ──► 彙編 ──► 理解計算機底層、嵌入式、安全
                      │     └──► C++ / Rust ──► 遊戲、高效能軟體、系統程式設計
                      │
                      └──► 大模型教程（LLM-Tutorial）──► 人工智慧
```

| 你的目標 | 推薦路線 |
|----------|----------|
| 先學會程式設計，還沒想好方向 | Python（整門課） |
| 做網站、小程式、網頁遊戲 | Python 前 8 課 → JavaScript/TypeScript |
| 考計算機專業 / 打好底層基礎 | Python → C → 彙編 → C++ |
| 找後端開發工作 | Python → Java 或 Go |
| 做遊戲引擎、高效能程式 | Python → C → C++ 或 Rust |
| 人工智慧、資料分析 | Python → LLM-Tutorial |

## 8.2 最有效的學習方法：動手

### 1. 每個例子都親手敲一遍

看懂 ≠ 會寫。讀課文時，把每一個例子**自己敲進編輯器**（而不是複製貼上），執行，然後**改一改**：換個數字、加一行、故意寫錯，看看會發生什麼。

### 2. 每課的練習都要做完

練習是專門設計來檢驗你是否真正理解的。卡住時：

1. 先回去重讀課文相關的部分；
2. 再點「💡 提示」，一次只看一條；
3. 實在不行再看參考答案——**看完後關掉答案，自己從頭再寫一遍**。

### 3. 少量多次，每天一點

每天 30～60 分鐘，比周末一次學 8 小時效果好得多。大腦需要「睡一覺」來鞏固新知識。連續學習的天數比單次學習的時長更重要。

### 4. 主動回憶，而不是反覆閱讀

學完一課，合上教程，試著**用自己的話**說出這課講了什麼、寫出關鍵程式碼。說不出來的地方，就是需要回去複習的地方。過幾天再回頭做一遍舊練習，效果更好（這叫**間隔重複**）。

### 5. 儘早開始做專案

學到迴圈和函式之後，就可以開始做小專案了。專案能把零散的知識串起來，也是最有成就感的部分：

- 🎲 猜數字遊戲、石頭剪刀布
- 🧮 計算器、單位換算器、個人記賬本
- 📝 待辦事項清單（儲存到檔案）
- 🔐 密碼生成器、檔案批次重新命名工具
- 🌐 抓取天氣資訊、自己的個人主頁
- 🎮 貪吃蛇、俄羅斯方塊（學完圖形庫之後）

**比教程練習難一點、又不至於完全不會**的專案最鍛鍊人。

| 型別 | 推薦 |

## 8.4 英語不好怎麼辦？

程式設計需要的英語比你想象的少得多：

1. **關鍵字**只有幾十個，用多了就記住了。
2. **報錯資訊**很模板化：第 5 課的詞彙表 + 學習程式的中文解釋，足夠應付大部分情況。
3. **變數名**用簡單英文單詞（`count`、`total`、`name`、`price`）。不知道怎麼說？查詞典，或者用拼音也比 `a1`、`b2` 強。
4. 遇到英文文件，可以用瀏覽器的翻譯功能先看個大概，**程式碼部分不要翻譯**。
5. 每天記 3 個程式設計常用詞，三個月後你會驚訝於自己的進步。

## 8.5 健康和心態

- 🧘 **卡住時離開一下**：散個步、睡一覺，回來常常一眼就看出問題。
- 🐢 **不要和別人比進度**：每個人的起點不同。和昨天的自己比。
- 📓 **記學習筆記**：記下踩過的坑和解決辦法，這是你獨有的寶貴資料。
- 👀 **保護眼睛和頸椎**：每 45 分鐘休息 5 分鐘，使用深色模式，把文字放大一點（選單「檢視 → 放大文字」）。
- 🎯 **允許自己「不完美」**：先讓程式能執行，再讓它變好。

## 8.6 制訂你的計劃

一個參考計劃（每天約 1 小時）：

| 階段 | 時間 | 內容 |
|------|------|------|
| 第 1～2 周 | 每天 1 課 | 程式設計起步 8 課 + Python 第 1～4 課 |
| 第 3～6 周 | 每 2 天 1 課 | Python 第 5～12 課，每週做一個小專案 |
| 第 7～8 周 | | Python 第 13～16 課，完成綜合專案 |
| 之後 | | 按 8.1 選擇第二門語言 |

## 8.7 小結

- 先精通一門語言（推薦 Python），再根據目標擴充套件。
- 親手敲每個例子，做完每道練習；每天少量、堅持；主動回憶、間隔複習。
- 儘早做專案——比練習稍難一點的專案最鍛鍊人。
- 資料首選官方文件，多用練習平臺和優秀的開源倉庫。
- 英語可以邊學邊積累；卡住時休息一下，和昨天的自己比。
